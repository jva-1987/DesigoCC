Comark Monitor Card for Fan Monitoring

Selecting the Fan Alarm property of the Comark Monitor Card node in System Browser, the Fan Alarm Value displays that you can adjust to set the minimum threshold value to monitor. If the value falls below this setting, a Trouble event is generated.
