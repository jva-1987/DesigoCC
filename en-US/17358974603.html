Network Settings

Property

Description

APOGEE Configuration Tab: Device Settings

The table below describes the fields in the APOGEE Configuration tab for an APOGEE P2 AEM device.

APOGEE P2 AEM Device Properties - APOGEE Configuration Tab

Property

Description

Device Name

Displays the APOGEE Node Identifier of the field panel.

Maximum BLN messages

Allows you to indicate how many BLN messages to keep in the panel before removing the older ones.

GMT offset (minutes)

Allows you to select the offset time from Greenwich Mean Time in minutes.

Automatic alarm registration

Allows you to enable automatic alarm registration to destination "0" for standard alarming.

COV polling rate

Allows you to set the time in seconds as to how often to poll properties that cannot send COVs.

Time sync (minutes)

Allows you to set the time in minutes as to how often the time at the field panel should be synchronized.

Eping rate (seconds)

Allows you to set the time in seconds as to how often to check if a field panel has failed.

APOGEE P2 AEM Network: Operations\Extended Operation Tabs

The Operation and Extended Operation tabs display the properties for an AEM Network when you are in Engineering mode and the AEM Network is selected in the System Browser tree.

APOGEE P2 AEM Network Properties (Operation\Extended Operation)

Property

Description

AEMAddress

Displays the IP address of the AEM panel.

Discovery Progress

Displays the progress of an initiated discovery between the AEM network and its panels.

Connection Status

Displays whether or not the AEM network is connected to Desigo CC .

Add Device - Add an AEM device to the AEM Network.

Connect - Initiate a connection when you add a device.

Disconnect - Disconnects the network.

Time Sync - Synchronizes the time on the BLN.

Network State

Displays whether or not the APOGEE AEM Driver is running and monitoring the network.

Node Name

The name of BLN.

Has AEM

Indicates whether or not the network has an AEM. Additionally, you can perform the following tasks from here:

Remove AEM - Remove an AEM from the BLN.

Reset AEMs - Disconnects and reconnects all the AEMs.

Summary Status

Displays the alarm status of your device

Our Node

The unique Desigo CC node number for the AEM Network so that the field panel recognizes it as a device.

APOGEE P2 AEM Device: Operation\Extended Operation Tabs

The Operation and Extended Operation tabs display the properties for an AEM device when you are in Engineering Mode and the device is selected in the System Browser tree.

AEM Device Properties (Operation\Extended Operation)

Property

Description

Address

Displays the IP address of the panel associated with the AEM panel.

Battery Status

Displays the percentage of battery left at the AEM panel.

Description

Allows you to enter and display a value description for your device. This description displays only in Desigo CC and is not written to the device.

DHCP Enabled

Indicates whether the device has DHCP enabled or not.

Firmware Revision

Displays the firmware revision currently on the device.

Hardware Revision

Displays the device hardware information.

Link Time

Displays the date the firmware on the device was built.

Node Name

The name of the BLN.

Ready

Indicates whether or not the panel is ready.

Status

Displays whether or not the device is connected or disconnected. From here you can also initiate the following tasks:

Backup - A device back-up.

Coldstart - A device coldstart.

Discover - A session update between Desigo CC and the device.

Summary Status

Displays the alarm status of your device

Telnet Enabled

Indicates whether or not Telnet is enabled.
