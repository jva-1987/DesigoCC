Trend Workspace

The Trend displays the live and historical trend series values from the devices. A trend can contain any number of hierarchically arranged areas for representing curves, with scales and legends. Trend view allows for a visual comparison of individual trends.
The Trend widget supports only the numerical, boolean, and enumerated format values from the selected source. Hovering over the trend chart displays a tooltip with details of the specific point on the chart.

1

Displays the name of the widget.

2

Displays the style selected for the trend with respect to the data point.

3

Displays the trend for the selected data point with a style selected for it. You can add up to 5 trends on the dashboard.

4

Behaves as a toggle button and stops trend when you click . To restart logging trends, click .

5

Settings

Contains the Widget name, Override dashboard settings, and Period.

-Widget name: Displays the widget name. You can change the name if required.

- Override dashboard settings: To override the dashboard settings, enable the option toggle. This will display the option to change the Date range and Interval in the widget saved in the dashboard.

- Period: Specify the period for the trend to fetch the values.

6

Source

Contains common elements such as Data point, Delete, Edit, and Add like all the widgets and the additional following list of elements:

- Y-axis: Allows you to change alignment of the chart y-axis to Left or Right.

7

Axes

Displays the Minimum and Maximum value selector for Left and Right Y-axis based on the axis selected for the trends.

- Left/Right Y-axis: Min.: Specify the minimum range for the left/right y-axis, which is displayed in the trend based on the selection of axis in the Source tab .

- Left/Right Y-axis: Max.: Specify the maximum range for the left/right y-axis, which is displayed in the trend based on the selection of axis in the Source tab.

- Chart: Displays the chart added to the trend to change the min and max values.

- Auto-scale: By default, the Auto Scaling is enabled. To change the minimum and maximum Y-axis (left or right) values, disable the auto scaling.

8

The slider is available at the bottom of the chart by default and it is focused to display 80% of the values if the values are more. Similarly if there are fewer values, the slider will adjust to fit the entire chart.
Adjust the slider horizontally or select a particular area in the slider to view that part of the trend with time and date related to your selection.

9

Displays the trend for the intervals selected from Hour, Day, Week, Month, Year, and All.
