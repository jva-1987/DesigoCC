Logging Event Notes

Any notes about the selected event display a the bottom of the event details area.
NOTE: If no notes were already entered, the following displays: No event notes.

  1. To enter a new note, in the event note area, do the following:
    a. Select  Add.
    b. Enter the text of the note.
    c. Select  to save the changes.
  2. A message prompts you to refresh.
  3. Select  Refresh.
  1. The new note displays in event note area, including date/time and user name.
