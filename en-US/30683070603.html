Create a Grouped List Card

You can create a Grouped list chart that displays a table with several data points in multiple groups. For background information, see Grouped List Card Workspace.

  1. In the dashboard, select the Grouped List Card from Create widget list.
  2. Click Next.
  3. The Create widget page opens.
  4. Click Add group to create the group.
  5. The Create group window opens.
  6. Enter the Group name and click Create.
  7. The group is created.
  8. Click Add in the group to select the data point.
  9. Select the device from the list and click Select.
  10. Select the Data point from the drop-down list.
    It is not possible to add a data point without a group in the group list card widget. Additionally, it is not possible to select a data point that has already been selected.
  11. The data point is added to the group.
  12. Repeat the steps 5 to 7 to add more data point to the group.
  13. Click Add group to add more groups.
  14. The Grouped List Card is created and displays a table with several data points in multiple groups.
  15. Repeat steps 3 to 7 to add more groups and data points into the group. The group name must be unique and should not be duplicated.
  16. Click Create to add the widget to the dashboard.
  17. Click Save.
  1. The Grouped list card is created in the dashboard.

Edit a Group

  1. In the Group list card widget, select the group that you want to delete.
  2. Select Edit group from  the icon next to Add icon.
  3. The Edit group window displays.
  4. Change the group name.
  5. Click Save.
  1. The group name is changed.

Delete a Group

  1. In the Group list card widget, select the group that you want to delete.
  2. Select Delete group from  the icon next to Add icon.
  3. The Delete group window displays.
  4. Click Delete.
  1. The group is deleted.
