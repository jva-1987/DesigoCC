Log View Definition Workspace for Mobile Flex

The Log View Definitions are located in the Application View under Log Viewer.

1

Master pane

Displays the list of log records sorted in descending order according to the date and time.

2

Search bar

Allows you to search for information using the pre-defined filters such as Event list, Activity, Action result, Date/Time, and so on.

3



Applies the selected filter.

4



Displays additional information about the selected log entry.

5



Provides the following option:
Save filter: Saves the log view definition changes.
Discard changes: Discards the changes done for the selected log view definition.
Save as: Allows you to save the log view definition as a new log view definition.
Customize columns: Display or hide columns in the Master pane.
Delete filter: Deletes the selected log view definition.

6



Navigates to the System Browser.
