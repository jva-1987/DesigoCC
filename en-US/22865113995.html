Configure the Fire WAN HUB-4 Module

  1. Select Project > Field Networks > [Fire WAN network] > [Enclosure].
  2. In the Object Configurator tab, click New .
  3. In the New object dialog box, enter a name and description for the new HUB-4 module.
  4. Click OK.
  5. The newly created HUB-4 module is automatically selected in System Browser.
  6. In the FireWAN tab, select the HUB-4 Settings expander.
  7. In Address, select the HNET address of the HUB-4 module.
    In the port table, configure the parameters of ports 1 to 4 as necessary.
    • Used: Select the check box if the corresponding port is used.
    • Electrical Interface: Select RS-485 or Modem.
      NOTE: The selection must be applied to ports in pairs. You must set the same option to both ports of the pairs 1-2 and 3-4.
    • Transmit Level (dbm): Set the transmit level for modem lines (it does not apply to RS-485 lines). You may need to increase the default level (-10 dbm) if a long line attenuates the signal and inhibits proper communication, or further decrease the level if the line is very short.
    • Class X Level Sensitivity (dbm): Set the Class X level sensitivity for modem lines (it does not apply to RS-485 lines). If you have a circuit with a short run and are experiencing troubles, modify the default level (-23 dbm) and adjust the setting in 5 dbm increments towards 0 dbm.
    • Ground Fault Inhibit: Select this check box to inhibit ground detection on the communication lines based on local operations.
    • FSI Poll Delay (msec): Set the delay between successive polls to panels on the communication link. For WAN solutions with HUB-4, set this value to zero.
    • Baud Rate: Select the communication baud rate that must match the setting of the connected equipment.
    • Custom Message: Enter the description text of the line.
    • Network wiring type: Select Class B or Class A.
      NOTE: Class A is only supported with RS-485.
    • If the XNET to connect is already configured, select it from the Associated XNET drop-down list or drag the XNET node from System Browser onto the corresponding port line in the table.
      Else, If the XNET is not configured, continue with the procedure. You can configure and connect the XNET later.
  8. Click Save .
  9. Repeat these steps for all the HUB-4 interfaces in the enclosures under the [Fire WAN network].

For background information about the HUB-4 configuration parameters, see the reference section.
