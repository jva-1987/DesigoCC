Managing Log View Definition

This section provides step-by-step instructions to work with Log View Definition. For background information, see Managing Log View Definition.

Creating Log View Definition

  1. You must have Show and Configure access rights to view and configure Log Viewer application.
  1. In System Browser, select Application View > Log Viewer.
  2. The Log Viewer fetches all data and displays the log entries in Master pane.
  3. Click the Search bar and select a value from the displayed list according to which you want to filter the displayed output. Alternatively, you can also enter a value in the Search bar. Some examples of filtering options include Action result, Event list, Activity, Date/Time, and so on.
  4. Click  and select Save filter.
  5. The Save As dialog box displays.
  6. In the Save As dialog box, perform the following:
    • Enter desired name and description in respective field.
    • Select a folder from the Location field to save the log view definition.
    • (Optional) Click New Log View Folder to create a new folder to save the log view definition.
    • (Optional) Click Cancel to navigate back to previous screen.
    • Click Save.
  7. The log view definition is created and saved in the selected folder.
    NOTE: The log view definition reflects in System Browser of the Desigo CC Installed Client.

Editing Log View Definition

  1. In System Browser, select Application View > Log Viewer.
  2. Select a log view definition to be edited.
  3. Click the Search bar and edit the filter options as per requirement.
  4. Click  and select Save filter.
  5. The log view definition is saved.
    NOTE: Editing log view definition also updates it in the Desigo CC Installed Client.

Deleting Log View Definition

  1. In System Browser, select Application View > Log Viewer.
  2. Select a log view definition to be deleted.
  3. Click  and select Delete filter.
  4. The log view definition is deleted.
    NOTE: Deleting log view definition also deletes it from the Desigo CC Installed Client.
