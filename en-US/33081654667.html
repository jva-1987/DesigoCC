Migrating S7 Driver

Desigo CC V8 introduces a migration tool to help transition from the legacy S7Com driver (WCCILs7.exe) to the integrated S7 standard driver (WCCOAs7.exe) in WinCC OA.

NOTE:

  1. The migration must be completed by Desigo CC V9, after which the old driver will no longer be supported.
  2. You must always back up your project before starting, as the migration is irreversible.
  3. The S7Plus driver is not affected.

Steps

  1. Copy Siemens.Gms.S7MigrationTool.exe to the \GMSMainProject\bin folder. Use the latest version of the tool (for example, from <DesigoCC_V9build>\InstallerDVD\InstallFiles\EM\Simatic_S7\AddSW\V8.0).
  2. Start the project in the System Management Console (SMC).
  3. Close all running Desigo CC applications.
  4. Run the migration tool Siemens.Gms.S7MigrationTool.exe from the \GMSMainProject\bin directory.
  5. Click Execute to begin migration.
  6. The Migration Tool dialog box shows the migration progress. The duration of migration depends on the number of data points and may exceed 30 minutes.
  7. Click Close to exit the tool.
  8. Restart the project.
  1. A subdirectory S7MigrationToolResultLogs is created with the results of the migration in the Logs directory in the migrated project.

Points to consider Post Migration

  • The new S7 standard driver does not support named connections. S7-400 H systems remain supported.
  • You can enable the Redundant Device option to add a second IP address.
  • You must verify the data point state reactions that used the old driver with the object model (GMS_S7_BA_Device_1) to align with the new driver with the object model (_S7_Conn).
  • If a newly created BACnet driver fails to start (especially with manager - num 1), you need to create and user another BACnet driver.

Recommended Settings for Optimizing the New S7 Driver Performance

  • For large projects with multiple S7-300/400 controllers, increase the query interval from 500 milliseconds to 2000 milliseconds, 4000 milliseconds or 8000 milliseconds depending on the project size.
  • For older S7-300 controllers, perform the following:
    • Add the following line to the S7 section of the configuration file:
      UseConnections = 1
    • Update the following line in the S7 section of the configuration file:
      ReadOpState = 0
