Managing Log Viewer

This section provides step by step instructions to work with Log Viewer.

Prerequisites

You must have Show and Configure access rights to view and configure Log Viewer application.

 

Viewing Log Entries

  1. In System Browser, select Application View > Log Viewer.
  2. The Log Viewer fetches all data and displays the log entries in Master pane.
  3. Select an entry from the Master pane.
  1. The details of the selected log entry displays in the Detailed pane. By default, the details of the first log entry displays in the Detailed pane.

Configuring Log Entries

  1. A warning is displayed in Log Viewer workspace if the maximum limit of the log entries is exceed.
  1. In System Browser, select Application View > Log Viewer.
  2. Do any of the following, to change the View size to view maximum of log entries.
    • Click  and select Show Log view properties.
    • Click  and navigate to Right panel > Properties.
  3. Toggle  Basic to select the Advanced option.
  4. Edit the View Size property.
  1. The View Size of log entries in Master pane is updated.

Customizing Columns of Log Viewer

  1. In System Browser, select Application View > Log Viewer.
  2. Click  and select Customize columns.
  3. The list of available columns display in the Customize columns list.
  4. Do any of the following:
    • Toggle  between the Visible and Hidden options to display or hide the columns in the Master pane.
    • Click Reset to default to display the default list of columns.
  5. Click Apply.
    NOTE: Adjust the Master pane using the splitter to view the details of all the selected columns in the tabular view.
  1. The columns are customized as per the specified settings.

Filtering of Log Entries

  1. In System Browser, select Application View > Log Viewer.
  2. Click the Search bar and select a filter option from the displayed list, according to which you want to filter the data. For a set of filter options predefined values are displayed. For others you can enter a value manually in the Search bar. Some examples of filtering options include Action result, Activity, Users, and so on.
  3. Click  or press Enter key to apply the selected filter.
  4. The log entries display in the Master pane according to the applied filter criteria.
  5. Click Cancel  to clear the filter options.

Viewing History Logs

You can view history logs for a log entry, any event and System Browser node.

  1. In System Browser, select Application View > Log Viewer.
  2. You can select a log entry or an event from the Master pane.
  3. The details of selected log entry is displayed in Detailed pane.
  4. Click  to open Right panel > History.
  5. Expand History  to view list of history logs.
  6. The list of history log displays latest 100 log entry items.
  7. In History, select a log record to view more details.
  8. Click  Back to close the details of log entry.
  9. Click  to close the right panel.
  10. Select Open in log view to view log entry items in Master pane.
  11. Log Viewer Master pane is displayed with Location filter applied on Source information column.
