Customizing the Columns in Event List

In Flex Client web/desktop app, you can customize what columns display in Event List, change their order, or resize them.

- Your preferences are automatically saved when you exit the Flex Client application, and persist across sessions.
Your user preferences are lost in case of project upgrade.

- Column settings are also specific to the user profile and preferences. This means that different users can have different column settings.

- Depending on your profile, some columns cannot be moved, resized, or hidden.

Resize a Column Directly in Event List

  • To resize a column, drag the edge of its column header in Event List to the desired width.

Show, Hide, or Rearrange Columns in Event List

  1. In the Events workspace, next to  Filter, select  and then Customize columns.
  2. The Customize columns window displays.
    NOTE: The available columns depend on your user profile.
  3. Do one or more of the following:
    • To show a column in Event List, switch on  the corresponding column.
    • To hide a column in Event List, switch off  the corresponding column.
      NOTE:  means that a column cannot be hidden.
    • To reposition a column, select  then drag-and-drop it to the desired position.
  4. Select Apply.
  1. Event List displays with the columns as you have customized them.

Restore the Default Column Settings in Event List

  1. You previously resized, moved, or showed/hid columns in Event List and now you want to restore the default settings.
  1. In the Events workspace, next to  Filter, select  and then Customize columns.
  2. In the Customize columns window, select Restore to default and then Apply.
  1. Event List displays with the columns back to their default settings.
