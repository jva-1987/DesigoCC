Selecting the Archive Group for Physical and Virtual Devices

You can archive the single or multiple measurement points of the physical and virtual devices into the long-term or short-term storage. For background information, see Archive Groups.

Archiving a Single Measurement Point

  1. You have created and configured the device in the project. For more information, see Integrating the Devices.
  1. Select Application View > Powermanager > [area] or [sector].
  2. Select the [device] for which you want to archive the measurement points.
  3. In the Main expander within the Device Configuration expander, disable the Use Area Settings checkbox.
  4. The fields are enabled for editing in the Measurement Points expander.
  5. In the Measurement Points expander, enable the Archive checkbox for the measurement point that you want archive.
  6. The Archive Group and Filter Group fields are enabled for the selected group. For information on the default archive group values for physical (supported in Modbus, BACnet, IEC61850, and OPC protocols), and virtual devices measurement points, see Default Archive Group and Filter Group Values.
  7. Select the archive group [GPM_Long_Term_Miscellaneous] from the Archive Group drop-down list.
    NOTE: The GPM_Long_Term_Miscellaneous archive group is used to archive instantaneous measurement points into the long term storage. You can select any other archive group (as required).
  8. Click Save .
  1. The measurement point is archived into the long term storage or short-term storage for the selected archive group.

Archiving Multiple Measurement Points

  1. You have created and configured the device in the project. For more information, see Integrating the Devices.
  1. Select Application View > Powermanager > [area] or [sector].
  2. Select the [device] for which you want to archive the measurement points.
  3. In the Main expander within the Device Configuration expander, disable the Use Area Settings checkbox.
  4. The fields are enabled for editing in the Measurement Points expander.
  5. Select the required group from the Group drop-down list.
  6. In the Measurement Points expander, enable the Archive checkbox in the header for the selected group.
  7. The Archive Group and Filter Group fields are enabled for the selected group. For information on the default archive group values for physical (supported in Modbus, BACnet, IEC61850, and OPC protocols), and virtual devices measurement points, see Default Archive Group and Filter Group Values.
  8. Select the archive group [GPM_Long_Term_Miscellaneous] from the Archive Group drop-down list in the header.
    NOTE: The GPM_Long_Term_Miscellaneous archive group can be used to archive instantaneous measurement points into the long term storage. You can select any other archive group (as required).
  9. Click Save .
  1. The measurement points are archived into the long term storage or short-term storage for the selected miscellaneous archive group.

Applying Inheritance from System and Area for Archiving

You can apply inheritance for archiving the measurement points using archive group and filter group from the system and area. In other words, inheritance is supported for the Archive Group and Filter Group selection.

  1. You have created and configured the system, area, and devices in the project.
  1. Select Application View > Powermanager or [Area].
  2. Navigate to Device Type Configuration tab > Main expander.
  3. Select the device from the Device Type drop-down list.
  4. Disable the checkbox Use Default Settings for the system or Use System Settings for area in the Main expander.
  5. The fields are enabled for editing in the Measurement Points expander.
  6. In the Measurement Points expander, enable the Archive check box for the required measurement point.
  7. The Archive Group, and the Filter Group fields are enabled for the selected measurement point.
  8. Select the required Archive Group and Filter Group values.
  9. Click Save .
  1. The changes made for archiving the measurement points in the system node, reflect in the area and device nodes.
  2. The changes made for archiving the measurement points in the are node, reflect in the device node.

For background information, see Archive Groups under Measurement Points expander.
