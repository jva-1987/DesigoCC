Power Quality Tab Workspace

You must have the GMS_opt_PowerQuality license and activated in your system to access the Power Quality tab in Flex Client. The PowerQuality tab is only available for Power Quality devices supporting the IEC 61850 protocol.

It is recommended to keep the browser language the same as the Flex Client user language. If not, the tooltip information on the Power Quality analytics data will be incorrect.

If you do not see the updated PowerQuality analytics data in the Flex Client, refresh the web page.
