Personalize Notifications

You can customize Flex notifications for events, suppressed objects, and licenses.

Display Notifications Settings

  • In the horizontal navigation bar, select your initials, and then Notifications.
  1. The screen refreshes to displays the notifications settings.
  • To exit the notifications settings, refresh again the screen by selecting any of the system functions available in the navigation bar. For example, System or Events.
  1. Once you complete the settings described below then you can handle the notification messages as described in Handle Flex Client Notifications.

Set Style for Notifications

  1. The Notifications settings display on the screen.
  1. Select the wanted notification type on the left among:
    • Events
    • Suppressed sources
    • License
  2. In Notification style area, select one of the following styles for the toast messages:
    • None: No toast messages will be displayed bottom right of the screen.
    • Close automatically: The toast messages will be displayed bottom right of the screen and will be closed automatically.
    • Close manually: The toast messages will be displayed bottom right of the screen and you can close them manually.
      NOTE: If more than three messages are present, the oldest will be closed automatically.
  3. Repeat the previous steps for all the notification types you want to set.
  4. To show the notifications in the Notifications area, switch on  Show in notification center.

Play Sound for Unprocessed Events

  1. You want to play the audio alert emitted from the client station for all the event categories when a new event occurs.
  2. The Notifications settings display on the screen.
  1. Select the Events notification type on the left.
  2. Switch on  Play sound for unprocessed events.
    NOTE: Depending on the Client Profile, this option might be switched on by default and read-only.

Override Notifications Behavior for Event Categories

  1. You want to override the behavior of event notifications for a specific event category or a subset.
  2. The Notifications settings display on the screen.
  1. Under the Events notification type on the left, select an event category.
  2. Switch on  Override notification style.
  3. In Notification style area, select the style for the toast messages.
  4. Switch on  or off  one or more of the following options:
    • Show in notification center to show or hide the notification relevant to the event category in the Notifications area.
    • Play sound for unprocessed events to play or silence the audio alert emitted from the client station for the relevant event category.
      NOTE: Depending on the Client Profile, this option might be switched on by default and read-only.
  5. Repeat the previous step for all the event categories whose notification style you want to override.

Play a Beep Sound for New Suppressed Objects or License Notifications

  1. The Notifications settings display on the screen.
  2. Select the notification type on the left for which to want to play a beep sound:
    • Suppressed sources
    • License
  3. Switch on  Play sound for new notifications.
