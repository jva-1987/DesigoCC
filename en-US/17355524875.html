Modify a Command Table

Modifying a command table for a zone involves editing the points in the modes, or removing the points from the modes.

  1. System Manager is in Engineering mode.
  1. In System Browser, select Application View.
  2. Select Applications > Schedules > APOGEE Zones > [the zone whose command table you want to modify].
  3. The Apogee EQS tab displays.
  4. From the Zone Editor, open the Command Table expander.
  5. Navigate to the mode that contains the point you want to modify or remove.
  6. Do one of the following:
    • To modify a point: Make the necessary changes to the Value and/or Delay fields for each point instance.
    • To remove a point from a mode: Click the X associated with the point instance, and then click Yes when prompted.
      NOTE: If the point is associated with all modes, an additional dialog box displays: To remove the point from all modes, click Yes. To remove the point only from the specific mode, click No.
  7. The points is removed from the modes.
  8. Click Save .
  1. The changes are saved.
