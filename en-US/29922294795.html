Integrating the Manual Measuring Device

This section provides instructions for creating, configuring of Manual Measuring Device and importing data using .CSV file.

For background information, see the reference section.

 

Prerequisites

  • System Manager is in Engineering mode.
  • In System Browser, select Application View.
  • One Manual Measuring Device consumes one device license.
