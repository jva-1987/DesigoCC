Configure the Ownership Station (UL527) for GCNET

If the XNET ownership was set for Panel-control-when-Linked-Panel-has-control, you need to associate control panels and Desigo CC management stations. The management station will take ownership of the fire network when the associated panel has the fire network ownership. Panels that will never take the fire network ownership do not need any station associated.

See a configuration example in GCNET FCC Configuration Reference.

  1. System Manager is in Engineering mode.
  2. You configured a GCNET network with the Ownership Settings = Panel Control when Linked Panel has Control (ULC 527 / UL 864 10th ed.).
  3. The available Desigo CC management stations are configured under Project > Management System > Clients (or > FEP, or > Server).
  1. In System Browser, select Management View.
  2. Select Project > Field Networks > [GCNET network].
  3. Expand the [GCNET network] and select the first FCC that is deputed to take the ownership.
  4. In the FCC Settings tab, open the Ownership Settings expander.
  5. From the Ownership station drop-down list, select the management station associated to the panel for ownership purposes.
  6. In the Linked Buildings section, set the Node Address and the Command Station to match the corresponding configuration in the Zeus tool for each Vlinks Command Station.
  7. Click Save .
  8. Repeat these steps for all the FCC panels under the [GCNET network].
