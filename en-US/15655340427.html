Point Editor

NOTE:
When this editor is opened in Operating mode, all fields are display only and cannot be edited. In order to make changes with this editor, System Manager must be in Engineering mode.

This editor displays the properties of the point selected in the System Browser. The point type is displayed at the top of the editor.

Item

Description

Object Name

Displays the point name.

Object Identifier

Displays the point Object Identifier information. An Object Identifier consists of an object type and instance number. The object type is the BACnet standard object type enumeration value. The field shows the object type and instance number separated by commas.

Description

Displays the user-entered point description.

Alarmable

Displays any BACnet intrinsic alarming for the point.

Fields such as Address settings, Data Type, and others are available depending on the point type. For more information on point characteristics, and for a more inclusive list of point characteristics, see the APOGEE BACnet ALN Field Panel User's Manual (125-3020).
