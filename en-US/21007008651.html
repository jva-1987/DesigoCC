Notification Groups

This section provides reference and background information for handling groups in the Flex Client Notification. For related procedures, see the step-by-step section.

Description

Displays the name and description of the group.

(Applicable only for Reno Plus users) Displays the number of active recipients out of total number of recipients in the group.

Create

Creates a new group. See Create Group in Creating and Managing Groups.

5

Search

Search for a specific group by name.

6



Displays the following options:

  • Edit: Edits the name and description of the group. See Edit Group Details in Creating and Managing Groups.
  • Add recipient: Adds recipients to the group.
  • Delete: Deletes the group from the list. See Delete Group in Creating and Managing Groups.

Group Details

Item

Name

Description

1



Navigates to the Group Workspace page. See Groups Workspace in Notification Groups.

2

Group name

Displays the current name of the group.

3

Recipient list

Displays the list of all the recipients and groups which are part of the group.

(Applicable only for Reno Plus users) Group displays the number of active recipients out of total number of recipients in the group.

4

Search

Search for a specific recipient or group by name.

5



Displays the following options:

  • Add recipient: Adds recipients in the group. See Add Recipient in the Group in Creating and Managing Groups.
  • Create group: Creates another group to the group. See Add Group in the Group in Creating and Managing Groups.
  • Edit group: Edits the name and description of the group.

6

Show group

Navigates to the selected group.

7

Remove

Removes the recipient or group from the group.
