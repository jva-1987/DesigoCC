Configuring Unattended System Events in a Distributed Configuration

Scenario

In distributed multi-server systems, you want to generate an alarm when any of the local systems is not attended. To do that, for each local system, you can configure an event for the System Manned property of the Main Server point. When the local system is unattended, an event will be visible on the other (attended) systems.

Complete this procedure for each local system.

  1. System Manager is in Engineering mode.
  1. In System Browser, select Management View.
  2. Select Project > Management System > Servers > Main Server.
  3. Select the Object Configurator tab, and then, in the Property list, select systemManned.
  4. In the Alarm Configuration expander, on the right-hand side, select Valid.
  5. In the Alarm Configuration group, select Management Station and Alarm kind: Discrete.
  6. In the Alarm Class column, select an alarm class for the event, for example Supervisory_NoAckNoReset (the event will appear and disappear automatically).
  7. In the Value Range column, select OR Operator (││) and False (system manned false means unattended).
  8. In the Event Text column, enter a text for the alarm condition (for example, System Unattended) and the normal condition (for example, System Attended).
    NOTE: You can use the same pair of texts for the Normal row just above.
  9. Select Alarm config.activated.
  10. Click Save.
  1. The unattended system event is configured.
