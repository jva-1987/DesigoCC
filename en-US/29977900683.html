Selecting the Archive Group for Logical Devices

You can archive the measurement point (single) of the logical devices into the long-term or short-term storage. For more information, see Logical Devices. For background information, see Archive Groups.

  1. You have created and configured the device in the project. For more information, see Integrating the Devices.
  1. Select Application View > Powermanager > [area] or [sector].
  2. Select the [device] for which you want to archive the measurement points.
  3. In the Result or Source expander, enable the Archive checkbox for the data point.
  4. Select the archive group [GPM_Long_Term_Miscellaneous] from the Archive Group drop-down list.
    For information on the default archive group values for logical devices measurement points, see Default Archive Group and Filter Group Values.
    NOTE: The GPM_Long_Term_Miscellaneous archive group can be used to archive instantaneous measurement points into the long term storage. You can select any other archive group (as required).
  5. Click Save .
  1. The measurement points are archived into the long-term storage or short-term storage for the selected archive group.

NOTE: Multiple measurement point selection is not possible for logical devices. For more information on applying filters after archiving, see Selecting the Filter Group for Devices.

For background information, see Archive Groups under Measurement Points expander.
