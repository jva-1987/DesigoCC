Additional P2 Offline Trend Editor Procedures

Do the following procedures as needed:

 

Delete a Trend Definition

  1. You have an APOGEE panel with defined trend definitions for your APOGEE data points.
  2. You have selected the point or TEC subpoint with the trend definition you want to delete.
  3. System Manager is in Engineering mode.
  1. In System Browser, select Management View.
  2. Select Project > Field Networks > [Network name] > [Field Panel name] > Points > [Points or TEC to which you want to create a COV trend definition].
  3. In the Apogee Trend workspace, from the Trend Definitions section, select the trend definition you want to delete.
  4. Click Delete.
  5. In the Trend Definitions section, a strikethrough displays over the trend definition entry.
  6. Click Save .
  1. In the Trend Definitions section, the strikethrough entry is removed from the list, indicating that the definition has been removed.

Delete APOGEE Trend Log Objects in Bulk

  1. In System Browser, select Application View.
  2. Select Applications > Trends > Offline Log Objects.
  3. Perform either of the following steps to add the trend log objects to the Edit mode:
    • Select the APOGEE P2 trend log objects to be modified and click Edit Trend .
    • Select the APOGEE P2 trend log objects to be modified. Then, select the New Trend option from the Related Items pane to open the Trends application in the Secondary pane. Click Edit Trend .
  4. Select the objects to be deleted, right-click and select Delete Trend.
  5. A confirmation message displays.
  6. Click OK.
  7. The results of the bulk operation display in the Bulk Operation Details window.
  8. Click OK.
  1. The trend log objects are deleted from System Browser.

 

Manually Collect Trend Data

  1. You have an APOGEE panel with defined trend definitions for your APOGEE data.
  2. You have selected the point or TEC subpoint with the trend definition for which you want to collect data.
  3. System Manager is in Engineering mode.
  1. In System Browser, select Management View.
  2. Select Project > Field Networks > [Network name] > [Field Panel name] > Points > [Points or TEC to which you want to create a COV trend definition].
  3. In the Apogee Trend workspace, from the Trend Definitions section, select the trend definition for which you want to collect trend data.
  4. In the Operation tab, locate the Samples property and click the associated Collect button.
    NOTE: If the Collect button is not immediately visible, scroll to the right.
  1. The collection status displays in the properties display area.

Modify a Trend Definition

NOTE:
To ensure that no trend collection data is lost, manually collect trend data before modifying a trend definition.

  1. You have an APOGEE panel with saved trend definitions for your APOGEE data points.
  2. You have selected the point or TEC subpoint with the trend definition you want to modify.
  3. System Manager is in Engineering mode.
  1. In System Browser, select Management View.
  2. Select Project > Field Networks > [Network name] > [Field Panel name] > Points > [Points or TEC to which you want to create a COV trend definition].
  3. In the Apogee Trend tab, from the Trend Definitions section, select the trend definition you want to modify.
  4. Make the necessary changes in the Trend COV Limit (for COV trend definitions), Panel Buffer, and Conditional Trend sections.
    NOTE: For interval trend definitions, you cannot modify the Trend Sampling Interval section.
  5. In the Trend Definitions section, the modified trend definition entry is italicized.
  6. Click Save .
  1. In the Trend Definitions section, the modified entry displays as regular text, indicating that the changes have been saved.

Modify APOGEE Trend Log Objects in Bulk

  1. In System Browser, select Application View.
  2. Select Applications > Trends > Offline Log Objects.
  3. Perform either of the following steps to add the trend log objects to the Edit mode:
    • Select the APOGEE P2 trend log objects to be modified and click Edit Trend .
    • Select the APOGEE P2 trend log objects to be modified. Then, select New Trend from the Related Items pane to open the Trends application in the Secondary pane. Click Edit Trend .
  4. Select the objects to be modified, right-click, and select Modify Trend.
  5. The properties of the selected objects display.
  6. Perform the required updates to the trend log objects and click Start Modification .
  7. The results of the bulk operation display in the Bulk Operation Details window.
  8. Click OK.

 

View a Trend Definition

  1. You have an APOGEE panel with defined trend definitions for your APOGEE data points.
  2. System Manager is in Engineering mode.
  1. In System Browser, select Management View.
  2. Select Project > Field Networks > [Network name] > [Field Panel name] > Points > [Points or TEC to which you want to create a COV trend definition].
  3. Do one of the following:
    • If you are viewing a trend definition for a point: Select the Points sub-folder. A list of all the data points displays in System Browser, and the Apogee Trend tab displays.
    • If you are viewing a trend definition for a TEC subpoint: Select the desired TEC . A list of the TEC subpoints displays in System Browser, and the Apogee Trend tab displays.
  4. In System Browser, navigate to the data point or TEC subpoint whose trend definitions you want to view, and then select the trend definition.
  5. Select the Apogee Trend tab.
  1. The trend definition displays.
