Generate and View Powermanager Reports

  1. You have configured Powermanager reports in the Installed client.
  1. Select Application View > Powermanager > Report Definition > [Powermanager reports].
  3. In the Reports tab that displays, click Generate.
  4. Select PDF or Excel or Both to generate the report in the required format.
  6. Enter the Duration, Interval Type, and Interval Length. Based on the selected Duration, the Interval Type will vary.
    For example, if the Duration = Custom, second, minute, hour, and day can be selected for the Interval Type.
    Only for the Custom duration, the From Date time and To Date Time fields can be filled. If these fields are filled for other durations, an error message will be displayed while generating a report.
  8. Click Run.
  9. You can view the generated reports in the selected format. The EN50160 report can only be generated in PDF format.
