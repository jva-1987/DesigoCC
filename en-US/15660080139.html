Enable the Web Server

Perform these steps if you plan to use Field Panel Editors hosted by the APOGEE field panel.

You must enable the Web Server option on all panels accessed by the editors and viewers.

You can enable the Web Server option on a panel before or after loading/upgrading the user interface files on the chosen host panel(s).

You do not need an APOGEE Editor or FPWeb UI license installed on panels to access the editors’ and viewers’ links in Desigo CC.

Use these procedures to enable Web Server using the HMI

S, H, E, W, M (System, Hardware, Ethernet, Webserver, Modify)

Example:

10:13:04 07/30/2010 FRI Logged on successfully Field panel <40091>

User: <high> <High default user account>

>Point, Application, Time, Message, Cancel, System, passWord, Bye? s

>Diagnostics, Users, dSt, Bacnet, Error_msgs, Hardware, Text, Quit? h

>Fieldpanels, Ethernet, nodeNametable, Disks, Reportprinter, Licensemanager, Quit? e

>ipSettings, Bbmd, sNmp, Telnet, Webserver, Quit? w

>Display, Modify, Uiupgrade, Graphicsbackup, Quit? m

>Webserver Enabled (Y/N) : y

>Ok to coldstart (Y/N) : y

Use these procedures to check the enabled/disabled status of Web Server

S, H, E, W, D (System, Hardware, Ethernet, Webserver, Display
