Create a Data Point Table

You can create the Data point table widget displays the live values from the devices for all the selected sources in the tabular view. For background information, see Data Point Table Workspace.

  1. In the dashboard, select the Data point table from Create widget list.
  2. Click Next.
  3. The Create widget page opens.
  4. Click Add to select the data point.
  5. Select the device from the list and click Select.
  6. Select the Data point from the drop-down.
  7. The Data point table is created and displays the live values form the devices for the selected source in the tabular view.
  9. Repeat the steps 3 to 5 to add additional data points. You can add an unlimited number of data points to the table. Only 10 data points are in a page, with any remaining data points appearing on subsequent pages.
  10. Click Create to add the widget to the dashboard.
  11. Click Save.
  1. The Data point table is created in the dashboard.
