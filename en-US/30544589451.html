Check Licenses

The following section describes how to check Desigo CC licenses in the Flex web/desktop app.

Checking Licenses in the Flex App

  1. From the views list box, select Management View.
  2. Select Project > Management System > Servers > Main Server > Licenses.
  3. The current license mode displays on top.
  4. The full list of installed license features displays in the Licenses tab, below the license mode.
  5. In the search box on top of the list, enter a specific text to filter data to the wanted result.
