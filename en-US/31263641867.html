Default period

The default period in the dashboard defines the time frame for the dashboard and the widgets to fetch data from the devices and display it in the widgets. This selection is applicable only to the Consumption chart and Trend widgets on the dashboard. Depending on the selected period, the consumption chart and trend displays the data.

Advanced

Allows to open the advanced mode for selecting the period. It contains Reference point and Range to customize the period.

- Reference point: Allows you to select the reference point to change the Range according to it.

- Today: Enable the check box to set the current day as the Reference point.

- Range: Allows you to define the range for the data point based on a reference. The range can be specified in terms of Days, Weeks, Months, or Years, considering options such as Before, After, and Within.
For example, if Range = 2 : Week : After, means that the data point will be calculated for next two weeks from the Reference point.

By default, the following periods are available for the selection:
- Last 24 hours: Displays the data measured up to the current local system time from 00:00 hours of the past 24 hours. For example, if today is 22nd of March and 16:00 hrs is the current time, the data measured from 21st March 16:00 hours to 22nd March current time is displayed.

- Last 7 days: Displays the data measured up to the current local system time from 00:00 hours of the past 7th day. For example, if today is 22nd of March, the data measured from 16th March 00:00 hours to 22nd March current time is displayed.

- Last 14 days: Displays the data measured up to the current local system time from 00:00 hours of the past 14th day. For example, if today is 22nd of March, the data measured from 9th March 00:00 hours to 22nd March current time is displayed.

- Last 20 days: Displays the data measured up to the current local system time from 00:00 hours of the past 20th day. For example, if today is 22nd of March, the data measured from 3rd March 00:00 hours to 22nd March current time is displayed.

- Last 30 days: Displays the data measured up to the current local system time from 00:00 hours of the past 30th day. For example, if today is 22nd of March, the data measured from 21st February (2025) 00:00 hours to 22nd March current time is displayed.

- Last 60 days: Displays the data measured up to the current local system time from 00:00 hours of the past 60th day. For example, if today is 22nd of March, the data measured from 22nd January 00:00 hours to 22nd March current time is displayed.

- Last 90 days: Displays the data measured up to the current local system time from 00:00 hours of the past 90th day. For example, if today is 22nd of March, the data measured from 23rd December (2024) 00:00 hours to 22nd March current time is displayed.

- Last 180 days: Displays the data measured up to the current local system time from 00:00 hours of the past 180th day. For example, if today is 22nd of March, the data measured from 23rd September (2024) 00:00 hours to 22nd March (2025) current time is displayed.

- Last year: Displays the data measured up to the current local system time from 00:00 hours of the past 1 year. For example, if today is 22nd of March, the data measured from 23rd March (2024) 00:00 hours to 22nd March (2025) current time is displayed.
