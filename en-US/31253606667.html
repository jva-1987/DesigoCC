Create Dashboard Workspace

Dashboards can be created in the system/area/device using the Create dashboard option. This allows you to add widgets to the dashboard in the form of charts and trends.

1

Dashboard name

Allows you to enter a name for the dashboard, which will be displayed at the top left.

2

Default period

Displays the default period for the dashboard and its widgets. It allows you to define the default period to fetch data from the devices and display it in the widgets for the selected period. This selection is applicable only to the Consumption chart and Trend widgets on the dashboard. For more information, see Default period.

3

Set as default

Select the toggle to set the dashboard as default dashboard.

4

Create

Allows you to create the dashboard in the required section.

5

Cancel

Allows you to cancel the dashboard creation at anytime.
