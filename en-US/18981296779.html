Creating Management Station Scheduler

To create a Management station scheduler and start working with these schedulers, you must first create and configure scenes and associate data points with the scenes.

Add and Configure Scenes

  1. In the System Browser, select the Schedules folder.
  2. The Schedule tab displays. Any existing calendars or schedulers display in a tile view.
  3. Click Add, and thereafter in drop-down list select Management station scheduler.
  4. The Scenes tab displays with a default scene added.
  5. Enter the name of the scene in the Name field.
  6. To add more scenes, click the Add drop-down list, and select Add scene from the menu options. For more information, see Scene Editor in Management Station Schedules.
  1. The scenes are added to the Management station scheduler.

 

Add Data Points

  1. Click the Add drop-down list and select Add data point.
  2. The Select data point dialog box displays.
  3. Select the data points that you want to add and then click Select.
    NOTE: It is not possible to add a data point when either Management station scheduler or the selected data point is validated.
    • You can either select a single data point or multiple data points by using multi-select option. For more details, see Multi-select in System Browser.
      Click  to find objects. For more details, see Filter in System Browser.
  4. The Configure selected data points dialog box displays.
  5. Specify different values for the data point property (by default, Present value) by changing the displayed values.
    NOTE: If you do not want the data point to be associated with a particular scene, select  next to the name of the scene and select Deactivate data point. To associate the data point with the same scene, select Activate data point.
  6. (Optional) Select the Select property option next to data point name to change the data point property value. You can select the property value from the displayed drop-down list.
  7. Click Add to save the scheduler with the configured scenes.
  1. The data points are added to all the scenes and the Management station scheduler is created.
