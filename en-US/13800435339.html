APOGEE FPWeb UI

Except for the Subpoint Editor, which is only available through FPWeb UI in Desigo CC, all editors and features of the FPWeb UI are similar to those in the Field Panel Web Server program. For detailed information on using FPWeb UI, see the BACnet Field Panel Web Server User Guide (125-3584).

NOTE:
Web pages hosted by APOGEE field panels use Adobe Flash technology, which your browser might not support. Other options are available for editing APOGEE field panels that do not rely on Adobe Flash. See About the APOGEE Field Panel Editors for a list of APOGEE field panel editing options.

Using FPWEB UI

To use FPWeb UI, perform the following steps:

  1. In System Browser, select Management View.
  2. In System Browser, navigate to and select the object (point, PPCL, or FLN device) whose data you want to edit or view in FPWeb UI.
  3. If the item is supported by FPWeb UI, the Related Items tab (Operating mode) or Extended Items tab (Engineering mode) displays one or more links for the object.
    NOTE: When an editor is opened in Operating mode, all fields are display only and cannot be edited. In order to make changes with an editor, System Manager must be in Engineering mode.
  4. Click the appropriate link.
  5. The Secondary Pane opens and displays a license agreement.
  6. Accept the terms of the license agreement by clicking ACCEPT.
  7. In the Secondary Pane, the FPWeb UI logon screen displays.
  8. Enter your FPWeb UI Username and Password.
  9. Click Login.
  10. In the Secondary Pane, the selected FPWeb UI editor displays with a minimized navigation pane on the left.
    NOTE: To expand FPWeb UI so that the navigation pane is visible, click the vertical expander on the left side of the editor.
  11. Do one of the following:
    • If you are viewing data in the FLN Subpoint Selector, see APOGEE FLN Subpoint Selector.
    • If you are viewing data for any other editor, or are using other features of FPWeb UI, see the BACnet Field Panel Web Server User Guide (125-3584).

Edit Subpoints

  1. In System Browser, select Management View.
  2. In the System Browser tree, navigate to and select the TEC whose data you want to edit.
  3. If the item is supported by the FPWeb UI, the link Set/ReleaseTECInitialValues displays in the Extended Items tab.
  4. Click the link. The Secondary Pane opens and displays the editor.
  5. Double–click on any row to edit its properties.
  6. Click Initialize TEC to load initial values into the TEC.
  7. Click Update Panel to save the current initial values of the TEC into the field panel.
  8. Click Refresh to refresh the values displayed in the editor.
