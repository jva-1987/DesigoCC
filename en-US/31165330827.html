Gauge Chart Workspace

The Gauge chart displays the live value from the device for the selected source. This widget supports only the numerical and boolean format values from the selected source.

1

Displays the gauge chart for the selected data point with minimum and maximum ranges.

2

Displays the device type added as a source for the widget.

3

Displays the name of the widget.

4

Settings

Displays the Widget name field to change the widget name and Threshold settings.

- Widget name: Displays the widget name. You can change the name if required.

- Threshold settings: You can modify the Threshold settings for the gauge based on the Auto scaling option in the Scale tab. If Auto scaling is disabled on the Scale tab, the threshold range can be defined using the conditions Normal, Caution, and Danger as shown in the below image:

5

Source

Displays the common elements such as Data point, Delete, Edit, and Add like all the widgets.

6

Scale

Displays the Minimum and Maximum value selector, Auto-scale, and Invert scale options for configuring the gauge.

- Min.: Specify the minimum range for the gauge if Auto-scale is disabled.

- Max.: Specify the Maximum range for the gauge if Auto-scale is disabled.

- Auto-scale: By default, the Auto-Scale is enabled. To change the minimum and maximum values, disable the auto scaling. This enables the Invert scale option. Additionally, this enables the Threshold settings in the Settings tab, which allows you specify the threshold range for the gauge.

- Invert scale: Invert the scale of the gauge. For example, if the invert scale option is enabled for voltage, the range starts from maximum to minimum (240V to 0V) instead of minimum to maximum (0V to 240V).
