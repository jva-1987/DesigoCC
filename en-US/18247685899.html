Running the Network Wizard for APOGEE BACnet

Using the Network Wizard is the recommended way to configure APOGEE BACnet. The wizard helps you create an APOGEE BACnet network and driver, as well as import devices. Complete the following procedures:

1 – Select the APOGEE BACnet Subsystem

  1. Select Project > Field Networks.
  2. Click the Network Wizard tab.
  3. The Subsystem selection section displays.
  4. From the Available subsystems drop-down list, select Apogee BACnet.
  5. Click Next page .

 

2 – Add Network Information

  1. Enter the network name and description.
  2. (Optional) To change the language selection, click the flag icon in the Network description field, select the desired language, enter the desired text, and then click OK.
  3. Click Next page .

 

3 – Select a Workstation and Driver

  1. From the Station Selection drop-down list, select the workstation your subsystem will be connected to.
  2. From the Driver selection drop-down list, do one of the following:
    • If you select New driver, click Next page . The wizard displays Step 4 of 6. Go to the Enter Driver Information topic.
    • If you select an existing driver, click Next page . The wizard displays Step 5 of 6. Go to the Import APOGEE BACnet Devices topic.

 

4 – Enter Driver Information

  1. Do the following:
    • (Optional) In the Driver description field, change the descriptive text. To switch languages, click the flag icon, select the desired language, enter the desired text, and then click OK.
    • Select a Port ID and Network number or accept the defaults.
    • From the Network adapter drop-down list, select the hardware adapter this driver will use.
    • From the IP address drop-down list, select the IP address this driver will use.
    • In the UDP port field, either accept or modify the default setting.
    • In the Instance number field, either accept or modify the default setting.
  2. From the Type drop-down list, select the desired type of advanced connectivity.
  3. If you select None, skip to the final step of this topic.
  4. If you select BBMD, do the following:
    • Click Add.
    • Enter the IP Address of the device serving as the BACnet Broadcast Management Device (BBMD), and accept the default UDP port and Subnet mask entries. These settings become part of the Broadcast Distribution Table for other BBMDs that you want the management station to communicate with.
    • Skip to the final step of this topic.
  5. If you select Foreign device (remote BBMD) do the following:
    • Enter the IP address of the remote BBMD that the foreign device will register with. Foreign devices can communicate directly with any other BACnet device on the network, but they must register with a BBMD to receive broadcasts from BACnet devices on other IP subnets.
  6. Click Next page .

 

5 – Import APOGEE BACnet Devices

  • Do one of the following :
    • Select Skip this step, I’ll do it later, and then click Next page .
    • Select Discover them from the network. Select this option if there are devices visible in the BACnet Object Browser. If you do not see your devices in the BACnet Object Browser, they will not appear in the management station. Then click Next page .
    • Select Import configuration files. If you have configuration files, you can drag and drop them into the import area, or you can browse for them. Choose the desired import option: all items, or selected items, and then click Next page .

 

6 – Review Summary Information

  1. Review the network information for accuracy. If you need to modify any of it, click Previous page until you arrive at the location where you need to modify information, and then resume your Network Wizard steps until you are satisfied with the configuration.
  2. Click Run Configuration .
  3. Click Yes.
