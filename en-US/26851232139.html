Configuring Log Entries in Mobile Flex

A warning is displayed in Log Viewer workspace if the maximum limit of the log entries is exceed.

  1. In System Browser, tap Application View > Log Viewer.
  2. Do any of the following to change the View size to view maximum of log entries.
    • Tap and select Show Log view properties.
    • Tap  and navigate to Properties.
  3. Tap  to toggle from Basic to Advanced.
  4. Edit the View Size property.
  5. Tap  to close the additional information pane.
  6. The View Size of log entries in Master pane is updated.
  7. For filtering the log entries and viewing history logs, see Filtering of Log Entries and Viewing History Logs in Managing Log Viewer.
