Configuring a GCNET Fire Network

Scenario

You want to configure Desigo CC for connecting fire control panels (Desigo Fire Safety Modular and Cerberus Pro Modular only) on a GCNET network.
For related information, see:

  • VNT Configuration in GCNET
  • Block Commands and System Behavior
  • XNET Ownership Reference
  • UL/ULC Compliance: XNET Fire Panel Settings section in the Compliance Notice for UL Norms page or Compliance Notice for ULC Norms page.

Prerequisites

  • The extension modules corresponding to the specific fire panels in use were installed and included in the active project. They can be either of the following:
    - Desigo Fire Safety Modular UL
    - Cerberus Pro Modular UL
  • In the Zeus tool, you have configured all the XNET networks (buildings) of the GCNET.
    In Zeus, from Tools > CreateVNT (GCNET) Configuration, select the XNET networks (buildings) and click Create to create the gms_gcnet.xml file in the GCNET subfolder of the Zeus path.
    NOTE: Subsequently, to update the exiting configuration, select the modified buildings only.
