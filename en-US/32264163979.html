Troubleshooting ApplicationCertificate cannot be found

When connecting to an OPC UA server, the following error might occur:

ApplicationCertificate cannot be found

This might happen after the certificate is regenerated.

To solve this issue, do the following:

  1. Stop the OpcUaAdapter service.
  2. Open the OpcUaAdapter Properties.
  3. Select the Log On tab.
  4. Select the This account option.
  5. Enter the name of the user (who regenerated the certificate).
    NOTE: This user must have administrator privileges.
  6. Enter and confirm the password.
  7. Click Apply and OK.
  8. Restart the service.
