Schedules

The Schedules application in Flex Client allows you to perform the following activities:

  • Set up schedules to automate the operation of the site: You can define a schedule on a daily basis and specify a different hourly timetable for each day of the week. For example, you could schedule a heating system to work from 9 a.m. to 6 p.m. on Mondays and Fridays and from 8 a.m. to 8 p.m. on Tuesdays, Wednesdays, and Thursdays.
  • Set up exception calendars, which can be associated to schedules: You can define calendars that define the dates (or date ranges) during which a schedule does not apply. For example, you can create a holiday calendar that overrides the regular heating schedule to reduce energy costs. Thereafter, you can associate one or more schedules with the calendar.
  • Search for existing schedules and calendars
  • View and edit schedules
  • Copy calendar entries for a particular day to other days of the week
  • View and edit calendars

If you navigate to any location within or outside the Schedules application, such as another tab, view, or any other application, then on switching back, you will see the same state of the schedule or calendar entry (for example, the particular date, week, or time range). For example, assume that you are in the Calendar view and the current week (13th September to 19th September) is selected. Now, if you navigate to the List view and switch back to the Calendar view, you will see the same current calendar entry for the week (13th September to 19th September) selected.
