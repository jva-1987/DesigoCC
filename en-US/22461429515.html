APOGEE BACnet Schedule Optimization Editor

For background information, see the reference section.

Complete the following procedures as needed:

 

These procedures are intended for the high-level user in the building system. Improperly optimizing the facility may cause severe damage to equipment. Please contact your building control representative before using the optimization feature.

 

Select only BACnet optimized schedules. Schedules that are not optimized will display an empty Optimization (SSTO) tab.

 

Optimize a BACnet Schedule

You can optimize the performance of your system with schedule optimization. Optimization allows the system to begin heating or cooling the facility in advance of the facility's next schedule event or mode change. By using optimization, the facility will be at the correct temperature when the event begins and ends.

Additionally, schedule optimization has the capability to "learn" your operating conditions. Based on your equipment's response times to the climatic conditions inside and outside of your facility, schedule optimization is capable of automatically adjusting the lead times needed for optimal performance.

Prerequisite: Set up an Optimization Schedule

  1. System Manager is in Engineering mode.
  2. System Browser is in Management View.
  1. Select Project > Field Networks > [APOGEE BACnet network] > Hardware > [APOGEE BACnet device] > [APOGEE BACnet device point] > [BACnet schedule].
  2. Select the Optimization (SSTO) tab.
  3. The Settings, General, Start, Stop, and Night expanders display.
  4. NOTE: SSTO Schedule Optimization requires that all command objects use the TxG_Apogee_SSTO_Action_Texts. The system assumes that all command objects in the list are homogenous, so it checks only the first command object in the list for SSTO optimization criteria.
  5. Click the Settings expander and select the unit of measurement.
  6. Click the General expander and complete all the fields.
  7. Click the Start expander and complete all the fields.
  8. Click the Stop expander and complete all the fields.
  9. Click the Night expander and complete all the fields.
  10. Click Save .
  1. The optimization parameters are defined for the BACnet schedule.

Enable SSTO Optimization for the Command Object

Before configuring SSTO, the user must select the correct action texts on the Schedule tab. If this step is not completed, the user who attempts to enable SSTO on the Optimization (SSTO) tab will receive an error message to configure the correct text group for the command object.

  1. System Manager is in Engineering mode.
  2. System Browser is in Management View.
  1. Select ApplicationView > Schedules > BACnetCommands.
  2. Select the Schedule tab.
  3. From the Text group drop-down, select TxG_Apogee_SSTO_Action_Texts.
  4. Click Save .

NOTE: After device re-discovery, the text group might change to a project-specific text group.

Modify BACnet Schedule Optimization

  1. System Manager is in Engineering mode.
  2. System Browser is in Management View.
  1. Select Project > Field Networks > [APOGEE BACnet network] > Hardware > [APOGEE BACnet device] > [APOGEE BACnet device point] > [BACnet schedule].
  2. Select the Optimization (SSTO) tab. If TxG_Apogee_SSTO_Action_Texts are not selected, the SSTO tab will not be available. See the above steps (‘Enable SSTO Optimization”) for more information on selecting the correct action texts.
  3. The Settings, General, Start, Stop, and Night expanders display.
  4. From the schedule editor, make the necessary optimization changes.
  5. Click Save .
  1. The changes are saved.

NOTE: At the point when the user clicks “Save,” the system will recreate any command object that has SSTO newly enabled. Because SSTO causes these command objects to be recreated, other applicable validation steps (for example, “Four Eyes validation”) will also be triggered upon save.

If SSTO is not available after you click Save, rediscover the panel to enable it again.

The action list will be checked for the following criteria at the point of save:

VAC 1 / OCC1 2 / OCC2 3 / OCC3 4 / OCC4 5 / OCC5 6 / WARMUP 7 / COOLDOWN 8 / NIGHT_HTG 9 / NIGHT_CLG 10 / STOP_HTG 11 / STOP_CLG 12
