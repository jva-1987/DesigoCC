Installing and Configuring Windows Hyper-V Virtualization Environment

Scenario

You want to install and configure Windows Hyper-V for running Desigo CC in virtual machines.

This page refers to Windows Server 2025. For more information about workflows and compatibility, see https://learn.microsoft.com/en-us/windows-server/virtualization/virtualization.

Prerequisites

  • You have a category B computer with any version of Windows Server (Desktop Experience) installed.
  • You have a Windows license for all the virtual stations you intend to create.
  • You have Windows ISO disk-image file for all editions you need to install.
  • UL only: You have located the COM ports associated to your USB devices (Comark Card and SNC Card)
  • You have checked the firewall to allow port 3240 (default value, can be changed).
