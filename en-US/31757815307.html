Condition Monitoring Workspace

The Condition monitoring widget displays the breakers condition, including its health and remaining lifetime, in both graph and table formats. The graph shows the breakers health percentage on the X-axis and remaining lifetime on the Y-axis. The table contains details such as the breaker name, health, remaining lifetime, maintenance recommendation, trip count, and more.

1

Displays the name of the widget. You can modify it from the Settings tab.

2

Displays the graph for the breaker health and remaining lifetime (in year) for the selected breakers in the Source tab. Hover over the graph to see a tool tip displaying the breaker name, remaining lifetime, breaker health, and maintenance recommendation.

3

Total Breakers

Displays the numbers of breakers selected for monitoring.

High

Displays the count of breakers that are highly recommended for maintenance.

Medium

Displays the count of breakers that are moderately recommended for maintenance.

Low

Displays the count of breakers that are less recommended for maintenance.

4

Breaker

Displays the breaker name.

Health

Displays the breaker health in percentage.

Remaining Lifetime (in years)

Displays the life time remaining in years for the breaker.

Recommendation for maintenance

Displays the status as High, Medium, or Low as a recommendation for breaker maintenance.

State

Displays the breaker state as Unknown, Not ready, Tripped, Switched On or Switched Off.

Trip count

Displays the number of trips that have occurred for the breaker.

Order Number

Displays the order number of the breaker.

5

Settings

Widget name: Displays the widget name. You can change the name if required.

6

Source

Contains the list of available breakers in the system, area, or device. By default, all the breakers are selected for the widget. You can disable the check box if required.
