Command Table

Configuring command tables for zones is optional. The Command Table expander displays the zone modes and points associated with them for the defined zone. When a zone is in a certain mode, the associated point for that mode takes on the value in the Command Table.

When a mode has an associated point in the Command Table, the following items display:

Item

Description

Name

Displays the name of the point.

Value

Displays the value the mode takes when it is in this mode.

> Type a value the mode will go into when the zone is in that mode.

Delay

Displays the time in seconds to delay before moving in to another mode.

> Type a value, in seconds, to delay before the zone moves to another mode.
