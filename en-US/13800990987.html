Configuring the BT BACnet Stack

  1. System Manager is in Engineering mode.
  2. A BACnet driver has been added and started.
  1. In System Browser, select Management View.
  2. Depending on where the BACnet Driver is located (Desigo CC server or FEP station), do one of the following:
    • Select Project > Management System > Servers > Main Server > Drivers
    • Select Project > Management System > FEPs > [FEP station] > Drivers
  3. Click the BACnet tab.
  4. Open the BT BACnet Stack Config expander.
  5. In the BT BACnet Stack Gateway Port Table section, click Add, and then select BACnet/IP or Ethernet.
  6. In the Port Properties expander, set the Network Number where your management station is connected (typically=1).
  7. Leave the Attached check box selected if you want the router port attached and accessible to other devices on the BACnet network.
  8. In the Adapter drop-down list, select the network adapter this driver will be using. The adapter does not appear with a valid IP address unless it is communicating on a network.
  9. Do one of the following:
    • If you are running Desigo CC on a computer without Datamate Advanced (DMA), accept the default IP Address and UDP Port settings.
    • If you are running Desigo CC and Datamate Advanced (DMA) on the same computer, make sure that the default UDP setting does not conflict with the UDP setting for DMA. The two UDP port numbers must be unique when they are on the same management station.
  10. (Optional) To add a Virtual Port, click Add and then select Virtual.
  11. (Optional) Configure the Physical Port as BBMD or Foreign Device.
  12. Click Save .
