Read the XNET Fire Panel Settings

After the configuration import, you can optionally see the parameter settings of the XNET panels, as configured in the Zeus tool.

  1. System Manager is in Engineering mode.
  2. You imported the configuration file.
  1. In System Browser, select Management View.
  2. Select Project > Field Networks > [XNET network].
  3. Expand the [XNET network] and select a panel.
  4. In the XNET tab, open the Panel Settings expander.
  5. The parameter list of the panel displays. For more information, refer to the reference page.
