Creating and Managing Groups

This section provides step-by-step instructions on how to create, update, and remove group from the Flex Client.

Create Group

  1. In the top navigation bar, select System.
  2. In the left side bar, click .
    • Navigate to Notification > Groups.
  4. The list of groups displays.
  5. Click Create.
    • Enter Name and Description of the group.
  6. Click Save.
  1. The new group is added to the tiles view.

Edit Group Details

  1. The group details to be modified is present in  Notification > Groups.
  1. Select the group or search the group name in Search field.
  2. Click  and select Edit from the menu options.
    • Modify the group Name and Description.
  3. Click Save.
  1. The group details are modified.

Delete Group

  1. The group to be deleted is present in  Notification > Groups.
  1. Select the group or search the group name in Search field.
  2. Click  and select Delete from the menu options.
  3. In the confirmation message that displays, click Delete.
  1. The group is deleted from the list.

Add Recipient to the Group

  1. The group where recipient needs to be added is present in  Notification > Groups.
  1. Select the group or search the group name in Search field.
  2. Click  and select Add recipient from the menu options.
  3. The Add recipient dialog box displays with the list of recipients.
  4. Select the checkbox corresponding to the recipient you want to add to the group and click Create.
  1. The selected recipients are added in the group.

Add a Group to Another Group

  1. The group to add in another group is present in  Notification > Groups.
  1. Select the group or search the group name in Search field.
  2. Click the group tile to open the group details.
  3. List of group recipient displays.
  4. Click  and select Create group.
  5. The Create group dialog box displays with the list of groups.
  6. Select the checkbox corresponding to the group you want to add to the group and click Create.
  1. The selected groups are added in the group.

Remove Recipient / Group from an Existing Group

  1. Recipient or group to be removed from an existing group is present in  Notification > Groups.
  1. Select the group or search for a group name in Search field.
  2. Click the group tile to open the group details.
  3. List of recipients in the group display.
  4. Select the specific recipient or group to be removed and click Remove.
  5. In the confirmation message that displays, click Remove.
  1. The recipient or group is removed from the group.

View Recipient Groups of Distributed Systems in Flex Client

  1. Systems are in a distributed environment.
  2. Recipients are present in distributed systems
  3. In Flex Client, the Application View of each system is visible
  1. In the top navigation bar select System.
  2. To view recipients of System 1 perform the following steps:
    • In the System Browser, select the Application View (System [X])
    • In the left side bar, click .
    • Navigate to Notification > Groups.
  5. System1 recipients are displayed. You can view and modify the recipients information of System 1.
  6. To switch to a different system and view or edit recipients of System 2 perform the following steps:
    • In the left side bar, click  Hierarchies and in the System Browser select Application View (System 2).
    • In the left side bar, click .
    • Navigate to Notification > Groups.
  9. System 2 recipient groups are displayed. You can view and modify the recipient group information of System 2.
