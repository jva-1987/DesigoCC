Importing the APOGEE BACnet Database

  1. System Manager is in Engineering mode.
  2. You have copied the exported database files to the computer running the Desigo CC server. It is recommended that you create a file location/folder name such as ApogeeDB.
  3. You have created a BACnet network in the Management View for each ALN in the APOGEE Automation System.
  4. (Optional) You have created a logical view in Desigo CC to map to an imported logical view.
  1. In System Browser, select Management View.
  2. Select Project > Field Networks.
  3. Select the network where you will import the database.
  4. In the Primary pane, click the Import tab.
  5. Click the Browse button.
  6. In the Open dialog box, navigate to the directory containing the database.
  7. Select the appropriate .xml file, and then click Open.
  8. (Optional) From System Browser, do the following:
    • Select the Manual Navigation check box.
    • Drag any pre-configured node you created in the logical view to the Hierarchies Mapping section.
  9. The node is now an available option for the next step.
  10. In the Hierarchies Mapping section, select the option that applies to this import.
  11. In the Source Items list, select all of the items in the list by clicking Move all items .
    NOTE: You should import everything in the list because of device and object interdependencies. If you don’t, you might encounter issues such as devices on your network not communicating properly.
  12. Click Import.
  13. The import procedure starts. When completed, the Import dialog box displays.
  14. If you want to view details of the import, click Open Log. Otherwise, click OK.
