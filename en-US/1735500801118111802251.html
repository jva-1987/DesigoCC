Adding FLN Application Libraries

During the integration, you are asked to select FLN application libraries. Since there are hundreds of FLN applications, select only those needed for your project. Otherwise, you will hinder system performance. Also, there are FLN libraries for both EN (US Standard) and SI (Metric) environments. Install only those needed for your environment. In other words, install one group or the other, but not both.

The project template BA_NA includes an FLN Application Guide that shows which libraries must be imported for the various TEC application numbers. You can find the guide in the Desigo CC System Browser. Once you have selected Application View and Show Description, select:

Applications > Documents > FLN Application Library Guide

Alternatively, you can click the link at the end of this topic to view the full list of supported applications.

Importing the FLN Libraries

  1. System Manager is in Engineering mode.
  1. In System Browser, select Management View > System Settings > Libraries.
  2. Click the Library Configurator tab.
  3. Click the Import button.
  4. The Import Libraries dialog box displays.
  5. Select the [GMSProject] > Libraries > Exports folder.
  6. From the list of libraries, select only the FLN libraries you need for your project—those that correspond to your FLN applications.
  7. Click Open.
  8. When asked if you want to import the folder structures for the various libraries, click Yes for individual libraries, or Yes to all for all the libraries you selected.
  1. The folder structure is added to the Libraries > BA (HQ) > Room equipment folder.
