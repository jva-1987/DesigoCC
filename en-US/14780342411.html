Overview of the Comark Monitor Card

The Comark monitor card provides a watchdog timer for the Desigo CC stations to control the proper functioning of the system. If the program is running properly, Desigo CC software regularly refreshes the watchdog timer. If not refreshed within a configurable timeout (default is 30 sec), the card can activate an audible alarm and then (by default after 90 sec) can force a computer reset to restart the software.

The card can supervise the computer temperature and fan speed, as well as 4 digital inputs for external devices. In case any of these elements shows an abnormal status related to configurable thresholds, an alarm condition is detected that can be acquired and treated by Desigo CC software.

In addition, the card provides for a relay output that you can program to report trouble conditions detected by Desigo CC software.

Hardware Installation

A maximum of two cards can be installed. The Comark monitor card is directly connected to the computer motherboard and allows monitoring the computer devices via USB mapped on a serial port. It can also be connected to the computer fan and reset to monitor the fan status and force the PC reset. Detailed information about the fire panel connection is provided in the following sections.

The card comes pre-installed in new computers along with the required drivers. In case you need to replace the card, please contact Technical Support.

Configuration

In the Desigo CC configuration, the Comark card is one of the drivers of the stations.
