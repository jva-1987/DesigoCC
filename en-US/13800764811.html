Modifying the FLN Subpoint List

  1. System Manager is in Engineering mode.
  1. In System Browser, select Management View.
  2. Select Project > Field Networks.
  3. Select the network with the FLN subpoint list you want to modify.
  4. Click the FLN Subpoint Selector tab.
  5. In the Application Selector section, select the application whose subpoints you want to modify.
  6. In the Subpoint Selector section, scroll through the list, and click the check boxes in the Enabled column to enable or disable the subpoints.
  7. Click Save .
