System Workspace

When you select System in the horizontal navigation bar, the system monitoring workspace displays below the Summary bar.

1

In the vertical navigation bar on the left, by selecting  or directly selecting an icon, you can choose between different views. Default selection is  Hierarchies.

2

By default, the workspace is arranged as follows:

  • Selection pane, next to the vertical navigation bar on the left.
    Depending on the selected view, this pane can display one of the following:
    • In  Hierarchies, a tree for navigating and selecting system objects.
      Depending on how the pane width is reduced, this navigation tree displays its objects in a hierarchical structure where you can expand a parent node to display its child nodes, or the tree will display as a flat list.
    • Other views. For example,  Notification or  Devices.
  • Primary pane, next to the Selection pane.
    Depending on the project configuration, other applications become available in this pane for the selected system object.
    For example, List view, which displays details of objects, or Graphics (for displaying site floor plans) and so on.

By clicking the button on the splitters, can you can expand/collapse panes.

To handle layouts (change layout, lock layout, and so on), see Adjust Layout. For more details about layout types, see the table below.

Investigative treatment is also available on top of System workspace. For instructions, see Handling an Event with Investigative Treatment.

3

By default, the right panel is collapsed.

If you select an object in the System tree:

  • By selecting  on the right, the right panel expands and displays the Properties application for inspecting and commanding the properties for the selected object. It also includes any object-related items (such as Trend to work with trend data, Report for generating and exporting reports; and so on) that you can display by selecting the corresponding tab.
  • By selecting one of the related-items icons on the right, the right panel expands and displays the corresponding related-item application.
  • By selecting , the event source pop-up overlay displays. Then by selecting Go to events, you will switch to the Events workspace with the selection of the specific event for the source in alarm.

Regardless of the object selection in the System tree, from the horizontal navigation bar, you can access additional features, among which some can display in the right panel.

The available layouts vary depending on the browser window size or the device screen resolution (see the following table for reference).
