Replacement Days

The Replacement Days expander displays a list of seven replacement days that you can use in place of the selected date's normal schedule for a zone or event. Replacement days do not affect zones or events scheduled as one-time occurrences.

To view or add replacement day schedule(s) for a zone or event, click the expanders for the desired replacement day.

Timeline

Displays replacement schedules for the selected replacement day.

Add/Remove Schedule Buttons

Button

Description

Add Schedule

Adds a new replacement schedule to the replacement day based on the current day. When clicked, the Duration section displays.

Remove Schedule

Removes the replacement schedule from the replacement day.

Duration

NOTE:
This section is only visible when you click the Add Schedule button, or an already existing schedule is in the replacement day.

 

Item

Description

Enable

When checked, the replacement schedule is active and will run as scheduled. If not checked, the replacement schedule is disabled and will not run as scheduled.

Start Time

Displays when the replacement schedule starts on the scheduled date.

> Use the UP and DOWN arrows to set the time the replacement schedule will start.

End Time

Displays when the replacement schedule ends on the scheduled date.

> Use the UP and DOWN arrows to set the time the replacement schedule will end.

Span (Days)

Displays the number of days the replacement schedule takes place.

> Use the UP and DOWN arrows to set the number of days the replacement schedule will run.

Mode
(Zones Only)

Displays the mode for the zone during the replacement schedule.

> Click the drop-down arrow and select a mode.
