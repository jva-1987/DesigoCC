Creating a Migration

  1. System Manager is in Engineering mode.
  2. In System Browser, select Management View.
  1. Navigate to System Settings -> Conversion Tools -> GenericDataMigration
  2. You should see a panel that allows you to browse for a .csv file that contains the migration mappings, a Settings panel to select the network with the source and target devices, and a series of element tabs that will be populated once the migration is complete.
  3. Under Select File, browse for the file containing your migration export from ABT.
  4. Under Settings, select the Source Network (containing the device you want to replace) and the Target Network (containing your new device).
  5. If you want the points on the new device to be tagged with the source device, select Add tag in target point showing the source data point.
  6. Once you have selected the .csv migration file and the correct network, the system will begin reading values from the file, populating each tab with points and the application data that could be migrated. At this point you can inspect each tab in the Update Elements panel to determine if your data is in the correct configuration before migrating. Some fields can be manually adjusted. For more on this, see the Reference section, Review and Adjust the Results of the Migration.
  7. Once you are satisfied with the points, graphics, trends and other application data in the Update Elements panel, click the button, “Update all elements of all tabs,” to begin the migration.
