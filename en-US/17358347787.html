Events

Available in Engineering Mode, the Event Editor displays in the primary pane when an existing event is selected in System Browser. Desigo CC allows you to view and modify your imported APOGEE events, as well as create new ones.

An event is an activity such as a meeting, weekday schedule, weekend cleaning, or repairs which occur in your building or campus. You can use these activities to create event definitions. An event definition identifies how an activity is going to affect a set of zones, and contains the:

  • zones affected by the activity
  • required operating mode for each zone

After event definitions are created, you can schedule the events. An event schedule includes the duration and repetition of the event. Event schedules are used in combination with control programs, command tables, and optimization parameters to ensure the zone conditions meet the needs of the event.
