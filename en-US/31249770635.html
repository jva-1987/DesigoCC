Configure the XNET Ownership Station

If the XNET ownership was set for Panel-control-when-Linked-Panel-has-control (UL-864 10th ed. and ULC-S527), you need to associate the management station with the panel in control of the fire system. The management station will take ownership of the fire network when the associated panel has the fire network ownership. Panels that will never take the fire network ownership do not need any station associated.

  1. System Manager is in Engineering mode.
  2. You configured an XNET network with the Ownership Settings = Panel Control when Linked Panel has Control.
  3. The available Desigo CC management stations are configured under Project > Management System > Clients (or > FEP, or > Server).
  1. In System Browser, select Management View.
  2. Select Project > Field Networks > [XNET network].
  3. Expand the [XNET network] and select the first panel that is deputed to take the ownership.
  4. In the XNET tab, open the Ownership Setting Station expander.
  5. From the Management Station drop-down list, select the management station associated to the panel for ownership purposes.
  6. In the Command Station ID field, enter the numeric ID set in the Zeus tool for the management station.
  7. Click Save .
  8. Repeat these steps for all the panels under the [XNET network] that can take the network ownership.
