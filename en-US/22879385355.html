Handle Session Timeout

In fs_en profile, a session timeout message displays because your user group was configured for auto-logoff after a period of operator inactivity.

  1. The Session Timeout message warns you about the time remaining before your Flex Client web session expires.
  • Select one of the following:
    • Log out, to exit the application.
      NOTE: If you log out, any unsaved changes will be lost.
    • Stay logged in, to stop session timeout.

In UL/ULC profiles, if auto-logoff occurs after a period of operator inactivity, Event List displays events with highest priority on top.
