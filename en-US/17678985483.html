APOGEE Information Text Importer Overview

The APOGEE Information Text Importer is a conversion tool that imports point information text from APOGEE export data into the Information Text feature of Desigo CC.

Prerequisites

Before you import information text into the management station, do the following:

  • Create the APOGEE export files using the Desigo CC Export Utility in either APOGEE Insight or the Commissioning Tool (CT).
    - APOGEE Insight must be at version 3.15, Patch 15 or later.
    - CT must be at version 3.16 or later.
    NOTE: Panel data exported prior to these versions will not contain APOGEE Information Text. Existing panels in Desigo CC must be re-exported from APOGEE Insight or CT to obtain the information text.
  • The APOGEE System extension module is installed and added to your project.
  • The APOGEE driver is installed and running.
  • An APOGEE network is created, and the APOGEE driver is associated with the network.
  • The APOGEE Panels containing Information Text have already been imported, and they display in your APOGEE network.
  • A folder with the exported data files is available—for example, C:\ApogeeDB.

Status Messages

Once the panels have been imported, the Migration Status column displays one of three results for each panel.Additionally, a log file listing import status (including errors) is available through the Import Summary dialog box that displays after the panels have been imported. You can also view the status in the Detailed Log.

Status Messages

Message

Result

Migrated

Panel data was successfully imported.

Migrated with Errors

Panel has been imported, but some data is missing.

Failed

Panel data was not imported.
