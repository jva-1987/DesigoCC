Migrating and Upgrading FS92 Cerberus Pro Fire Panels

Upgrade Cerberus DMS from Previous Versions

When you upgrade Cerberus DMS from V4.x/V5.0/V6.0 to V7.0, just follow the standard Cerberus DMS upgrade procedure.

Then, in the Cerberus DMS project, re-import the SiB-X metafile on each fire system to apply the latest library modifications.

Expanding Control panels

It is possible to expand the fire panels as follows:

  • FC922 to FC924

A new import of the SiB-X metafiles is required. Existing object references in graphics, macros, user defined views, schedules and so on are still valid after the new SiB-X import.
