Dashboards Workspace

In the Flex Client, select Desigo CC root node to see the Dashboards workspace from system, area, and device nodes. The Dashboard contains widgets, options to define the timeline, and actions to modify the dashboard and the widgets.

Actions

You can manage the dashboards using various options available in the Actions drop-down.

- Edit dashboard: Allows to change the Dashboard name, Default time period and contains Set as default dashboard to set the default dashboard that is displayed while navigating between area folders.

- Set as default: Allows to set the default dashboard that is displayed while navigating between nodes.

- Delete dashboard: Allows to delete the dashboard.

- Apply dashboard config: Allows you to copy current dashboard configuration to another system/area/device either with or without source.
With source: Allows you to copy the current dashboard configuration, including the source, to the destination system/area/device.
Without source: Allows you to copy the current dashboard configuration, excluding the source, to the destination system/area/device. The source of the destination device will be applied automatically.
