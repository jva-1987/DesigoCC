Object Configurator

  • The archive functionality is linked to the Object Configurator tab. When the measurement points are archived at the system or area or device node, the same changes will be reflected in the Object Configurator tab of the device node.
  • Similarly, if the measurement points are configured from the Object Configurator tab, the changes will be reflected in the device node of both physical, virtual and logical devices.

Any settings configured in the object configurator of an earlier version of Powermanager will be retained if Powermanager is upgraded to a higher version.
