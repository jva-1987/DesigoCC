Configure the Performance Mode

You can select from three performance modes to manage data and optimize counter calculations efficiently.

For background information, see Performance Mode Expander under System tab.

  1. Ensure that System Manager is in Engineering Mode.
  1. In System Browser, select Application view.
  2. Go to Application view > Powermanager.
  3. The System tab displays.
  4. Go to the Performance Mode expander.
  5. The performance modes are displayed in the counter calculation table.

  6. By default, 15 Minute Consumption Calculation performance mode is selected.

  7. Select the performance mode, as required. Based on the selected performance mode, the counter calculation happens.
  8. Click Save.
  9. A note Configurations for Performance Mode will reflect only when the project is restarted is displayed at the bottom of the table.
  10. Close Powermanager.
  11. Go to System Management Console and restart the project.
  12. Launch the Powermanager.
  13. The newly selected performance mode is considered to counter calculations. If the project is not restarted, the calculations are performed based on the previous configuration.
  14. You can switch to any of the three modes for the counter calculation. Switching between different modes does not cause any data loss.

  15. If you upgrade the Powermanager from older versions to V9.0 or a higher version, the 1 Minute Consumption Calculation performance mode is selected by default. This also applicable for migration scenarios.

    In lower versions 1-minute, 15-minute and 1-day calculations are set as default. To retain this data, this mode remains the default setting for upgraded and migrated projects.
