Fire WAN Troubleshooting

Handle Fire WAN Performance Issues

Symptom

Situation

Do the following...

Slow event acquisition and display in large Fire WAN Networks. Slow or missing response to detector parameter readings (search for Reading XNET Detector Parameters).

The Zeus tool version and the number of connected panels can influence the system performance.

Verify the Zeus tool version and check the connectivity limits in Fire WAN Limits and Compatibility.

  • Verify the Zeus tool version and check the connectivity limits in Fire WAN Limits and Compatibility.
  • In large XNET networks with more than 5 panels, set a longer Command Timeout in the Fire WAN driverControl Settings. We recommend to set 120,000 msec (2-minute response delay).

Handle Fire WAN Event Issues

Symptom

Situation

Do the following...

Missing events on the management station. Event List misalignment with fire panels.

In the Zeus configuration (up to V15.00.xxxx), with the Proprietary NFPA System Type setting, the Self Restoring options are not supported and can result in event misalignments.

Check the Zeus setting in Fire WAN Limits and Compatibility.
