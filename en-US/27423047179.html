Create a Data Point Card

You can create the Data point card widget that displays the live value from the device for the selected source using a card. For background information, see Data Point Card Workspace.

  1. In the dashboard, select the Data point card from Create widget list.
  2. Click Next.
  3. The Create widget page opens.
  4. Click Add to select the data point.
  5. Select the device from the list and click Select.
  6. A blank data point card displays with an image of the added device, if it is available in the repository. If the image is not available, a default placeholder image will be displayed.
  7. Select the Data point from the drop-down.
  8. The Data point card is created and displays the live value from the device for the selected source in a card. You can add only one data point per card; add a separate card for each additional data point.
    The Data point card widget supports only the numerical, boolean, enumerated, date, and time format values from the selected source.
  10. Click Create to add the widget to the dashboard.
  11. Click Save.
  1. The Data point card is created in the dashboard.
