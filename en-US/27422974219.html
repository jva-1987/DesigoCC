Create a Dashboard and Widget

You can create a dashboard and add widgets for the configured devices in the Installed Client to view the measurement points in various charts.

Create a Dashboard

  1. Go to Application View > Powermanager > [Area].
    Dashboards can also be created from Application View > [System/Device].
  2. In the Dashboards tab that displays, click Create.
  3. The Create dashboard page opens.
  4. Enter the Dashboard name and select Default period. The dashboard default period is Last 7 days.
  5. Enable Set as default dashboard to make it default dashboard.
  6. Click Create.
  7. A new dashboard is created.

Create a Widget

  1. The Dashboard is created.
  1. In the dashboard, click Create Widget.
  2. The Create Widget page opens.
  3. Select the widget from the list or search using the Search bar.
  4. Click Next to create a widget.
  5. Depending on the selected widgets, follow the corresponding procedures from the list below:
    - Create a Consumption Chart
    - Create a Trend
    - Create a Data Point Table
    - Create a Data Point Card
    - Create a Gauge Chart
    - Create a Grouped List Card
    - Create a Line Area Chart
    - Create a Condition Monitoring
  1. The widget is created.
