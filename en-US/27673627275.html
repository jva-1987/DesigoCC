Reports Workspace

In the flex client, navigate to Powermanager root node > Report Definition > [Reports], to see the Reports workspace. Here, you can set the duration and intervals for generating the reports. For related procedures, see the step-by-step section.

In Flex Client, the Reports section helps to generate Energy and Power reports. The availability of any reports in the Flex Client for execution depends on the following configurations done in the Installed Client:

  • Reporting extension with all its configurations working including Main URL, Web Services URL, synchronization, execution of all configuration page settings and job create cache.
  • Report are configured in Standard Client and will be reflected in the Flex Client to execute Energy and Power Reports.
  • Show and Configure rights configured to view the Reports application in the Flex Client.
    For more information, see Application Rights in User and User Group Administration > User Administration.
