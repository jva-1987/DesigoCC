Adjust Layout

Your user preferences are automatically saved when you exit the Flex Client application. They persist across sessions, but they are lost in case of project upgrade.

Display the Layout Settings

  • In the horizontal navigation bar, select .
  1. The right panel expands and displays the Layout settings. Current settings are highlighted in a different color. You can now change layout settings according to your preferences.
  • To close the right panel, in the horizontal navigation bar, select again . Alternatively, you can:
    • Select in Flex web app.
    • Select  and then choose Close in Flex desktop app.

Change System Workspace Pane Layout

  1. The System workspace displays on the screen along with the Layout settings displayed in the right panel.
  • Under Pane layout, select one of the available icons to switch to a different pane layout.
    For a complete list of the available layouts, see System Workspace.

Lock or Unlock Layout

  1. The Layout settings display in the right panel.
  2. By default, layout is unlocked , which means that you can drag the vertical splitter to resize layout areas.
  1. To lock the layout, select .
  2. The button changes to locked . This means that you can no longer resize the layout areas.
  3. To unlock the layout, select again the lock/unlock button.

Adjust the Size of Layout Areas

  1. The layout is unlocked (), and you want to resize the layout areas.
  • Do one or more of the following:
    • In the Events workspace, drag the splitter between the list area and the details area to adjust their size.
    • In the System workspace, drag the splitters between the different panes to adjust their size.
  1. By resizing layout areas their content adjusts accordingly (for example, text on multiple lines).

Restore Default Layout

  1. The Layout settings display in the right panel.
  • Do one of the following:
    • If you are working with Flex web app, in the Layout panel, select Default layout.
    • If you are working with Flex desktop app, in the right panel, select  and then choose  Reset layout.
  1. Layout is restored to default depending on the screen size and splitter standard settings.
