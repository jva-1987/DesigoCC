Management Station Hardware in UL Fire Systems

In UL fire and voice systems, the following types of management station hardware can be used:

  • Full Control – Comark Computer
    UL 864-listed computers. This hardware can be used for any Desigo CC stations (Server, Client, FEP, physical server for virtual machines).
    For configuration examples, search and browse the Fire System Architecture sections. For minimum computer hardware and software specifications, see UL 864-listed Computer Specifications.
  • Full Control – Off-the-shelf Computer
    UL 60950/UL 62368-listed Building System Information Unit (BSIU) computers. This hardware can also be used for any Desigo CC stations (Server, Client, FEP, physical server for virtual machines).
    If such a management station has control, it must be located in the same room as the associated Fire Alarm Control Unit (FACU) controlling the fire alarm system (technically indicated as the Global Command Station). Monitor-only stations do not need to meet this requirement
    The communication path from management station to the fire system must meet the same requirements as non-BSIU systems (refer to the Fire System Architecture sections).
    For minimum computer hardware and software specifications, see UL 60950/UL 62368-listed Computer Specifications.
  • Monitor Only – Off-the-shelf Computer
    Unlisted computers. This hardware can only be used for monitor-only stations.
