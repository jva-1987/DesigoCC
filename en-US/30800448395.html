Manual Measuring Device Workspace

In the Manual Measuring Device workspace, you can add the Value and DateTime for the Manual Measuring Device created in the Installed Client. You can also import the data for the device in the .CSV file and view the values. For related procedures, see Add Data to Manual Measuring Device.

Properties

Summary Status

Displays the status of summary.

Alarm Suppression

Displays the status of alarm triggered.

Add Manual Value And DateTime

Displays the added value, date, and time.

Import File

Import the .CSV file which contains the device data.

Status

Displays the status message for the imported file.

Last Entered DateTime

Displays the last entered date and time from the imported file.

Last Entered Manual Value

Displays the last entered value from the imported file.

Energy Value Consumption (15min)

Displays the values for every 15min interval. You can see the value in reports.

Energy Value Consumption (1 day)

Displays values for every 1day interval. You can see the value in reports.

Counter Value

Displays the Total Energy Consumption value. You can see the value in reports.
