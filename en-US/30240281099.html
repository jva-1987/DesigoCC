Standard Client Profiles

The standard client profile customizes certain aspects of the installed Desigo CC application. It determines the appearance and behavior of the Summary bar, Event List, and other system functions involved in event handling, such as:

  • What event lamps display in the Summary bar
  • The default pane layout of System Manager
  • Whether the Summary bar can be collapsed
  • The background category colors in Event List

Client profiles can be applied to Desigo CC stations and/or to users. For instructions see Configuring Client Profiles.
