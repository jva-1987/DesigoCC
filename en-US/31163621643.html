Open Dialog Box

The table describes the major components of the dialog box in the Graphics Editor Workspace:

Name

Description

System List

Contains a dropdown with a list of systems and displays the currently selected system.

Folder List

Displays an expandable list of all the Graphics Folder and Graphics Library folders related to the project.

Graphic List

Displays a list of all the graphics in the selected folder.

Search Filter

Allows you to search for graphics and limit the objects displayed.

Includes a real-time filtering feature that dynamically updates the displayed list based on the input. Filtering is case-insensitive and works by matching substrings. Wildcards are not supported.
