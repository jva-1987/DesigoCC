Working with Reports in Mobile Flex

This section provides instructions to work with reports in the mobile Flex web application.

  1. Select a report from the list of displayed reports or tap  and select a report from the folder.
  2. The Reports tab displays.
  3. Tap Generate and select an option to generate a report in PDF, EXCEL or both formats.
  4. The History area displays the report execution records.
  5. Tap next to the relevant report and select an option to view, download or delete the report.
    • For a PDF preview, tap Open in new tab in the preview area.
  6. The PDF preview of the selected report displays in a new tab.
