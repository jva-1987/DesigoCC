Add Data to Manual Measuring Device

  1. The Manual Measuring Device is created and configured in the Installed Client.
  1. Go to Application View > Powermanager > [Area/Sector] > Manual Measuring Device .
  2. Click  in the top right corner.
  3. The Manual Measuring Device properties displays.
  4. In the Properties expander, click on the Add Manual Value and DateTime field.
  5. The Add Data pop-up window displays.
  6. Enter the Value.
    Conditions to be followed for entering the value:
    1. Single data can be added manually.
    2. Manual entered value should always be lesser than overflow value.
    3. Entered value should be less than next value and greater than previous value for entered date and time.
    4. Negative values are not allowed.

  7. NOTE 1: Conditions for decimal separator used in Values field :
    A dot (".") is used as the decimal separator in English-speaking regions (for example, "12.5").
    A comma (",") is used as the decimal separator, common in many European regions (for example, "12,5").
    In both cases, the placement of the decimal separator and thousands separator is reversed.

    NOTE 2: Ensure the correct decimal separator is used for entering values based on your systems regional settings to avoid data entry errors or import issues.

  8. Enter the DateTime.
    Conditions to be followed for entering the date and time.
    1. Ensure the time interval is always 15 minutes, with seconds set to zero.
    2. Previous datetime is allowed.
    3. Future datetime is not allowed.
  9. Click .
  1. In the Add Manual Value And DateTime field, the entered Value and DateTime displays.

To Import .CSV File

  1. In the Properties expander, click Import File.
    You can create a .CSV file with actual data by referring to the sample file.
    For more information about import scenarios and importing .CSV files, see Integrating Manual Measuring Device in Installed Client help file.
  2. Enter the file path which contains the .CSV file.
    Only .CSV file format is supported to import.
  3. The file is imported successfully with the Status = Import Successful and displays values from the imported file.
  4. You can also view the Last Entered Manual Value, Energy Value - Consumption(15min), Energy Value - Consumption (1day) and Counter Value. from the Properties expander.

The Dashboard supports the Manual Measuring Device, and you can view the Consumption chart and Trend widgets for it.

For background information, see Manual Measuring Device Workspace.
