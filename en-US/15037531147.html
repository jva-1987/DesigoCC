Properties

This section provides step-by-step instructions for properties and related items. For background information, see the reference section.

Command a Property for Multiple Objects

  1. You have selected two or more objects of the same type because you want to command one property for all of them.
  1. From the Property List, select either Basic or Advanced mode.
  2. Select the property you want to command.
  3. The aggregate property value and the individual property values display.
    NOTE: The aggregate property indicates the value of the property for all the selected objects. If an asterisk is displayed, the value differs on the selected objects. If a value is displayed, that is the value of all of the selected objects. Commanding the aggregate property commands the value for all the selected objects.
  4. Determine whether you want to command all properties to the same value or command an individual property, and do one of the following on either the aggregate or individual property:
    • To view available commands, selectand then select the command you want to execute.
    • If the property has a dark gray border around the property value, select the value and, depending on the property,
      - Modify its value, or
      - View more detailed information about the property and modify individual values.
  5. Enter any required parameters.
  6. Do one of the following:
    • Select  to send the command.
    • Select to cancel the command.
      NOTE: The memo is not available for a multi-object selection.
  1. If the command succeeds,  displays next to the affected property values. If the command fails,  displays next to the affected property values.

Command or Release a Priority Array Property

  1. You have selected an object with a priority array property.
  1. From the Property List, select Advanced mode.
  2. Select the Priority Array property.
  3. For the desired priority level, select the value you want to modify or release.
  4. Do one of the following:
    • To send a command, enter or modify the value and then select .
    • To release a command, select .

Command Properties

  1. You have selected an object.
  2. The property you want to command displays a dark gray border or.
  1. From the Property List, select either Basic or Advanced mode.
  2. Do one of the following:
    • To view available commands, select and then select the command you want to execute.
    • If the property has a dark gray border around the property value, select the value and, depending on the property, either modify its value, or view more detailed information about the property and modify individual values.
  3. Enter any required parameters.
  4. Do one of the following:
    • Select  to execute the command.
    • Select  to cancel the command.
  1. If the command succeeds,  displays next to the property value. If the command fails,  displays next to the property value.

Filter Properties

  • In the Search box, enter the desired text, which is filtered as you enter it.
  1. The filtered properties display.

Create a Memo

  1. You have selected an object and would like to create a memo.
  1. Select .
    The Memo dialog box displays.
  2. Enter the memo as desired.
  3. Select Save.

Modify a Memo

  1. You have selected an object and would like to modify the memo.
  1. Select .
    The Memo dialog box displays.
  2. Select Edit.
  3. Modify the memo as desired.
  4. Select Save.

Viewing a Related Item

  • Do one of the following:
    • To expand a group header to show the items in the group, select anywhere on the header.
    • To collapse a group header to hide the items in the group, select anywhere on the header.

Creating a New Related Item

  1. Select the Group Header you want to create a new item for.
  2. The Add menu displays.
  3. Select Add.
  4. Select the desired new item and destination pane.
  1. A new item is created in the selected pane.

Sending a Related Item to a Specific Viewing Location

  1. The group header you want to work with is expanded and related items are visible.
  1. To the right of the item you want to view, select .
  2. From the contextual menu, select the desired action.
  1. The item displays in the selected viewing location.
