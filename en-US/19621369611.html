Creating and Managing Trend View Definitions

This section provides step-by-step instructions on working with trend view definitions.

Create a Trend View Definition

  1. In System Browser, select a Trends folder, Offline Log Objects folder, Online Log Objects folder, or Trend View Definitions folder.
  2. Do one of the following:
    • For Monitor screen, select Create trend.
    • For Mobile Flex, tap  and Create trend.
  3. The Edit mode displays.
  4. Select the Series tab and thereafter select the Chart expander.
  5. Select  to add data points.
  6. From the drop-down list in the Select data point dialog box, select Management View and select Project > Field Networks > [network type] > Hardware > [device].
    Either select a single point or select multiple data points by using multi-select and Select. In order to find objects, use Filter.
    NOTE: You can also select any data point from the drop-down list in the dialog box, irrespective of selection of any of the standard views (for example, Management View or Application View). You can add the same data point multiple times and all the duplicate data points is displayed in the Series tab.
  7. The properties is reflected immediately in the chart preview. If you have added any non-trended objects, then the details of those objects are also reflected.
  8. For each trend series property you want to modify, do the following:
    • Select the drop-down arrow that displays below Style, and select the appropriate Color, Width, Dash type, Marker, and Interpolation options.
      The Interpolation option is visible only for Analog Series and can change the series representation from Direct Chart to Step Chart or vice-versa.
      NOTE: In the Installed client, if the series representation option for Analog Series is set as None and saved. Then after reloading the trend view definition which contains the same Analog Series, in the Flex Client, the series representation is displayed as a Direct Chart.
    • Select the drop-down list that displays below Y-Axis and select the appropriate Left or Right options.
      For mobile Flex,Y-Axis option is available under .
      NOTE: If the data point is either Binary or Multistate, the drop-down list is disabled.
    • Select the drop-down arrow that displays below Reference, and select the appropriate data point property. In the text box below, enter a name for the trend series.
      NOTE: The selection of a new data point property results in the creation of a new online trend log object, once the property is saved.
    • Select  and select Select property from the displayed options. From the properties list, select the appropriate data point property. By default, the Present Value property is selected.
      NOTE: The selection of a new data point property results in the creation of a new online trend log object, once the property is saved.
    • Select either Show data point properties or Show Trendlog properties to display the corresponding properties in the right panel below the Properties tab.
    • Select , to remove the respective trend series from the trend view definition.
      For mobile Flex, Delete option is available under .
  9. The properties are reflected immediately in the chart preview.
    NOTE: If there is no Read or Read/Write access to the Property Groups to which the Trended Property belongs to (for example, Status, Configuration Property Groups), the respective Trended Property (for example, Present Value, High Limit, Low Limit, and so on) will not be displayed. The data points which are out of scope also do not display in the Series tab.
  10. Select the General tab, and do the following:
    • Enter a name in the Trend name field.
    • Enter a time range for the Default period, using the symbol. Select one of the viewing options: minute, hour, day, week, month, year or all from the drop-down list.
  11. The properties are reflected immediately in the chart preview. If you have added any non-trended objects, then the details of those objects are also reflected.
  12. Select the Axis tab, expand the chart and specify the Min and Max range for Left Y – Axis or Right Y – Axis.
    NOTE: The left or right y-axis show scaling in the Trend View, if the Auto-scale toggle button is enabled, and accordingly the Max and Min range is disabled. The Left Y - Axis: Min. and Max. or Right Y - Axis: Min. and Max. is disabled if the trend series is not set to the either left or right y-axis.
  13. Select Save.
    For mobile Flex, Save option is available under .
  14. In the Save as dialog-box, perform the following steps:
    a. Enter a name in the Description field, if you want to either modify the name mentioned in the Title field or if it is empty.
    b. Select the main Trend View Definitions folder or any subfolder under it.
    c. Select Save.
    NOTE: In order to find objects, use Filter .
  1. A trend view definition is created under the Trend View Definitions folder. The trend view definition saved in the Flex Client is retained in the management station.
  2. For each data point that is added, an online trend log object is created in the Online Log Objects folder.

 

Create a Trend View Definition from Online or Offline Trend Log Objects

  1. In System Browser, select Trends.
  2. Select one of the following:
    • An offline trend log object from the Offline Log Objects folder.
    • An online trend log object from the Online Log Objects folder.
  3. Select Edit .
  4. The Edit mode displays.
  5. Change the General properties, Series properties and the Axis properties for each trend series.
    For more information, see Create a Trend View Definition.
  6. The properties display in the chart preview.
  7. Select Save.
    For mobile Flex, Save option is available under .
  8. In the Save as dialog box, do the following:
    a. In the Name field, enter a name.
    b. In the Description field, enter description.
    c. Select the main Trend View Definitions folder or any subfolder under it.
    d. Select Save.
    NOTE: In order to find objects, use Filter.
  1. A trend view definition is created under the Trend View Definitions folder.
  2. For each data point that is added, an online trend log object is created in the Online Log Objects folder.

 

Create a Trend View Definition from Right Panel

  1. From the System Browser, select a folder, an online log object, an offline log object or a data point.
    NOTE: You can also select multiple objects by using multi-select.
  2. Next to the selected object, select  and select Send to Secondary Pane.
    NOTE: The  displays only when you reduce the zoom percentage of your browser to less than 100%.
  3. Navigate to  Right Panel > Trend.
    • Click Add.
  4. Select New Trend in secondary pane.
  5. The Edit mode displays in the Secondary pane.
  6. Change the General properties, Series properties and the Axis properties for each trend series.
    For more information, see Create a Trend View Definition.
  7. Select Save.
    For mobile Flex, Save option is available under .
  8. In the Save as dialog-box, do the following:
    a. In the Description field, enter a name.
    b. Select the main Trend View Definitions folder or any subfolder under it.
    c. Select Save.
    NOTE: In order to find objects, use Filter .
  1. A trend view definition is created and displays under the Trend View Definitions folder.
  2. For each data point that is added, an online trend log object is created in the Online Log Objects folder.

 

Add Subcharts to a Trend View Definition

  1. In System Browser, select Trends.
  2. From the Trend View Definitions folder, select a trend view definition.
  3. Select Edit .
  4. The trend view definition displays in the Edit mode.
  5. Select the Series tab and select the Chart expander.
  6. Select Add chart.
    For mobile Flex, Add chart option is available under .
  7. A new expander with the heading Chart (X) is added.
  8. Select the expander to be configured.
  9. Configure the subchart by adding data points, specifying the style options, location of the y-axis, and so on. For more information, see Creating and Managing Trend View Definitions > Edit Series Properties in Trends Step by Step.
    NOTE: The axis properties cannot be modified if your subchart contains Binary or Multistate points.
  10. The subchart is added below the existing chart.
  11. Select the General tab and select the expander representing the subchart to specify details such as properties of X and Y axis. For more information, see Creating and Managing Trend View Definitions > Edit General Properties in Trends Step by Step.
    NOTE: If your subchart does not contain datapoints, the preview of the chart does not display in the View mode.

 

Edit General Properties

You want to view and edit the General properties of a trend view definition.

  1. In System Browser, select Trends.
  2. From the Trend View Definitions folder, select a trend view definition.
  3. Select Edit .
  4. The Properties window displays in Edit mode.
  5. Select the General tab. See General Properties in Trends Reference.
  6. The properties of Trend View display.
  7. In the Trend name field, enter a new name for the trend view definition.
  8. Modify the default time period (if required).
  9. Select the expander for the sub chart whose properties you want to edit.
  10. Select Save.
    For mobile Flex, Save option is available under .
  1. The edited properties are saved and display in the Trend View.

NOTE: On switching to any other tab or event when you switch back to the Trend tab, the General tab displays and the previously saved chart properties are retained.

 

Edit Series Properties

You want to view and edit the data source properties for each trend series of a trend view definition.

  1. In System Browser, select Trends.
  2. From the Trend View Definitions folder, select a trend view definition.
  3. Select Edit .
  4. The Properties window displays in Edit mode.
  5. Select the Series tab. See, Series Properties in Trends Reference.
  6. The charts associated with the trend view definition display as expanders.
  7. Select the expander corresponding to the sub chart to be edited.
  8. For each trend series property to modify, do the following:
    • Select the drop-down arrow that displays below Style, and select the appropriate Color, Width, Dash type, Marker, and Interpolation (available only for Analog Series) options.
    • Select the drop-down list that displays below Y-Axis and select the appropriate Left or Right options.
      NOTE: If the data point is either binary or multistate, the drop-down list is disabled.
    • Select , and select either Show data point properties or Show Trendlog properties to display the corresponding properties in the right panel below the Properties tab. Select the Select property option to change the property for the data point. By default, the Present Value property is selected. Selection of a new data point property results into the creation of a new online trend log object, once the property is saved. Select Rename to rename the data point.
    • Select , to remove the respective trend series from the trend view definition.
    • Select  to add additional data points to the trend view definition.
  9. The edited properties are reflected immediately in the chart preview. Trend series for any non-trended points (if added) to the trend view will also display.
    NOTE: If there is no Read or Read/Write access to the Property Groups to which the Trended Property belongs (for example, Status, Configuration Property Groups), the respective Trended Property (for example, Present Value, High Limit, Low Limit, and so on) is not displayed. The data points which are out of scope, will also not display in the Series tab.
  10. Select Save.
    For mobile Flex, Save option is available under .
  1. For each data point that is added, an online trend log object is created in the Online Log Objects folder.
  2. The edited properties are saved and display in the Trend View.

NOTE: On switching to any other tab or event when you switch back to the Trend tab, the General tab displays and the previously saved Series properties are retained.

 

Manual Upload of Trend Log Data

  1. In System Browser, select Trends.
  2. Perform either of the following steps:
    • From the Trend View Definitions folder, select the trend view definition containing offline trend log objects or trend log multiple objects.
    • From the Offline Log Objects folder, select an offline trend log object.
  3. Select  that displays next to Zoom  and select Manual upload from the displayed options.
  4. A message notifying the initiation of upload of trend data displays.
  5. Once the data is available in database, the data reflects in the chart.

NOTE 1:
You can automatically upload and display trend log data to the chart by selecting either of the following:
An offline trend log object or trend log multiple object.
A trend view definition containing an offline trend log object or trend log multiple object.
NOTE2:
For other subsystem Trend logs (other than BACnet), the user must manually refresh or reload the Trend log to view the uploaded data.

Define the Settings

  1. In System Browser, select a Trends folder, Offline Log Objects folder, Online Log Objects folder, or Trend View Definitions folder.
  2. Select  and Settings.
  3. In the Trend settings dialog box, do the following:
    a. In the Data accuracy section, move the slider anywhere between Loading fast to High resolution.
    b. In the Default period section, enter a time range using the symbol. Select one of the viewing options: minute(s), hour(s), day(s), week(s), month(s), year(s) or all from the drop-down list. By default, 1 week is selected.
  4. Select Close.
  1. The defined settings are saved and applied to online trend log objects, offline trend log objects and the trend view definitions.

NOTE: In case of a trend view definition, these settings are only applied during its creation and can be overridden.

 

Delete a Trend View Definition

  1. In System Browser, select Trends.
  2. From the Trend View Definitions folder, select a trend view definition.
  3. Select  that displays next to Zoom  and select Delete from the options displayed.
    NOTE: By default, the Delete option for an offline trend log object is disabled.
  1. The trend view definition is permanently deleted from the Trend View Definitions folder.

NOTE: The online trend log objects in the trend view definition are not deleted. No recorded data is lost.

 

Delete an Online Trend Log Object

  1. In System Browser, select Trends.
  2. From the Online Log Objects folder, select an online trend log object.
  3. Select  that displays next to Zoom  and select Delete from the options displayed.
    NOTE: By default, the Delete option for an offline trend log object is disabled.
  1. An online trend log object is permanently deleted from the Online Log Objects folder.

 

Display Quality Indication Area

  1. Select a trend online log object, a trend offline log object or a trend view definition.
  2. Select  that displays next to Edit and select Show data status indication.
  1. The quality indication area is displayed and is highlighted with the red color. This area indicates a quality issue (a problem with the data point).

 

Remove Subcharts from a Trend View Definition

  1. In System Browser, select Trends.
  2. From the Trend View Definitions folder, select the trend view definition with the Subchart that you want to remove.
  3. Select Edit .
  4. Select the Series tab.
  5. The list of Subcharts present in the trend view definition displays as expanders.
  6. Select the expander corresponding to the Subchart to be removed and select  that displays next to .
  7. Select Remove chart.
  1. The Subchart is removed and no longer displays in the View mode. Information related to the axis properties and data sources for the Subchart is also removed.
