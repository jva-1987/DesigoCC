APOGEE PPCL Editor

Complete the following procedures as needed:

Activating Edit Mode

  1. System Manager is in Engineering mode.
  1. In System Manager, select Management View.
  2. Select Project > Field Networks > [Network name] > [Field Panel name] > PPCL > [Program name].
  3. Select the program you want to edit.
  4. Click the ApogeePPCL tab.
  5. Click Edit Program.
  1. The Edit Program icon turns gray to show that it is active.

Clearing Trace Bits

  1. System Manager is in Engineering mode.
  2. The Status column for the program displays at least one T.
  1. In System Manager, select Management View.
  2. Select Project > Field Networks > [Network name] > [Field Panel name] > PPCL > [Program name].
  3. Select the program you want to clear.
  4. Click the ApogeePPCL tab.
  5. Click Clear Program Trace Bits .
  6. The Clear Program Trace Bits dialog box displays.
  7. Accept the default beginning and ending statement program line numbers, or enter your own.
  8. Click OK.
  1. The system clears the trace bits from the program.

Compiling a Program

  1. System Manager is in Engineering mode.
  1. In System Manager, select Management View.
  2. Select Project > Field Networks > [Network name] > [Field Panel name] > PPCL > [Program name].
  3. Select the program you want to compile.
  4. Click the ApogeePPCL tab.
  5. Click Edit Program.
  6. Click Compile Program .
  7. Select one of the following:
    • Compile Selected Statements
    • Compile All Statements
  1. The PPCL Editor compiles the statements and displays the results in the Output section.

Compiling and Saving a Program

  1. System Manager is in Engineering mode.
  1. In System Manager, select Management View.
  2. Select Project > Field Networks > [Network name] > [Field Panel name] > PPCL > [Program name].
  3. Select the program you want to compile and save.
  4. Click the ApogeePPCL tab.
  5. Click Edit Program.
  6. Click Save .
  1. The PPCL Editor compiles the statements, saves the program to the field panel, and then displays the results in the Output section.

Copying or Moving Program Lines

  1. System Manager is in Engineering mode.
  1. In System Manager, select Management View.
  2. Select Project > Field Networks > [Network name] > [Field Panel name] > PPCL > [Program name].
  3. Select the program you want to copy or move.
  4. Click the ApogeePPCL tab.
  5. Click Edit Program.
  6. Select the text, statement, or group of statements you want to copy or move.
  7. Do one of the following:
    • Right-click and select Copy.
    • Right-click and select Cut.
  8. Place the mouse cursor in the program where you want to copy or move it.
    NOTE: You can copy or move information within a program or across programs.
  9. Right-click and select Paste.
  1. The system copies or moves the information.

Creating a New Program

  1. System Manager is in Engineering mode.
  1. In System Manager, select Management View.
  2. Select Project > Field Networks > [Network name] > [Field Panel name] > PPCL > [Program name].
  3. Select the program from which you want to create a new program.
  4. Click the ApogeePPCL tab.
  5. Click New Program .

Deleting a Program

  1. System Manager is in Engineering mode.
  1. In System Manager, select Management View.
  2. Select Project > Field Networks > [Network name] > [Field Panel name] > PPCL > [Program name].
  3. Select the program you want to delete.
  4. Click the ApogeePPCL tab.
  5. Click Delete .
  1. The system deletes the program from the field panel, updates System Browser, and displays the results of the action in the Output section.

Disabling Statements

  1. System Manager is in Engineering mode.
  1. In System Manager, select Management View.
  2. Select Project > Field Networks > [Network name] > [Field Panel name] > PPCL > [Program name].
  3. Select the program you want to disable.
  4. Click the ApogeePPCL tab.
  5. Click Edit Program.
  6. Do one of the following:
    • Place the cursor in the program statement that you want to disable.
    • Select the block of program (multiple statements) that you want to disable.
  7. Click Disable Program Statements .

Enabling Statements

  1. System Manager is in Engineering mode.
  1. In System Manager, select Management View.
  2. Select Project > Field Networks > [Network name] > [Field Panel name] > PPCL > [Program name].
  3. Select the program you want to enable.
  4. Click the ApogeePPCL tab.
  5. Click Edit Program.
  6. Do one of the following:
    • Place the cursor in the program statement that you want to enable.
    • Select the block of program (multiple statements) that you want to enable.
  7. Click Enable Program Statements .

Finding and Replacing Text in a Program

  1. System Manager is in Engineering mode.
  1. In System Manager, select Management View.
  2. Select Project > Field Networks > [Network name] > [Field Panel name] > PPCL > [Program name].
  3. Select the program you want to find and replace.
  4. Click the ApogeePPCL tab.
  5. Click Search Text .
  6. The Search Text dialog box displays.
  7. In the Find What field, enter the text you want to find.
  8. In the Replace With field, enter the text you want to substitute.
  9. From the Look In drop-down arrow, select where you want to look for the text—either a selection of code, or the entire program.
  10. In the Search Type section, chose any search options you want included.
  11. Click Find Next, Replace, or Replace All as needed.

  9. In the Search Type section, chose any search options you want included.

Going to a Program Statement

  1. System Manager is in Engineering mode.
  1. In System Manager, select Management View.
  2. Select Project > Field Networks > [Network name] > [Field Panel name] > PPCL > [Program name].
  3. Select the program you want to go to.
  4. Click the ApogeePPCL tab.
  5. Click Go To Program Statement .
  6. The Go To Program Statement dialog box displays.
  7. Enter the statement number you want to go to.
  8. Click OK.

Opening a PPCL Program

  1. System Manager is in Engineering mode.
  1. In System Browser, select Management View.
  2. Select Projects > Field Networks > [Network name] > [Field Panel name] > PPCL > [Program name].
  3. Select the program you want to open.
  4. Click the ApogeePPCL tab.

Refreshing a Program

  1. System Manager is in Engineering mode.
  1. In System Manager, select Management View.
  2. Select Project > Field Networks > [Network name] > [Field Panel name] > PPCL > [Program name].
  3. Select the program you want to refresh.
  4. Click the ApogeePPCL tab.
  5. Click Refresh Program .
  1. The management station connects to the field panel and reads program statements and their status, and then displays the results in the workspace.

Renumbering Program Lines

  1. System Manager is in Engineering mode.
  1. In System Manager, select Management View.
  2. Select Project > Field Networks > [Network name] > [Field Panel name] > PPCL > [Program name].
  3. Select the program you want to renumber.
  4. Click the ApogeePPCL tab.
  5. Click Edit Program.
  6. From the PPCL Program toolbar, click Adjust Program Statement Number .
  7. The Adjust Statement Number dialog box displays.
  8. Select a statement option.
  9. Complete the Start Number field.
  10. Complete the Increment By field.
  11. Click OK.
  1. The system adjusts the program statement numbers.

Saving a Program Under a New Name

  1. System Manager is in Engineering mode.
  1. In System Manager, select Management View.
  2. Select Project > Field Networks > [Network name] > [Field Panel name] > PPCL > [Program name].
  3. Select the program you want to save under a new name.
  4. Click the ApogeePPCL tab.
  5. Click Save Program As .
  6. The system compiles the program and opens the Save As dialog box.
  7. From the drop-down lists, select the Network, Device, and Program Name.
  8. From the Priority drop-down list, select the PPCL Priority.
    NOTE: This field displays for BACnet devices only.
  9. Click OK.
  1. The program is saved.

Using Command Assist

  1. System Manager is in Engineering mode.
  1. In System Manager, select Management View.
  2. Select Project > Field Networks > [Network name] > [Field Panel name] > PPCL > [Program name].
  3. Select the program you want to assist.
  4. Click the ApogeePPCL tab.
  5. Click Edit Program.
  6. Do one of the following:
    • Place the mouse cursor in an existing line of code where you want to enter a new command.
    • Place the mouse cursor at the beginning of a new line number.
  7. Click Command Assist .
  8. Scroll through the command list to find the command you want to enter in the line of code.
  9. Double-click the command.
  10. The system enters the command, and the Attribute Editor displays.
  11. From System Browser, drag the point you want and drop it anywhere in the program workspace.
  12. The system adds the point to the program statement.
  13. Repeat the process for each command and point you want to enter.

Using the Horizontal Splitter

  1. System Manager is in Engineering mode.
  1. In System Manager, select Management View.
  2. Select Project > Field Networks > [Network name] > [Field Panel name] > PPCL > [Program name].
  3. Select the program you want to split.
  4. Click the ApogeePPCL tab.
  5. Move your cursor over the Horizontal Splitter until you see the double-headed arrow.
  6. Either double-click the splitter or drag it to create two sections in the program.
  7. To close the splitter, either double-click the splitter or drag it back to the top of the program.
