Reports

This section provides instructions to work with reports in the Flex Client application. For background information, see the reference section.

Display Reports in Tile View

  1. You want to display the report definitions as tile icons in the Reports tab.
  2. System Browser is in Application View.
  • In System Browser, do one of the following:
    • To display all the available report definitions as tile icons, select Applications > Reports.
    • To display only the report definitions of a specific subfolder as tile icons, select Applications > Reports > […].

Contact your system administrator if the report definition is not displayed as tile icon.

Display the History of a Report Definition

  1. You want to work with a report definition.
  2. System Browser is in Application View.
  • You can select a report definition from System Browser or from the Reports tab.
    Do one of the following:
    • Select Applications > Reports > [..] > [report definition].
    • Select Applications > Reports > [..]. Then in the Reports tab, select the relevant tile icon.
  1. The selected report definition, including its execution records, displays in the History area of Reports tab.

Export a Report to File

  1. You want to export a report to a PDF or Excel file, or both.
  2. System Browser is in Application View.
  1. Select Applications > Reports > […] > [report definition].
  2. The Reports tab displays.
  3. Select Generate and then one of the following:
    • PDF
    • Excel
    • Both
  1. The History area displays the report execution records.
  2. If you selected the export to PDF or Excel, a new row is created in the History area for each of the file formats, which indicates the name of the report definition, the type of format, and the execution timestamp.
  3. If you selected an export in both formats, a new row is created in the History area, which indicates the name of the report definition, and the execution timestamp.
    You must expand this row to see the different exports (PDF and XLSX) as child items.
    For each execution, All pages indicates that only one PDF file was created; for big files multiple PDF page blocks will be created depending on configuration; xlsx indicates that an Excel file was created.
    Exported files are stored on the server.

Contact your system administrator if the generated report view is not displayed.

Cancel The Execution of a Report Export

  1. In the History area, next to the selected report definition, the Generating status tells you that a report export is being executed, and you want to cancel the operation in progress.
    NOTE: You might not be able to cancel the execution of very small reports.
  • Next to the selected report definition that is being executed, select  and then Cancel.

Display a Report Preview

  1. System Browser is in Application View.
  1. Select Applications > Reports > […] > [report definition].
  2. The Reports tab displays. The History area shows the exports executed for the selected report definition.
  3. You can preview a PDF export in several ways.
    In the History area, expand the desired report definition, and do one of the following:
    • Next to the report definition or PDF export you want to preview, select  and then Preview.
    • Select the report definition or the row under it that corresponds to the PDF export you want to preview.
  4. The content of the selected PDF export displays in the preview area of the Reports tab.

You cannot preview an Excel export. You can only select the corresponding row in the History area, and then in the preview area, select Download to download the file locally.

Download Report Files

  1. System Browser is in Application View.
  1. Select Applications > Reports > […] > [report definition].
    NOTE: Use CTRL + click to select multiple report definitions and their exports.
  2. The Reports tab displays. The History area shows the exports executed for the selected report definition.
  3. You can download locally individual exports or all the exports for a report definition.
    In the History area, do one of the following:
    • Next to the relevant report definition whose exports you want to download, select  and then Download.
    • Select the row that corresponds to the report definition whose exports you want to download, and then, in the preview area, select  Download.
    • Expand the relevant report definition, and do one of the following:
      - Next to the individual export you want to download, select  and then Download.
      - Select the individual row that corresponds to the individual export you want to download, and then in the preview area, select  Download.
  1. The files corresponding to the selected exports are downloaded locally. The download location depends on your browser settings.

Delete Report Files

  1. System Browser is in Application View.
  1. Select Applications > Reports > […] > [report definition].
  2. The Reports tab displays.
  3. You can delete an individual export or all the exports for a report definition.
    In the History area, do one of the following:
    • Expand the relevant report definition, and next to the export you want to remove, select  and then Delete.
    • Next to the individual report definition whose export files you want to remove, select  and then Delete. If a message box informs you that there are multiple documents associated with this report definition, confirm Delete.
  1. The relevant execution records disappear from the History area, and the corresponding export files are deleted from the server.

Search or Filter Reports

  1. You want to search for a specific report definition or file (PDF or Excel) of a report definition.
  1. In System Browser, select Application View > Reports or subfolder.
  2. The Reports tab displays.
  3. In the Search box, enter the desired text.
  1. The items in the Reports tab are filtered as you enter the text.

Select a Related-Item Report

  1. In System Browser, select the system object you want to work with.
  2. Do one of the following:
    • If the right panel is expanded, locate the Reports section among the different related items, and then open it.
  3. If the right panel is collapsed, select one of the following:
    - to expand the right panel. Then locate the Reports section among the different related items and open it.
    - Report to directly expand the right panel with the Reports section open.
  4. Select the desired related-report item definition.
  1. The selected item opens in the Reports tab, in the Comparison pane.
  2. NOTE: When generating a report from the right panel in Flex Client, children of the selected object are always considered by default in Flex reports.
