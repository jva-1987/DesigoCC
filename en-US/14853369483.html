Working with Notification

This section provides step-by-step instructions for some common Notification tasks.

Start Notification from Event List

An event has occurred that triggered an alarm-triggered notification. The notification has Starting Mode = Manual, which means operator intervention is required for the system to start sending out the preconfigured messages.

  1. Event List displays on the screen.
  2. An event has occurred for which the command to start a notification is available.
  1. In Event List, select the event that triggered the notification.
  2. Click Launch Incident for the event.
  1. The system starts sending the notification messages preconfigured for this event. The command to stop notification is available for the event.

 

Stop a Notification from Event List

Sending of a notification is in progress. The notification was configured with Starting Mode = Manual and Can be stopped = Yes. You now want to interrupt (halt) sending of the messages.

  1. You previously started a notification from Event List, and the command to stop notifications is available for the event.
  • In Event List, click Cancel Incident for the event.
  • The system stops sending the notification messages preconfigured for this event. The command to start notification is available for the event.
