Improve Performance of Field Panel Editors

Read these topics if you are creating a new BACnet project or you are integrating an APOGEE Insight system, and plan to use Field Panel Editors hosted by the APOGEE field panel.

You can improve the performance of FPWeb UI and APOGEE Editors by allowing two types of cache: Internet Explorer Temporary Internet Files, and flash cache.

Flash Cache

Perform these steps if you are creating a new BACnet project or you are integrating an APOGEE Insight system.

FPWeb UI and APOGEE Editors are Adobe Flash-based applications that can “cache” field panel information.

  1. You have one of the FPWeb UI or APOGEE Editors displayed in a Desigo CC Secondary pane.
  1. Right-click and select Settings.
  2. Select the folder icon, clear the Never Ask Again check box, and move the slider all the way to the right, toward unlimited.
  3. Click Close.

 

Internet Explorer Temporary Internet Files

Perform these steps if you are creating a new BACnet project or you are integrating an APOGEE Insight system, and plan to use Field Panel Editors hosted by the APOGEE field panel.

Desigo CC uses Internet Explorer (IE) as its browser.

Using IE’s “temporary internet files” improves performance. Internet Explorer can obtain FPWeb UI and APOGEE Editors files from the field panel and store a local copy. Using the cached files is faster than communicating to the field panel to obtain the files.

In Internet Explorer, do the following:

  1. From the Tools menu, select Internet Options.
  2. In the General tab, under the Browsing history section, click the Settings button.
  3. Verify that the Automatically radio button is selected, and click OK.

 

Clearing the Cache

Perform these steps if you are creating a new BACnet project or you are integrating an APOGEE Insight system, and plan to use Field Panel Editors hosted by the APOGEE field panel.

When a new version of the FPWeb UI or APOGEE Editors’ files are released, the previous version should be removed from IE’s Temporary Internet files.

In Internet Explorer do the following:

  1. From the Tools menu, select Internet Options.
  2. In the General tab, under the Browsing history section, click the Delete button.
  3. Select the Temporary Internet files check box, and then click the Delete button.
