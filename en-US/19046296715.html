Scalance Ethernet Switches in Redundant Fiber Networks

Wide system architectures including remote connections over fiber optic lines can be realized in a Class X redundant fiber link configuration.

In such cases, you should apply the Siemens Scalance X200 switches to benefit from the redundant and diagnostic capabilities of the network devices in this family.
Particularly useful models for medium-size fire systems including a redundant fiber link are:

  • For UL applications - Scalance X204-2 switch unit, supporting four 10/100 Mbit/s Ethernet ports as well as two 100 Mbit/s fiber ports that you can set for a redundant (ring) supervised communication.
  • For UL/ULC applications - Scalance XC206-2SFP switch unit, supporting six 10/100 Mbit/s Ethernet ports as well as two 100/1000 Mbit/s fiber ports that you can set for a redundant (ring) supervised communication.

The following sections describe the setup and configuration procedures for the switches when applied to a redundant fiber connection with fault supervision.
