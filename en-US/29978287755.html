Filter Groups

  • Applies filters based on the polling intervals for the measurement points selected for archiving.
  • The Filter Group consists of a list of existing Desigo CC filter values in the form of time intervals to filter the measurement points to archive based on the selected archive group. This allows you to have a control on the measurement points which needs to be archived instead of storing huge data without any time stamp.
  • You can select any of the values to define the time interval for archiving. By default, the Filter Group value for all measurement points is set to Unfiltered, which archives the measurements without considering time dependency.
    The other filter groups archive the measurement points based on the time interval. For example, selecting 1 Minute Interval archives the measurement points every minute.

For related procedures, see Selecting the Filter Group for Devices.

When time-based smoothing is applied to the measurements from the System node, the Filter Group value changes accordingly and reflects the information in the respective Note field.
