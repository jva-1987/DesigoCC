FPWeb UI Overview

NOTE:
Web pages hosted by APOGEE field panels use Adobe Flash technology, which your browser might not support. Other options are available for editing APOGEE field panels that do not rely on Adobe Flash.

Desigo CC hosts several FPWeb UI editors that are designed to allow you to edit properties of objects in field panels. The FPWeb UI is similar to the interface used in the Field Panel Web Server program. To access these editors, you select the appropriate object in System Browser. This displays one or more links in the Related Items or Extended tabs. Clicking on the link displays the associated editor in the Secondary pane.

Prerequisites

  • It is recommended that you install or flash the latest firmware available to ensure the best system performance and to install the most recent bug fixes.
  • The Field Panel Web Server must be enabled in each field panel, and user interface files must be loaded on at least one field panel on every ALN in order to use this feature.
  • Because the FPWeb UI provides a similar interface to those provided by the Field Panel Web Server program, you should also use the BACnet Field Panel Web Server User Guide (125-3584) as a reference manual.
  • For editing/write capability in the FPWeb UI, System Manager must be set to Engineering mode. Operating mode offers view-only capability.
  • For proper viewing of the UI, you must install the 32-bit version of Adobe Flash Player on every machine where you will use FPWeb UI. This includes both the Desigo CC server and clients.
