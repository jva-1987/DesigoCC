Widgets Workspace

In the dashboard, widgets can be created to display charts and trends for measurement points from the configured device in the installed client. Live and historical values can be viewed from the widgets.

The following list of elements is commonly seen in all the widgets.

1

Displays the name of the current dashboard.

2

Displays the widget mode, either Create or Edit widget.

3

Displays the corresponding chart or trend for the created widget.

4

Settings

Contains the following options to configure the widgets.

- Widget name: Displays the widget name. You can change the name if required. Applicable to all the widgets.

- Period: Modify the period for the widget that is defined in the dashboard. Applicable to Consumption chart, Trend, and Line area chart.

- Default interval: Modify default interval for the widget that is defined in the dashboard. Applicable only to Consumption chart.

- Override dashboard settings: Override the dashboard settings for the widget and define the new settings. Applicable to Consumption chart, Trend, and Line area chart.

- Threshold settings: Define threshold for the widget. Applicable only to Gauge chart.

- Style: Change the color for the chart. Applicable to Consumption chart.

- Compare: Compare the consumption values for two different date ranges. Applicable only to Consumption chart.

- Default value view: Select the default view for the group list card in the widget. Applicable only to Grouped list card.

5

Source

Contains the following options to add and configure source for the widgets.

- Add: Select the device and corresponding data point for the chart. Displays all the devices from the system and area to select from it. Applicable to all the widgets

- Data point: Select the data point for the device from the drop-down. If no data point is selected,  icon displays to select the data point. You can use  search in the Data point field to find the data point. Applicable to all the widgets

- Y-axis: Change alignment of the chart y-axis to Left or Right. Applicable to Consumption chart and Trend.

- : Change the existing data points. Applicable to all the widgets

- : Delete the data points. If the screen size is small, the delete option will be automatically fit into the  icon. Applicable to all the widgets.

- Add group, Edit group, and Delete group options to customize and modify the groups. Applicable to Group list card.

- Style: Change the color for the line, and area min. and max. in the chart. Applicable to Trend, and Line area chart.


- For the Condition monitoring chart, it contains a list of all available breakers from the system, area, or device.

6

Axes/Scale

Axes displays the Minimum and Maximum value selector for Left and Right Y-axis. Applicable to Consumption chart and Trend.

Scale displays the Minimum and Maximum value selector, Auto scale, and Invert scale. Applicable only to Gauge chart.

7

Create

Create the widget in the dashboard.

8

Back

Displays when creating a widget for the first time. Discards all the changes and navigates back to Create widget page.

9

Cancel

Cancel the changes made to the widgets.
