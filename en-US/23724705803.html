Switch to Full-screen Mode

If available for an application located in Primary or Secondary pane, you can also work in full-screen mode that is, expand this application to full screen as follows:

  • On pane top right, select .
  1. A single pane layout occupies the entire work area, below the Summary bar, and between the navigation bar on the left and the right panel. Any other panes are hidden.
    NOTE: Full-screen mode is maintained when selecting an object in the System tree, pressing F5 to refresh the browser screen, switching tabs in the Primary pane, or switching from System to Events and then back to System. Full-screen mode is persisted across user’s sessions.
  • To exit full-screen mode, on pane top right, select .
    NOTE: You exit full-screen mode also when you switch to a different layout, or you do a send to secondary pane action.
