Edit a Dashboard and Widget

Edit a Dashboard

You can change the dashboard name, default dashboard and period, relocate the widgets in the dashboard using Edit Dashboard.You can also copy the dashboard configuration to another dashboard. For more information on copying the dashboard configuration, see Copy the Dashboards or Energy Management Tab Configuration.

  1. Select the dashboard that you want to edit.
  2. Select Edit dashboard from the Actions drop-down.
  3. The Edit dashboard pop-up window displays.
  4. Change the Dashboard name and Default period.
  5. Enable Set as default to set the default dashboard.
    The Set as default option is also available under the Actions in the dashboard.
  6. Click and drag the widgets to move it anywhere in the dashboard. This allows you to modify the preview of the dashboard.
  7. Click Save.
  8. The dashboard is updated.
