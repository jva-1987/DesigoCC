Management Station Hardware in ULC Fire Systems

 

In ULC fire and voice systems, the following types of management station hardware can be used:

  • Full Control – Comark Computer
    ULC S527-listed computers. This hardware can be used for any Desigo CC stations (Server, Client, FEP, physical server for virtual machines).
    For configuration examples, search and browse the Fire System Architecture sections. For minimum computer hardware and software specifications, see ULC S527-listed Computer Specifications.
  • Monitor Only – Off-the-shelf Computer
    Unlisted computers. This hardware can only be used for monitor-only stations.
  • Colocated Request/Grant/Deny Control Panel Settings
