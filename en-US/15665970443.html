APOGEE FLN Subpoint Selector

Complete the following procedures as needed:

Creating a Default Function

  1. You have Discovered a device whose application number is not in the Functions list.
  2. You are in Engineering mode, and you have selected the FLN Subpoint Selector tab.
  1. In the Application Selector section, select the application for which you want to create a default Function.
  2. In the Subpoint Selector section, scroll through the list, and select the check boxes in the Enabled column to enable subpoints or clear the check boxes to disable subpoints.
  3. From the toolbar, click Create Default Function, and then, once the System Manager dialog box displays, click OK to confirm the Function has been created successfully.
  4. From the Models & Functions tab you can configure the Function accordingly.
  5. Click Save .
  6. Once you have configured the Function, click Apply Default Function to apply the default Function to the appropriate devices.
  7. The System Manager dialog box displays confirming which devices the default Function has been assigned to. Click OK.

Deleting an Application

  1. You are in Engineering mode, and you have selected the FLN Subpoint Selector tab.
  1. In the Application Selector section, select the application you want to delete.
  2. Click Delete.
  1. The system deletes the application.

Modifying the FLN Subpoint List

  1. You are in Engineering mode, and you have selected the FLN Subpoint Selector tab.
  1. In the Application Selector section, select the application whose subpoints you want to modify.
  2. In the Subpoint Selector section, scroll through the list, and select the check boxes in the Enabled column to enable subpoints or clear the check boxes to disable subpoints.
  3. Click Save .

Syncing Subpoints to a Panel

  1. You are in Engineering mode, and you have selected the FLN Subpoint Selector tab.
  1. In the Application Selector section, select the application for which you want to bundle or unbundle data points.
  2. In the Subpoint Selector section, scroll through the list, and select the check boxes in the Enabled column to enable (bundle) subpoints or clear the check boxes to disable (unbundle) subpoints.
  3. From the toolbar, click Save , and then click ReSync .
  1. The devices in System Browser are updated to reflect the new list of unbundled data points.
  2. The System Manager dialog box displays confirming which devices the default Function has.
