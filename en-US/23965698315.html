Start and Exit Flex Client Web/Desktop App

You can access Flex client either in a browser or using the Flex desktop app.

Start the Flex Desktop App

  1. The Flex desktop app has been installed and set up on your computer.
  1. Double-click the Flex Client app icon on desktop.
  2. Depending on configuration, you may now see a certificate selection dialog box:
    • Select Use Certificate, then select the host certificate that identifies your Flex station, and click Continue.
    • If a Credential Required dialog box appears, then you must also provide the password for the selected certificate.
      NOTE: If you do not know which is the correct certificate and/or its password, contact your system administrator.
      It is also possible to select No certificate and use Flex client as an anonymous, rather than identified, station.
  3. Now you can proceed to log into Desigo CC. See Log into Flex Client Web/Desktop App, below.

Start Flex Client Web App in the Browser

  1. You have a working [Flex client URL] that you can use in the browser.
  2. You have a compatible web browser. See Browser Compatibility with Operating System, below.
  1. Enter the [Flex client URL] in the browser address bar and press Enter or select Go.
  2. Depending on configuration, you may now see a certificate selection dialog box:
    • Select the host certificate that identifies your Flex station and select OK.
    • If a Credential Required dialog box appears, then you must also provide the password for the selected certificate.
      NOTE:       If you do not know which is the correct certificate and/or its password, contact your system administrator.
      It is also possible to select Cancel in the certificate dialog box and use Flex Client as an anonymous, rather than identified, station.
  3. Now you can proceed to log into Desigo CC. See Log into Flex Client Web/Desktop App, below.

Log into Flex Client Web/Desktop App

  1. You have started Flex Client, either in the desktop app or browser.
  1. If you are an Open ID user, authenticate yourself on the OIDC provider.
  2. If Flex Client started up with a default user automatically logged in:
    • In horizontal navigation bar, select the default user initials.
    • Select Log in.
  3. The Desigo CC login screen appears.
  4. In the Desigo CC login screen:
    • Enter your username, and select Next.
    • Enter your password, and select Log in.
  1. You are logged into Flex Client with your Desigo CC credentials.

NOTE: If you are an exclusive user, OIDC authentication (if applicable) and the Desigo CC password are only required the first time. Subsequently you need only enter your Desigo CC username.
If you are logged off automatically due to inactivity, regardless of whether you are an exclusive user, you will no longer be required to authenticate on the OIDC provider.

Refresh Flex Client Web/Desktop App

  • To manually refresh Flex web/desktop app, proceed as follows:
    • In Flex web app, select  in the browser toolbar, or press F5 key on the keyboard.
    • In Flex desktop app, select  and then choose Refresh.

Log Out of Flex Client Web/Desktop App

  • In the horizontal navigation bar, select your initials, and then  Log out.
  1. If a default user is configured, the default user is automatically logged in.
  2. Otherwise, the Desigo CC login screen appears.

With Desigo CC version 6.0 or higher, when you log in to the Flex Client application using an Identity Provider, you must log out from Flex Client and the Identity Provider independently. However, if you are logged in to the Flex Client app with MyId (Siemens ID) via Auth0, then a single logout from Flex Client applies to both Flex Client and the Identity Provider.

Exit Flex Client Web/Desktop App

  • In the Flex desktop app, click Close in the top right corner of the main system window to quit the application.

 

  • In the browser, make sure to log out of Flex Client first, then you can close the browser tab.

Security of Flex Client in the browser

Use the Log out option to exit the Flex Client web app rather than only closing the browser tab or entering another URL in the address bar. If you close the browser or leave the page without logging out, it will continue to count as an active session.
After logging out, you can close the browser tab. If using a shared computer or device, make sure to also clear the browser history and cache.

Browsers offer to save your username and password so that they are remembered at the next login. It is recommended to decline this option.
Your organization can take measures to disable browsers from storing your login credentials.

Update the Flex Desktop App

  1. When you start the desktop app, a message tells you that a new update is ready to install.
    NOTE: The update app message will not display in closed mode.
  1. Do one of the following:
    • To install the newer version immediately, select Quit application and install update now, and then Continue.
    • To do the update later, select Snooze and remind me again in, and then choose the interval of time after which the reminder will display again.
  2. Once you choose to install the update, click Yes, and then follow the instructions in the setup wizard.

NOTE: Once the update is completed, see your System Administrator to have the closed-mode folder deleted from the file system.

Notes on Default User

If Flex Client is configured to have a default user automatically logged in note that:

  • Auto-logoff after a period of operator inactivity does not occur while the default user is logged in.
  • Even if you exit Flex Client with another user logged on, at the next start Flex Client will run with the default user.
