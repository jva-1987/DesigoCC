Importing APOGEE Insight Graphics

  1. System Manager is in Engineering mode.
  2. There is a Symbols folder available under System Settings > Libraries > L4-Project > Common > Common.
  1. In System Browser, select Management View.
  2. Select Project > System Settings > Conversion Tools > APOGEE Graphics Importer.
  3. From the Graphics Import tab, click Select APOGEE Graphics .
  4. In the Graphics Folder Selector dialog box, do one of the following to select the graphics folder directory that contains the APOGEE graphic folder you want to import:
    • In the Look In field, type the name of the graphics folder.
    • Navigate to and click on the graphic folder.
  5. Click OK.
  6. In the Graphics Importer tab, a list of all the available graphics folders displays.
  7. To filter the list of graphics to display, in the search field, type the name of the graphic you want to display. As you enter the text, the matching graphics display.
  8. To select the graphics you want to import from the displayed list, do one of the following:
    • Select the check box next to the graphics to import.
    • To select all the graphics in the list for import, select the checkbox in the heading row.
  9. To specify the Graphics Folder each graphic is imported into, for each graphic folder do the following:
    • Select the checkbox next to the graphic(s) you want to import into the folder. To select all graphics, select the checkbox in the header.
    • Navigate to Application View, and from the Graphics node, drag the appropriate folder and drop it over to the APOGEE Graphics Importer pane.
    • Repeat for each folder as needed.
      NOTE: Graphics that do not have an associated Graphics Folder selected for them are automatically imported into the Graphics root folder.
  10. To start the import, from the toolbar click Save Graphics .
  11. The graphics migration runs.
  12. Once the migration is complete, the status next to each graphic indicates the following:
    • Migrated Successfully – New graphics are available in System Browser under Applications > Graphics.
    • Migrated with Errors – Graphics may have been imported. A log file listing errors during migration is available under GMSMainProject > _DefaultProject > GraphicsImportLog.
    • Failed – Nothing has imported. A log file listing errors during migration is available under GMSMainProject > _DefaultProject > Temp > GraphicsImportLog.
  1. The graphics are imported to Applications > Graphics folder. The symbols are imported to Project > System Settings > Libraries > L4-Project > Common > Common > Symbols.
