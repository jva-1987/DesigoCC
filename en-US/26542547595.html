Operator Tasks

This section contains general reference information for the operation of the Operator Tasks extension module. For related procedures, see the step-by-step section.

The Operator Tasks application helps you create, automate, and manage building tasks that are not part of regular schedules. For instance, you can use it to temporarily silence alarms in the building during maintenance for a specific duration, such as 2 hours.

An operator task consists of one or more commands that are executed when the task is started.

  • Operator tasks begin to execute when you start them, or at a specified time after that.
  • Operator tasks end after a specified duration, or at a specific date/time.
  • When an operator task ends, a manual or automatic revert can set the commanded parameter back to its original state or a new state/value.

Tasks are created based on pre-programmed templates with specific properties and command sequences. Select the template corresponding to the action you want to perform (for example, Suppress Alarms) and then add target objects of the appropriate managed type.
