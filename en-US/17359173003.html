APOGEE Cross Trunk

Cross Trunk enables an APOGEE P2 panel, while acting as a client, to reference APOGEE BACnet points or P2 points that are on a different Building Level Network (BLN). The client references and/or commands the value of a point, while the server is where the point resides. With some limitations, which are described later, using Cross Trunk is as simple as adding a reference to a point on another BLN, or an APOGEE BACnet point, at the appropriate locations within the PPCL Editor, Trend Editor, and the Equipment Scheduler (EQS).
Cross Trunk supports Front End Processor (FEP) network connections to network field panels. A FEP is a computer that provides additional connections between building level devices (such as field panels) and the Desigo CC system.

NOTE:
While acting as a client, Cross Trunk does not enable a BACnet panel or APOGEE BACnet panel to reference P2 points.

Pre-Condition and General Guidelines

Some general guidelines for using Cross Trunk include:

  • If Cross Trunk is active in Desigo CC, any Insight workstations on the same network must have the InsightCrossTrunkService set to Stopped.
  • Cross Trunk is not intended for real-time control. Therefore, avoid Cross Trunk references in commands such as PPCL LOOP statements.
  • Because commands and COVs are sent once per second, if multiple commands per second are attempted, only the last command is sent. Likewise, with multiple COVs, only the last COV is sent.
  • Cross Trunk can be enabled and disabled in Management View for a selected BLN in the APOGEE Configuration tab > Network Settings section. This may be useful during migration and enabling Cross Trunk in Desigo CC only after the BLN has been completely removed from Insight.
    NOTE: Anytime you disable Cross Trunk, you must manually restart the associated Network driver, so that it can update it’s connections.
  • If you migrate away from APOGEE P2 panels to PXC.A variants, Cross Trunk is not supported. Other panel types may also lack Cross Trunk support.
