Converting APOGEE Notification Recipients

  1. The prerequisites in the APOGEE Notification Recipient Converter Overview have been met.
  1. Navigate to APOGEE_System > Additional SW > APOGEE RENO.
  2. Right click on the APOGEE RENO_CSV_Converter.exe file and select Run as Administrator.
  3. Click Browse and select the APOGEE Insight recipients report you want to convert for compatibility with Desigo CC.
  4. Click Save and type a new name for the CSV file.
  5. The CSV is converted to a tabular formatted CSV file compatible with Desigo CC.
  6. Click Close.
