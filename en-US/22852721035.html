Events Workspace

When you select Events in the horizontal navigation bar, the event handling workspace displays below the Summary bar.

1

The Events workspace consists in a single pane layout ()arranged as follows:

  • A list of events on the right
  • Details relevant to the selected event on the left

You can drag the splitter between the list area and the details area to adjust their size. See also Adjust Layout.

2

By default, the right panel is collapsed.

If you select an event in the list:

  • By selecting  on the right, the right panel expands next to the event details, and displays the Properties application for inspecting and commanding the properties for the event source. It also includes any event source-related items (such as Trend to work with trend data, Report for generating and exporting reports; and so on) that you can display by selecting the corresponding tab.
  • By selecting one of the related-items icons on the right, the right panel expands and displays the corresponding event source related-item application.
  • By selecting , you can display the event source pop-up overlay. Then by selecting Go to events, the list of events refreshes and displays only the event relevant to the source in alarm.

Regardless of the event selection in the list, from the horizontal navigation bar, you can access additional features, among which some can display in the right panel.

The available layouts vary depending on the browser window size or the device screen resolution (see the following table for reference).
