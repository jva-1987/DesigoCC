Modifying SNMP Network Settings

You can modify the name of the SNMP network and adjust its parameters, if needed.

 

  1. System Manager is in Engineering mode.
  1. In System Browser, select Management View.
  2. Select Project > Field Networks > [SNMP network].
  3. In the System Management tab, open the General Settings expander.
  4. Modify one or more of the following settings:
    • Name (SNMP network name).
    • Port (UDP Port number to send the SNMP request to. Range: 1—65535. Default is 161.) This value must exactly match the port of the device you want to monitor.
    • Timeout (Time to wait before sending the request again if no reply has been received. Range: 500—10000 milliseconds. Default is 500 milliseconds.)
    • Retries (Maximum number of times an SNMP request for a device response must be retried. Range: 1—1000. Default is 1.)
    • Polling (Frequency in milliseconds at which a device is polled by the SNMP driver. Range is equal to or more than 500 milliseconds. Default is 30000 milliseconds.)
  5. Click Save .
