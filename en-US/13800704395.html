Sharing the Database

  1. Open Commissioning Tool Job Editor and create a new job in [YourDrive]:\Jobs\[ProjectName].
  2. Navigate to [YourDrive]:\Co mmTool\Database.
  3. Right-click on the Database folder, and then select Properties.
  4. Select the Sharing tab.
  5. From the Advanced Sharing section, click Advanced Sharing. Click Yes when prompted if you want to allow the following program to make changes to your computer.
  6. The Advanced Sharing dialog box displays.
  7. Check the Share this folder check box.
  8. In the Settings section, in the Share name field, type ATOM$.
  9. Click Permissions.
  10. From the Group or user names section pane, select Everyone.
  11. From the Permissions for Everyone pane, check the Allow check box to give Full Control.
  12. Click OK.
