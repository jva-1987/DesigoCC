Add NCC Nodes to XNET Network

You can manually add nodes to represent the NCC stations included in your XNET network.
These nodes provide support for events affecting the NCC stations.

  1. System Manager is in Engineering mode.
  2. You configured the XNET network.
  1. In System Browser, select Management View.
  2. Select Project > Field Networks > [XNET network].
  3. In the XNET tab, click Create a New NCC Object .
  4. In the New Object dialog box, enter a name and description.
  5. Click OK.
  6. The newly created NCC node is automatically selected in System Browser.
  7. In the Node Settings expander, assign the NCC an Address in the XNET network, ranging from 1 to 64 (addresses already taken by imported panels are not displayed).
  8. Click Save .
  9. Click OK.
  1. The new node is added to System Browser.
