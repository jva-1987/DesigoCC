Consumption Chart Workspace

The Consumption chart displays the historical consumption values for a specified period using bar chart. By default, the consumption chart displays the values based on the timeline defined in the dashboard. You can change this timeline from the Settings option while creating the widget.
The Consumption chart widget supports only the counter data points from the selected source. In the consumption chart, compared data between two different date ranges can be created.

Axes

Displays the Minimum and Maximum value selector for Left and Right Y-axis.

- Left/Right Y-axis: Min. : Specify the minimum range for the left/right y-axis, which is displayed in the consumption chart. This is editable if the Left Y-axis is selected for the chart in the Source tab.

- Left/Right Y-axis: Max.: Specify the maximum range for the left/right y-axis, which is displayed in the consumption chart. This is editable if the Right Y-axis is selected for the chart in the Source tab.

- Auto-scale: By default, the Auto Scaling is enabled. To change the minimum and maximum Y-axis (left or right) values, disable the auto scaling.

10

The slider is available at the bottom of the chart by default and it is focused to display 80% of the values if the values are more. Similarly if there are fewer values, the slider will adjust to fit the entire chart. You can also adjust the slider to view the specific range of values.
Adjust the slider horizontally or select a particular area in the slider to view that part of the trend with time and date related to your selection.
