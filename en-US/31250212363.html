Configuring System Unattended Audible Alarms

Scenario

You want to generate an audible alarm on the fire control panel and, optionally, on the management station (from the Comark monitor card), when Desigo CC is unattended.

  1. System Manager is in Engineering mode.
  2. The Comark driver was configured.
  1. In System Browser, select Application View.
  2. Select Applications > Logics > Reactions.
  3. Select the Reaction Editor tab.
  4. (Optional) In the General Settings expander, enter a comment about the unattended audible alarm.
  5. Open the Triggers and Values and States expanders.
  6. In System Browser, select the Manual Navigation check box, and then select Management View.
  7. Select Project > Management System > Servers > Main Server.
  8. Drag the Main Server node into Values and States.
  9. A new trigger row displays.
  10. In the Property column, select System Manned.
  11. In Value Range, select = False.
  12. Open the Output and Action expanders.
  13. Add the Comark card alarm:
    • Drag Project > Management System > Servers > Main Server > Drivers > [COMARK driver] into Action.
    • In the Command column, select Unsilence and then True.
  14. Open the Output and Else Action expander.
  15. Add the Comark card alarm:
    • Drag Project > Management System > Servers > Main Server > Drivers > [COMARK driver] into Else Action.
    • In the Command column, select Unsilence and then False.
  16. Click Save As .
  17. In the Save Object As dialog box, do the following:
    a. Select the main Reactions folder or any subfolder under it as the destination where you want to save the new reaction.
    b. Enter a name and description.
    c. Click OK.
  18. The new reaction object is added to System Browser and is enabled by default.
  19. In System Browser, clear the Manual Navigation check box.
