Configure the Fire WAN Network

  1. Select Project > Field Networks.
  2. In the Object Configurator tab, click New , and select New Fire WAN Network.
  3. In the New object dialog box, enter a name and description.
  4. Click OK.
  5. The newly created network is automatically selected in System Browser.
  6. In the FireWAN tab, select the Network Settings expander.
  7. From the Monitored by driver drop-down list, select the Fire WAN driver you configured previously.
    NOTE: A Fire WAN driver can only be associated to one Fire WAN network.
  8. Click Save .

For background information about the WAN configuration parameters, see the reference section.
