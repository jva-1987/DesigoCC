Manage Startup Issues

Message

Situation

Do the following...

No connection to the building management platform.

When you try to log in, and WSI is unreachable.

Wait until the connection is reestablished.

See your system administrator.

The user name or password is incorrect.

Invalid user credentials and you cannot log in.

Enter valid user name or password.

Credentials of account are expired and need to get changed first.

Password has expired, and you cannot log in.

Update the password.

A needed license is missing or expired.

One or more licenses are missing or expired, and Flex Client cannot start.

See your system administrator.

A required license option is missing.

One or more license options are missing, and Flex Client cannot start.

See your system administrator.

The network connection to the system is lost.

The Flex Client screen is grayed out and Flex Client cannot be used because there are connectivity problems to the web service (for example, network cable disconnected or web service down).

Wait until the connection is reestablished.

See your system administrator.
