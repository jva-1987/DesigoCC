List View

This section provides step-by-step instructions for the Textual Viewer tasks in the Flex Client. For background information, see the reference section.

 

Display or Hide a Column

  1. You want to change which columns are visible in List View.
  1. Select .
  2. The Customize Columns dialog displays.
  3. Switch as desired:
    The column displays.
    The column does not display.
  4. Select .
  1. Your column visibility preferences are now changed.

Reorder a Column

  1. Select .
  2. The Customize Columns dialog displays.
  3. Select the column name you want to move.
  4. Drag the column to the new location.
  5. Select .
  1. Your order preferences are now changed.

Making a New Selection in List View

  1. To make a new selection, select the object whose properties you want to view.
  2. Select the desired object.
  1. The object displays in Property Viewer.
