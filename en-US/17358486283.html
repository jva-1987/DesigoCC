Settings

The Settings expander enables you define a zone, which includes specifying the building resource(s) that you want to schedule, and configuring the default operating mode, unit of measurement for optimization, optimization parameters, and whether or not the zone is available for scheduling.

Definition

Item

Description

System Name

Displays the unique name that identifies a zone.

NOTE: You cannot edit the System Name once the zone is saved.

Name

Displays the User Name of the zone.

Descriptor

Displays text that provides additional information about the zone. (Optional)

> Type a descriptor using up to 16 characters, upper- and lower-case letters, numbers, or periods.

Field Panel

Displays the name of the field panel in which the zone is defined.

When you save the zone for the first time, the Save dialog box prompts you to select a network and a device (field panel) from that network to associate with the zone.

State Text Table

Displays the state text table that supplies the mode names (VAC, OCC1) for a zone. The default entry for a zone is TxG_ApogeeP2_-2005_Zone_Mode.

> Click the drop-down arrow to select a new name from the list.

NOTE: You cannot edit this selection once the zone is saved.

Default Operating Mode

Displays the default mode the zone returns to when not in use. If you are using the default State Text Table entry for a zone, the default mode is VAC. Default operating modes include:

  • Vacant mode: VAC
  • Zone occupied modes: OCC1, OCC2, OCC3, OCC4, OCC5
  • Optimization occupied modes: Warmup, Cooldown, NGHT_HTG, NGHT_CLG, STOP_HTG, STOP_CLG

> Click the drop-down arrow to select a mode name.

NOTE: You cannot edit this selection once the zone is saved.

Units

Displays the unit of measurement for optimizations in a zone.

  • English. Displays values using the English unit of measurement.
  • System International. Displays values using the System International (SI) or modern metric unit of measurement.

Settings

Enable Scheduling

If checked, the zone is available for scheduling. If not checked, the schedules for the zone will not be executed.

Optimize with SSTO

If checked, zone optimization is enabled.

Recommand

If checked, displays the delay time, in seconds, after a warmstart to recommand a zone to the proper mode.

> Type a number to set the number of seconds to delay before the recommand.

Minimum Time Off

Displays the minimum time a zone can be in vacancy mode between two occupancy modes.

> Type a number to set the minimum time off, in minutes, between modes.

NOTE: If the time between two occupancy modes is less than the minimum off time, the zone remains in the first occupancy mode until the second occupancy mode starts.
