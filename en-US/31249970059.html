Configure the GCNET Network

Create the GCNET Network Node

  1. System Manager is in Engineering mode.
  1. In System Browser, select Management View.
  2. Select Project > Field Networks.
  3. In the Object Configurator tab, click New , and select New XNET GCNET.
  4. In the New Object dialog box, enter a name and description.
  5. Click OK.
  6. The newly created network is automatically selected in System Browser.

 

Import the GCNET Configuration

  1. The GCNET configuration file (typically named gms_gcnet.xml) is available locally or over the network.
  1. In the Import tab, click Browse to select the GCNET configuration file.
  2. Click Open.
  3. The file is checked for errors and the Analysis Log button becomes available to show the check log.
  4. If the file is valid, the list of units displays in the Source Items section on the left, showing the units whose database is in the configuration file.
  5. The Source Items list includes:
    - the VNT Settings
    - the Fire Command Center (FCC) list, including a panel ID, the panel name, and the number of instances, or objects, that belong to each FCC.
  6. In the Source Items list, click to select all files for import, or click to select an individual file.
    NOTE: You can filter the contents of the lists by typing some search-matching characters in the fields above the lists (Type to search fields). The filter is removed if you delete the text.
  7. Click Import.
  1. The VNT settings are imported into the GCNET node.
  2. The FCC panels configuration data is available in System Browser, under the GCNET node.
  3. The Import Log button becomes available to show the detailed import log.

NOTE: In distributed systems, you can import different fire networks on the distributed servers. However, on each distributed server, you need to import the GCNET configuration file, and select all FCCs required by the server to control the appropriate fire networks. As a side effect, not affecting the operation, this will cause multiple FCC nodes to be displayed in the Node Map if the same FCC is imported more than once.

 

Check and Align VNTs

  1. In the VNT Settings tab, select the VNT Connection Settings expander.
  2. Enter User name and Password for VNT data transfer. Then click Save .
    NOTE: Click Modify to edit a previous setting.
  3. Enter Password for VNT service user. Then click Save .
    NOTE: Click Modify to edit a previous setting.
    • Refer to the VNT Installation Instructions document.
  4. Open the VNT Settings expander.
  5. In Device Configuration, click Check.
  6. See the Device Configuration column. After a few second, it can be one of the following:
    • Unreachable: Communication problem. Verify the network connection and try again.
    • Aligned: The device configuration is aligned with the management station. No action required.
    • Outdated: The device configuration is not aligned with the management station and must be updated.
  7. Click Update to align a single device, or Update all to align them all.
