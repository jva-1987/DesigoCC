Settings

The Settings expander enables you define unit of measurement for optimization.

Definition

Item

Description

Units

Displays the unit of measurement for the schedule optimization.

  • English. Displays values using the English unit of measurement.
  • System International. Displays values using the System International (SI) or modern metric unit of measurement.
