Schedules

The Schedules expander enables you to view, modify, add, or delete an event or zone schedule.

Calendar

Select a date to view, modify, add, or delete an event or zone on that date.

Timeline

Displays events or zones scheduled on the selected date in the calendar.

Add New/Delete Schedule Buttons

Button

Description

Add New Schedule

Adds a new event or zone schedule to the Timeline based on the selected date in the Calendar and at the time the Add New Schedule button was clicked. To view the configuration settings for the schedule, click the schedule entry in the Timeline.

Delete Schedule

Deletes the selected event or zone schedule from the Timeline.

 

NOTE:
The Regular Schedule, Repetition, and Mode Information sections are only visible when you click the Add New Schedule button, or you have selected an already existing schedule in the Timeline.

Regular Schedule

Item

Description

Schedule Date

Date

Displays the date the schedule is set to run.

> Click the drop-down arrow and select the date.

Duration

Start Time

Displays the time of day the schedule starts.

> Use the UP and DOWN arrows to set the time the schedule will start.

End Time

Displays the time of day the schedule ends.

> Use the UP and DOWN arrows to set the time the schedule will end.

Span

Displays the number of days the schedule takes place.

> Use the UP and DOWN arrows to set the number of days the schedule will run.

Enable

When checked, the schedule is active on the Timeline and will run as scheduled. If not checked, the schedule is disabled on the Timeline and will not run as scheduled.

Repetition

Item

Description

Frequency

Defines how often the schedule will run.

> Click the drop-down arrow and select the frequency for the schedule.

  • One Time. Only occurs once.
  • Daily. Occurs every day.
  • Weekly. Occurs on the same day every week.
  • Working Days. Occurs Monday through Friday. This choice is only available if the Schedule Date is a work day (Monday through Friday).
  • Custom Weekly. Occurs on specified days every week. If this is selected, the boxes of the week are enabled, allowing you to check the specific days that you want the event to occur.

You can also select the term for the event:

  • Until. When selected, displays the end date for the schedule. Click the drop-down arrow to select an end date.
  • For. When selected, displays the number of days or weeks that the schedule will repeat from the start date. Type a value to specify the repetition.
  • Continuous. When selected, the schedule is configured to repeat without an end date.

Mode Information (Zone Schedules Only)

A zone should have at least two modes: vacant (VAC) for when the zone is not being used, and at least one occupied mode (for example, OCC1) for when the zone is in use.

Item

Description

Mode

Displays the mode the zone is in during the schedule.

> Use the UP and DOWN arrows to select a mode.

Overrides

Displays the associated overrides for an event or zone. To delete an override from an event or zone, click the X associated with the override entry.

Item

Description

New Override

Adds a new override for an event or zone. When clicked, the Override Details section displays, from which you can configure an override.

Override Details

Override Date

Displays the date the override takes place. The date is determined by the date or selection in the calendar.

Enable

When checked, the override is active on the Timeline and will run as scheduled. If not checked, the override is disabled on the Timeline and will not run as scheduled.

Duration

Start Time

Displays the time of day when the override starts.

> Use the UP and DOWN arrows to set the time the override will start.

End Time

Displays the time of day when the override ends.

> Use the UP and DOWN arrows to set the time the schedule will end.

Span

Displays the number of days the override takes place.

> Use the UP and DOWN arrows to set the number of days the override will run.

Copy To

Allows you copy the schedule to another event, zone, or replacement day. A zone should have at least one active schedule to copy. Drag-and-drop an event, zone, or replacement day from System Browser over the Drop [Item] here text, and then click Copy.

NOTE:
Day shift schedules cannot be copied.
