Groups Workspace for Mobile Flex

To view the Groups workspace, rotate your mobile screen and navigate to Notification > Groups.

Groups Workspace

1

Groups (tile)

Displays the name and description of the group.

2

Search

Allows you to search for a group by name.

3

Create

Creates a new recipient group. For more information, see Create Group in Creating and Managing Groups.

4



Displays the following options:

  • Edit: Edits the name and description of the group. See Edit Group Details in Creating and Managing Groups.
  • Add recipient: Adds recipients to the group.
  • Delete: Deletes the group from the list. See Delete Group in Creating and Managing Groups.

1

Group list

Displays the list of recipients and groups which are a part of the selected group.

2

Search

Allows you to search for a recipient or group by name.

3



Navigates to the Group workspace window.

4



Displays the following options:

  • Add recipients: Adds recipients to the group. See Add Recipient in the Group in Creating and Managing Groups.
  • Create group: Adds a new group in the current group. See Add Group in the Group in Creating and Managing Groups.
  • Edit group: Edits the name and description of the group.

5

Show group

Navigates to the selected group.

6

Remove

Removes the recipient or sub-group from the parent group.
