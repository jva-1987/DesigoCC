Log View Definition Workspace

The Log View Definitions are present in the Application View > Log Viewer in the System Browser.
The log view definition created in the Desigo CC Installed client and Flex client reflects in the System Browser under Log View.

The changes made for log view definition in the Flex client reflects in the Installed client and vice-versa.

The Log View tab displays the list of log entries in the Master pane, and details of selected log entry in the Detailed pane.

 

1

System Browser

Displays the list of objects in the selected view.

2

Search bar

Displays the applied filter criteria for selected log view definition.
NOTE: Only Flex supported columns are displayed in the search bar.

3

Master pane

Displays the list of log entries for selected log view definition.

4

Search icon

Applies the filter for selected filter criteria.

5

Discard changes

Discards the changes done for the selected log view definition and brings it to original state saved on server.

6

Save filter

Saves the Log view definition changes.

7



Displays the following option:
Save as: Allows you to save the log view definition as a new log view definition.
Delete filter: Deletes the selected log view definition.
Customize columns: Display or hide columns in the Master pane.

8

Show details

Displays the activity details of the log entry displayed in the Detailed pane.
