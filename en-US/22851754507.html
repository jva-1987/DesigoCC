Change Your Password

Password Policy

  • Even though it is indicated that password must be at least 1 character, you may want to choose a strong longer password which contains:
    • Upper case (A-Z) and lower case [a-z] characters
    • Numeric characters (0-9)
    • Special characters:
      ! " # $ % & ' ( ) * + , - . / : ; < = > ? @ [ \ ] ^ _ ` { | } ~
  • When you enter a new password and confirm it, under those fields:
    • A green line appears, if the password is compliant with the password policy.
    • A yellow line appears, if the password does not comply.
  • Your new password must be different from your previous password.
  • When your password is more than 180 days old, you will be prompted to change the password automatically.
  • If you enter an incorrect password for all five attempts, your account will lock for 30 minutes.

 

Read the instructions of the topic that most closely relates to the task you need to carry out.

Change Default Password Upon Your First Logon

  1. Upon your first logon, you are forced to change the default password, and the change password fields are available.
  1. Complete all required fields—New password, Confirm password—and then select Change.
  2. The logon page displays.
  3. Enter password.
  4. Click Logon.
  1. The logon to the Flex Client application is carried out.

Change Your Password when it is About to Expire

  1. After logon, a notification in the bottom-right-hand corner tells you that your password is about to expire.
  1. In the horizontal navigation bar, select  Notifications.
  2. Under User Account, select the password expiration notification.
  3. The Change password dialog box appears.
  4. Complete all required fields—New password, Confirm password—and then select Change.
  1. The dialog box closes, and a success notification displays in the bottom-right-hand corner.

Change Your Expired Password

  1. Upon logon, a message tells you that your password has expired, and the change password fields are available.
  1. Complete all required fields—New password, Confirm password—and then select Change.
  2. The logon page displays.
  3. Enter password.
  4. Click Logon.
  1. The logon to the Flex Client application is carried out.

Change Your Password After Logon

  1. You are logged on to the Flex Client application.
  2. For security reasons or reset, you want to change your password.
  1. In the horizontal navigation bar, select your initials, and then select Account.
  2. The account page displays.
  3. Select Change password.
  4. The Change password dialog box displays.
  5. Complete all required fields—Current password, New password, Confirm password—and then select Change.
  1. The dialog box closes and a success notification displays in the bottom-right-hand corner.
