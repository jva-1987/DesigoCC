Point Editor Toolbar

The APOGEE Point Editor toolbar allows you to create, save, and delete APOGEE points.

Point Editor Toolbar

Icon

Name

Description

New

Allows you to create a new point.

Save

Saves the point to the field panel.

Save As

Allows you to save the point information with a different point name.

Delete

Removes the point from System Browser and the field panel.
