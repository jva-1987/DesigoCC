Back Up and Restore Field Panel Editor Databases

Perform these steps if you are creating a new BACnet project or you are integrating an APOGEE Insight system, and plan to use Field Panel Editors hosted by the APOGEE field panel.

APOGEE Field Panels must be at Revision 3.2.4 or later for networks that include Desigo CC. Initial field panel setup (field panel settings, initial field panel database, making panel ready, and so on) occurs using Commissioning Tool (CT).

Database Restore Options

The field panel can have its database restored in one of three ways based on the following restore order:

  • Field panel flash file
  • Insight
  • Desigo CC

Field Panel Flash File

When the Insight workstation is not the database restore source, and the field panel is configured to autorestore, and a database has been saved to the panel’s flash file system, the field panel will get its database restored from flash. The field panel’s flash-file system backup is triggered by database change notifications in conjunction with a 15-minute inactivity timer.

Insight Workstation

When an Insight workstation is configured as the panel’s Main Disk or Backup Disk, and Insight is online, the field panel will get its database restored from Insight. The Insight workstation’s backup is triggered by database change notifications.

Management Station

When the field panel’s flash file is not the database restore source, and the Desigo CC Backup/Restore feature is enabled for the field panel, the field panel will get its database restored from Desigo CC. The field panel is backed up to the management station every 24 hours. The 24-hour timer is triggered when the management station server starts.

NOTE:
When the management station discovers an APOGEE field panel, it will auto-add itself as the field panel’s Main Disk or Backup Disk, if a slot is available, and the field panel is in ready state, in order to receive database change notifications. However, the management station separates the concept of field panel Main Disk/Backup Disk from the Desigo CC feature of Backup/Restore. The Backup/Restore feature of the management station, which uses native BACnet services, can be enabled or disabled independently.

Steps to Manage a Panel’s dbFile Settings

  1. The field panel’s default web server Enabled setting is Disabled.
  2. The field panel’s default dbFile setting is AutoRestore/AutoSave Disabled.
  3. When you configure a Revision 3.2.4 field panel using CT to web server Enabled, the field panel automatically adjusts the dbFile settings to AutoRestore/AutoSave Enabled.

Steps to Enable the Management Station Backup/Restore Feature

When you add a Revision 3.2.4 field panel to Desigo CC, you must do the following so that Desigo CC can be a database restore source:

  1. Select Engineering mode.
  2. Select the field panel in the System Browser.
  3. Select the BACnet tab and open the Backup/Restore Information section.
  4. Check Enable automatic backups and restores.
  5. In the Reinitialize password and Confirm password fields, enter the password used to log on to the field panel.
  6. Click Save .

NOTE:
Unless explicitly disabled, when Desigo CC discovers an APOGEE field panel, Desigo CC adds itself as a destination to each existing notification class in the field panel.
