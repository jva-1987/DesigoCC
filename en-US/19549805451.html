Documents

This section provides instructions to work with documents or web pages in the Flex Client application. For background information, see the reference section.

Display Documents in Tile View

  1. You want to display the documents as tile icons in the Documents tab.
  1. In System Browser, select Application View.
  2. Do one of the following:
    • To display all the available documents as tile icons in the Documents tab, select Applications > Documents.
    • To display only the documents of a specific subfolder as tile icons in the Documents tab, select Applications > Documents > […].

Search or Filter Documents

  1. System Browser is in Application View.
  2. In System Browser, the Documents folder or a subfolder is selected.
  • In the Search box of the Documents tab, enter the desired text.
  1. The items in the Documents tab are filtered as you enter the text.

View a Document

  1. System Browser is in Application View.
  2. In System Browser, the Documents folder or a subfolder is selected.
  1. Do one of the following:
    • In System Browser, select the node that corresponds to the document you want view.
    • In the Documents tab, select the tile icon that corresponds to the document you want view.
  2. The content of the selected document that corresponds to a file or to a website (included in the list of allowed websites) is displayed in the Documents tab. A website that is not in the list of allowed websites displays in another browser tab.
  3. (Optional) If you wish to open the same document in a separate window or tab, do one of the following:
    • If you are working with the Flex desktop app, in the Documents tab, select  Open in new window.
    • If you are working with the Flex web app, in the Documents tab, select  New tab.

View a Related-Item Document

  1. You selected a system object that has one or multiple documents related to that object.
  1. Do one of the following:
    • If the right panel is expanded, locate the Documents section among the different related items, and then open it.
    • If the right panel is collapsed, select one of the following:
      -  to expand the right panel. Then locate the Documents section among the different related items and open it.
      - Document to directly expand the right panel with the Documents section open.
  2. Select the document-related item you want to open.
  3. If you selected a related item corresponding to a file or a to a whitelisted website, the relevant file or web page opens in the Documents tab, in the Comparison pane.
  4. If you selected a related item corresponding to a web page that was not whitelisted, this web page opens in another browser tab.
  5. (Optional) If you wish to open the same related-item document in a separate window or tab, do one the following:
    • If you are working with the Flex desktop app, next to the related item select and then Open in new window.
  6. If you are working with the Flex web app, next to the related item select and then New tab.
