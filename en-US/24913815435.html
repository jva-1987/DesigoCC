Assigning Devices to Groups

In Device View you can group devices together to more easily monitor them through a group tile. There are various methods for assigning devices to groups. Group creation happens during device assignment.
NOTE: A device can only be a member of one group at a time. If a device is already assigned, you must remove it from its group before you can assign it to a different group.

Assign a Single Unassigned Device to a Group

  1. On the device tile, select  and then select Add to Group.
  2. In the Add device to group dialog box, select an Existing group from the list, or set New group and type in a name to create a new group.
  3. Select Add.
  1. The device is assigned to the specified group.

Group Unassigned Devices (with Multi-Select)

You can multi-select unassigned device tiles and then group them together with a single command. This method requires a keyboard and mouse.

  1. Hold down the CTRL key and click on each of the device tiles you want to select.
  2. The selected tiles are marked with a blue border. Note that it is not possible to multi-select group tiles, or device tiles already assigned to a group.
  3. On any one of the selected tiles, select  and then select Add to Group.
  4. The Add devices to group dialog box shows you the devices you are about to group together. If required, you can deselect any devices that you do not want to include in the operation.
  5. Set the group to which the devices should be assigned: Either select an Existing group from the list, or select New group and type in the name of the group to create.
  6. Select Save.
  1. The selected device tiles are assigned to the specified group.

Group Unassigned Devices (from Edit Menu)

From the Edit menu, you can perform an Add to group, choosing from a list of all the devices that are currently not assigned to any group.

  1. Select and select Add to group.
  2. The Select devices to group dialog box shows a list of all the devices that are currently unassigned.
  3. Select the check boxes alongside the devices that you want to group together. You can type some text into the search.. field to filter the device list.
  4. Select Next.
  5. The list now shows the devices you are about to group together. If required, you can deselect any devices that you do not want to include in the operation.
  6. Set the group to which the devices should be assigned: Either select an Existing group from the list, or select New group and type in the name of the group to create.
  7. Select Save.
  1. The selected devices are assigned to the specified group.

Add Unassigned Devices to an Existing Group

From a group tile, you can assign new devices to the group, choosing from a list of all the devices that are currently unassigned.

  1. From the group tile, select  and then select Manage Group.
  2. The dialog box shows the current members of the group.
  3. Select Add.
  4. The Select devices to group dialog box shows a list of all the devices that are currently unassigned.
  5. Select the check boxes alongside the devices that you want to add to this group. You can type some text into the search.. field to filter the device list.
  6. Select Add again.
  7. The list now shows the updated members of the group, including the devices you just added. If required, you can deselect some devices at this point.
  8. Select Save.
  1. The selected devices are added to the group, and any deselected ones are removed.

Move Some Devices from one Group to Another (Existing) Group

From a group tile, you can move some of the group's members to a different group. This must be an already-existing group, you cannot create a new group in this workflow.

  1. From the group tile, select  and then select Manage Group.
  2. The dialog box shows the current members of the group.
  3. Select the Add to group option and, from the drop-down list, select the desired target group.
  4. Select the check boxes alongside the devices that you want to transfer to this target group.
  5. Select Save.
  1. The selected devices are removed from the current group and assigned to the specified target group.
