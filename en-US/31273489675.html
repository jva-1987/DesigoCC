Create a Line Area Chart

You can create a Line area chart that displays a line chart with area data points. For background information, see Line Area Chart Workspace.

  1. In the dashboard, select the Line area chart from Create widget list.
  2. Click Next.
  3. The Create widget page opens.
  4. Click Add to select the data point.
  5. Select the device from the list and click Select.
  6. Select the Data point from the drop-down.
    In the Installed Client, data points must be archived to view their values in the Flex Client Line area chart. For more information on devices that supports the line area chart by default, see Line Area Chart Workspace.
  7. The Min. data point and Max. data point fields displays.
  8. Select the Min. data point and Max. data point from the drop-down. For the line area chart, these values must be selected.
    For data points that support minimum and maximum values, these fields are auto-populated when the main data point is selected. For data points that do not support minimum and maximum values, the Min. data point and Max. data point drop-down lists display the data points based on the unit of the selected main data point.
  9. The Line area chart displays with minimum and maximum area data points.
  10. Click Create to add the widget to the dashboard.
  11. Click Save.
  1. The Line area chart is created in the dashboard.
