Viewing the Details of Ownership Actions

Scenario

You want to view historical data of the commands executed on a fire panel, including actions relating to request and transfer of ownership. On this last purpose, it is necessary to add a specific column to the log.
NOTE: To view historical data relating to changes of ownership, a specific engineering configuration is required (see Related Topics).

  1. In the Contextual pane, click the Detailed Log tab.
  2. Click Select columns .
  3. In the Select columns dialog box, do the following:
    a. In the Available columns list, select the check box that corresponds to the column Action Details.
    b. Click OK.
  4. Click Save as Default , to save the changes also for the next work sessions.
