(Optional) Configuring the Datamate Advanced Editor

Desigo CC includes editors within the software that allow you to edit most APOGEE field panel data. The following editors are included in the management platform:

  • APOGEE Equipment Scheduler
  • APOGEE Point Editor
  • APOGEE PPCL Editor
  • APOGEE FLN Subpoint Editor
  • APOGEE Trend Editor
  • BACnet Editor
  • BACnet Scheduler
  • Operation and Extended Operation Tabs

Datamate Advanced can be used for additional Field Panel configuration requirements.

To access the Datamate Advanced Editor, you must select the appropriate object in System Browser. This displays one or more links in the Related Items or Extended Items tabs. Clicking on the link displays the editor in the Secondary pane.

The system must be in Engineering mode to make changes with the editor. Operating mode offers view-only capability.

DMA is a full-featured tool for configuring APOGEE field panels. DMA allows you to configure both P2 and BACnet networks. You can use DMA to add FLNs, create and edit points, create and edit PPCL, and run field panel reports.
Datamate Advanced (DMA) is targeted for: large sites with sophisticated users and sites where frequent configuration changes occur. Power users at these sites appreciate the bulk configuration capabilities of Desigo CC , including Attribute Duplicator, Global Commander, and the Trend Grid application. They also benefit from access to System Profile and field panel reports available in DMA. Additionally, sites migrating from APOGEE Insight to Desigo CC have users who are already familiar with the DMA applications, which are identical to the same applications in the APOGEE Insight software. Providing access to DMA after migration provides a smoother transition from APOGEE Insight to Desigo CC.

Please note the following:

  • If you are running DMA on the same computer as Desigo CC, then DMA must use a different port.
  • If you are running DMA on an APOGEE Ethernet Microserver (AEM) network, you must have two AEM devices—one for Desigo CC and one for DMA.
