Import the Comark Driver Settings from a File

  1. An XML file containing Comark driver configuration data is available in the Device folder of [Installation Drive]:\[Installation Folder]\[Project Name].
  2. A Comark driver object was already created.
  1. In System Browser, depending on where the Comark card is installed, select one of the following:
    • Project > Management System > Servers > Main Server > Drivers > [Comark]
    • Project > Management System > FEPs > [FEP] > [drivers folder] > [Comark]
  2. Click the System Management tab.
  3. Click Import Device.
  4. In the Select device to import dialog box, do the following:
    a. Select the XML file that corresponds to the device configuration.
    b. Click Import.
  1. If the device being imported is the same as the one used for creating the configuration file, the configuration data is copied from file to device.
  2. If the property names do not match, the Combines properties dialog box displays, asking you to match the properties in the file with the device properties. Select the correct matching and click Import.
