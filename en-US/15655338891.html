APOGEE Editors Overview

NOTE:
Web pages hosted by APOGEE field panels use Adobe Flash technology, which your browser might not support. Other options are available for editing APOGEE field panels that do not rely on Adobe Flash.

The Desigo CC management station hosts several APOGEE editors that are designed to allow you to edit properties of APOGEE objects in APOGEE field panels. The APOGEE editors’ interface is similar to the interface used in the Field Panel Web Server program. To access these editors, you select the appropriate object in System Browser. This displays one or more links in the Related Items or Extended Items tabs. Clicking on the link displays the associated editor in the Secondary pane.

APOGEE Editors are special Field Panel Web Server UI pages used with Desigo CC Versions 1.0, 1.1, and 2.0 for viewing and editing points, PPCL, panels, and TEC subpoints. They remain available as legacy features and will not be enhanced in the future. APOGEE Editors can only be used with BACnet panels. They do not support P2 controllers.

You must be in Engineering mode to make changes with the editors. Operating mode offers view-only capability.

NOTE 1: Field Panel Web Server must be enabled in each field panel, and user interface files must be loaded on at least one field panel on every ALN in order to use this feature.
NOTE 2: Because these editors provide a similar interface to those provided by the Field Panel Web Server program, you should also use the BACnet Field Panel Web Server User Guide (125-3584) as a reference manual.
