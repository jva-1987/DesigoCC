APOGEE Editors

System Manager must be in Engineering mode in order to perform the tasks in this section.

Complete the following procedures as needed:

View APOGEE Editor Data

  1. In System Browser, navigate to and select the object (point, PPCL, or FLN device) whose data you want to view.
  2. If the APOGEE Editors feature supports the item, one of the following links in the Related Items tab displays:
    • ViewPointDefinition
    • ViewPPCL
    • ViewTECInitialValues
    • ViewTECDeviceDefinition
  3. Click the link.
  1. The Secondary pane opens, displaying the editor.

NOTE:
When this editor is opened in Operating mode, all fields are display only and cannot be edited. In order to make changes with this editor, System Manager must be in Engineering mode.

Create a Point

  1. In System Browser, select Management View.
  2. In System Browser, navigate to and select the field panel where you want to create the point.
  3. If the item is supported by the APOGEE Editor feature, the link AddNewPointDefinition displays in the Extended Items tab.
  4. Click the link. The Secondary pane displays a dialog box.
  5. In the Point Name field, enter the name of the point.
  6. In the Point type field, select the point type.
  7. Click Create to create the point.
  8. The Point Editor displays in the Secondary pane. Edit any additional fields that you want or which are required by the point type, and then click Save to create the point.

Edit a Point

  1. In the System Browser tree, navigate to and select the point whose data you want to edit.
  2. If the item is supported by the APOGEE Editor feature, the link Edit/DeletePointDefinition displays in the Extended Items tab.
  3. Click the link. The Secondary Pane opens, displaying the Point Editor.
  4. Edit any fields as appropriate.
  5. Click Save to save your changes.

Delete a Point

  1. In the System Browser tree, navigate to and select the point you want to delete.
  2. If the item is supported by the APOGEE Editor feature, the link Edit/DeletePointDefinition displays in the Extended Items tab.
  3. Click the link. The Secondary Pane opens, displaying the Point Editor.
  4. Click Delete.
  5. A message box asks you to confirm the deletion.
  6. Click Yes to delete the point, or, No to cancel the deletion.

Create a PPCL Program

  1. In System Browser, select Management View.
  2. In the System Browser tree, navigate to and select the field panel where you want to create the PPCL program.
  3. If the item is supported by the APOGEE Editor feature, the link Edit/DeletePPCL displays in the Extended Items tab.
  4. Click the link. The Secondary Pane opens, displaying the PPCL Editor.
  5. Click + (plus sign) at the bottom of the editor.
  6. A dialog box displays. In the PPCL Name field, enter the name of the program you are creating.
  7. If you want, you can assign it a priority level.
  8. Click Create.
  9. The name of the program displays in the Program list, and a blank programming space displays in the window.
  10. Edit the PPCL program using the available fields and buttons.
  11. Click Save to save any changes you’ve made.

Edit PPCL

  1. In System Browser, select Management View.
  2. In the System Browser tree, navigate to and select the field panel containing the PPCL program you want to edit.
  3. If the item is supported by the APOGEE Editor feature, the link Edit/DeletePPCL displays in the Extended Items tab.
  4. Click the link. The Secondary Pane opens, displaying the PPCL Editor.
  5. From the Program list, select the PPCL program you want to edit.
  6. The program is displayed in the editing window.
  7. Edit the PPCL program using the available fields and buttons.
  8. Click Save to save any changes you’ve made.

Delete a PPCL Program

  1. In System Browser, select Management View.
  2. In the System Browser tree, navigate to and select the field panel containing the PPCL program you want to delete.
  3. If the item is supported by the APOGEE Editor feature, the link Edit/DeletePPCL displays in the Extended Items tab.
  4. Click the link. The Secondary Pane opens, displaying the PPCL Editor.
  5. From the Program list, select the PPCL program you want to delete.
  6. The program is displayed in the editing window.
  7. Click the – (minus sign) at the bottom of the editor.
  8. A message box displays, asking you to confirm the deletion.
  9. Click Yes to delete the program, or No to cancel the deletion.

Create an FLN Device

  1. In System Browser, select Management View.
  2. In the System Browser tree, navigate to and select the field level network (FLN) where you would like to create the device.
  3. If the item is supported by the APOGEE Editor feature, the link AddNewTECDeviceDefinition displays in the Extended Items tab.
  4. Click the link.
  5. The Secondary Pane opens, displaying the FLN Device Editor.
  6. Edit any additional fields that you want or which are required for the device, and then click Save to create the FLN device.

Edit an FLN Device

  1. In System Browser, select Management View.
  2. In the System Browser tree, navigate to and select the FLN device whose data you want to edit.
  3. If the item is supported by the APOGEE Editor feature, the link Edit/DeleteTECDeviceDefinition displays in the Extended Items tab.
  4. Click the link. The Secondary Pane opens, displaying the FLN Device Editor.
  5. Edit any fields as appropriate.
  6. Click Save to save your changes.

Delete an FLN Device

  1. In System Browser, select Management View.
  2. In the System Browser tree, navigate to and select the FLN device you want to delete.
  3. If the item is supported by the APOGEE Editor feature, the link Edit/DeleteTECDeviceDefinition displays in the Extended Items tab.
  4. Click the link. The Secondary Pane opens, displaying the FLN Device Editor.
  5. Click Delete.
  6. A message box asks you to confirm the deletion.
  7. Click Yes to delete the FLN device, or, No to cancel the deletion.

Edit TEC Subpoints

  1. In System Browser, select Management View.
  2. In the System Browser tree, navigate to and select the TEC whose data you want to edit.
  3. If the item is supported by the APOGEE Editor feature, you will see the link Set/ReleaseTECInitialValues in the Extended Items tab.
  4. Click the link. The Secondary Pane opens, displaying the editor.
  5. Double-click on any row to edit its properties.
  6. Click Initialize TEC to load initial values into the TEC.
  7. Click Update Panel to save the current initial values of the TEC into the field panel.
  8. Click Refresh to refresh the values displayed in the editor.
