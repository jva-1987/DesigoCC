Manual Project Backup Compression from Main Server

You can compress Desigo CC project data directly from Main Server. This allows for quickly transferring the compressed project data backup to other computers networked.

  1. In System Browser, select Management View.
  2. Select Project > Management System > Servers > Main Server.
  3. The Operation/Extended Operation tab displays the Main Server properties.
  4. In the Backup Destination field, enter a valid path and click Apply.
  5. By default, Compression Type = Plain. This means that a plain file backup copy will be created at the backup location, but no compression will be used.
    • Next to the Compression Type property, select Compressed and click Apply.
  6. Next to the Backup Status property, click Start.
  1. After the activity is completed (Backup Status = Last Backup Successful), the compressed back up ZIP file is stored at the specified backup location.
