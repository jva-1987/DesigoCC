Comark Monitor Card

Scenario

You want to configure the Comark monitor card installed on the stations of your management platform. You need to configure a driver for each station equipped with the card.
For background information, see the reference section.

Prerequisites

  • The Comark extension module is installed and included in the active project.
  • System Manager is in Engineering mode.
  • System Browser is in Management View.
