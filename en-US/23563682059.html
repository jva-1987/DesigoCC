Create Area Summary Configuration

  1. Select Applications > Desigo CC > [area].
  2. Navigate to Summary tab.
    In the Summary expander, the Enable Configuration option is enabled by default starting from Powermanager V9.0. For the older versions, this configuration needs to be enabled manually.
  3. In the Measurement point section, enable the Calculate checkbox for the measurement points to start calculations, if it is not already enabled.
    NOTE: For the measurement points Total Active Power, Total Reactive Power, and Total Active Energy, the Calculate checkbox is enabled by default.
  4. Enable the Archive checkbox for the measurement points to archive the data.
    NOTE: For the measurement point Total Active Energy, the Archive checkbox is enabled by default.
  5. Enable the Alarm checkbox for the measurement points to activate alarms.
  6. Configure alarms in the Alarm Configuration expander.
  7. Select the check box under the Include column in the Include Devices section to monitor the respective device.
    All the devices created under the corresponding area, sectors, and sub sectors can be seen here. Logical devices are not supported for the Summary calculation.
  8. In the Power Interval Settings expander, select the interval from the Interval drop down list for which the power values are to be calculated.
    NOTE: The default Interval value is 1 minute.
  9. Click Save .

- Total energy calculations are performed only for 15-minute and 1-day intervals.

- For devices created in version V9.0 and later, are automatically included in energy and power calculations at the area summary node levels by default.

- If the device type is edited, the respective device instance will be automatically excluded from the area level summary configurations. The device must be manually added back to the summary calculations.

For background information, see Area Summary Configuration.
