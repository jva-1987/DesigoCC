Mobile Flex Homepage

After you start Desigo CC Flex mobile web app in the browser and sign in, your favorite homepage displays.

 

1

  • Tap to open the navigation menu.
    • For more details, see Mobile Flex Navigation Menu.

2

  • Tap Desigo CC logo to reload your mobile Flex favorite homepage screen.
    • To change your homepage, see Set Your Favorite Homepage in Mobile Flex.

3

  • Summary bar
    • See Use Summary Bar in Mobile Flex.

4

  • Tap to open the more options menu.
    • For more details, see Mobile Flex More Options Menu.

5

  • Tap to open the user account menu.
    • For more details, see Mobile Flex Account Menu.

6

  • Tap to access the applications available depending on selected object/event source.

7

  • Area of the screen where you can work with the different functionalities.
    • See Using Flex Web App on Mobile Devices.
