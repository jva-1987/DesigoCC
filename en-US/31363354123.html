Synchronize the measuring periods of devices in Powermanager

  1. Ensure PAC meter data and time is synchronized with Powermanager server (not required for PAC3200 device).
  2. Ensure Powerdemand Synchronization mode is set to synchronization via bus.
  3. System Manager is in Engineering mode.
  4. Select Application view > Powermanager > Modbus Configuration tab > Synchronization expander > Measuring Period expander.
  1. Navigate to Source section and click New.
  2. Select a Device and Measurement Point from the drop down list.
  4. Navigate to Devices to be Synchronized section and select the required device from the list.
  5. Check-in the Enable Synchronization check box.
  6. Click Save.
  7. Activate the digital input on the source device. Upon activation, synchronize the measurement periods of all selected devices with the PC date and time.
