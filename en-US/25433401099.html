Advanced Reports Execution and Parameter Information Workspace

1

System Browser objects

- Displays the list of objects in the selected view (Application View, Management View, Logical, Physical, and UserView).
- Web application rules are configured on the System Browser objects.

- When you select the System Browser object or its child object, on which web application rule is configured the Reports tab is displayed.
NOTE: If the web application rules are configured on the Reports System Browser object, then on the selection of this Reports System Browser object the Reports tab is displayed without web application rules.

-To view the Reports tab in Primary pane or in Secondary pane and generate the advanced report from these panes:
Select the System Browser object on which web application rule is configured, and then select  to the right of the selected object to open the contextual menu. Select either Send to primary or Send to secondary.

2

Reports drop-down list

Displays the web application rules configured on the System Browser object.
For example, select the [Load Profile Report] web application rule from the Reports drop-down list.

3

Generate

Generates the advanced report output in three formats:
- PDF format: PDF report along with timestamp is generated successfully and its preview is displayed in the preview area.
- Excel format: The Excel report document along with the timestamp is generated successfully but its preview is not displayed in the preview area. You can only select the corresponding row in the History area, and then in the preview area and download the advanced report locally.
- Both formats: The generated report is displayed in the preview area in PDF format. The history group entry can be expanded by showing two sub-entries, one for PDF and one for Excel.

4

Parameter information section

- After selecting one of the following formats: PDF, Excel, or Both, the corresponding parameter information section is displayed.
-The advanced report displays depending on the parameters set in the parameter information section.
- The individual parameters are displayed based on their value type and differ according to the selected web application rule in the Reports drop-down list.
For example, see the table below with the parameters and its description of [Load Profile Report].

5

Execute

After execution, by default, the advanced report is saved at the location: [Installation Drive C]:\[Installation Folder]\[Project Name]\ FlexReports and displays the data as per the specified parameter values.

Following are the parameters and the description for the [Load Profile Report] report displayed in the parameter information section:
All the parameters that are marked with (*) are mandatory. Without selecting or not entering these mandatory field values, the Execute button is not enabled.

#

Parameters

Description/Value

1

*Media Group

Specify the index value of the media group from the Media Group text group.

2

*Media

Specify the index value of the media from the Media text group.

3

*Time Range from Report Content

Specify the time range for the data to be displayed in the report by specifying the respective values in the Time range for Report Content drop-down list.

4

*Interval

Specify the aggregation interval for the report. The values specified for this field depend on the type of report to be executed through the web application rule.

5

From Date and To Date

Specify the date range for the report.

6

Display limits in Graph

Display limits in Graph can have either of the following values:
- Default
- Line: Displays the limit lines as horizontal lines on the graph.
- None
- Range: Displays the limit lines as a range on the graph.

7

Alternative Title to the default

Specify an alternative title for the advanced report.
For example, for a [Load Profile Report] report, if by default the title appears as [Load Profile Report] then you can specify an alternative title to this default.

8

Alternative Purpose to the default

Specify the alternative purpose for the advanced report.
For example, if by default for a [Load Profile Report] report the Purpose: appears as [This report displays the power of an interval for a period] then you can specify an alternative purpose to this default.

9

*Consumption From

Select the meter for which the consumption is to be calculated. You can select either of the following values:
- Main Meter (consumption field)
- Source Meter (raw consumption field)

10

High limit value For automatic limits select "Null Value

Specify the numeric value for high limit value to display the proper meter readings and graph in the report output.

11

Low limit value For automatic limits select "Null Value

Specify the numeric value for low limit value to display the proper meter readings and graph in the report output.

Similarly, you can create web application rules on any System Browser object or child object and view the Reports tab, parameter information section, and execute other Energy Reports, Pharma Reports, Power Reports, Trend Calculation reports, DMS reports, DI migration reports, and so on.
