SNMP Configuration Guidelines for Scalance Switches

In Desigo CC, the network switch monitoring is based on the Simple Network Management Protocol (SNMP) protocol.

To properly configure the switch monitoring function in Desigo CC, you need the following configuration elements.

  • SNMP Driver
  • We recommend using an SNMP driver on the closest Server or FEP station to the network switch. For instance, the Server station driver can monitor the local switch (networked on the server subnet) and the driver on the remote FEP station can monitor the remote switch connected over the redundant fiber link.
  • If no SNMP driver exists on the system you are configuring, just add a new one.
    NOTE 1: You can safely share the same SNMP driver up to its maximum load.
    NOTE 2: Make sure to start the SNMP Driver.
  • SNMP Network
  • Add or re-use an SNMP Network on all Server or FEP stations that need to monitor a Scalance switch.
  • Scalance device to the SNMP Network
  • For each switch unit to monitor, add a Scalance device to the SNMP Network. You can easily define the detailed object configuration by importing an XML file containing the required SNMP object. The XML data file is available in the Devices folder of your system files.
    In the System Management tab of the Scalance device, make sure that the Host name is set to the IP address of the device.

SNMP Driver

We recommend using an SNMP driver on the closest Server or FEP station to the network switch.
For instance, the Server station driver can monitor the local switch (networked on the server subnet), and the remote FEP driver can monitor the remote switch connected over the redundant fiber link.

You can use an SNMP driver already installed, if available, up to its maximum load. If no SNMP driver exists, add a new one.

NOTE: Make sure to start the SNMP Driver.

SNMP Network

Add or re-use an SNMP Network on all Server or FEP stations that need to monitor a Scalance switch.

Scalance Device to the SNMP Network

For each switch unit to monitor, add the SNMP Scalance device to the SNMP Network.

In the SNMP Scalance device, import the device configuration that corresponds to your model.

 

For detailed information on the SNMP configuration, see SNMP.
