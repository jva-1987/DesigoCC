Create a Remote Power Quality Database

Scenario

You want to create and link a remote Power Quality Database.
For background information, see the reference section.

Prerequisities

  • The root, host certificates used for securing the communication between Server and remote SQL Server are imported in the appropriate Windows Certificate store on Server station using SMC and set as default.
  • You have installed IEC61850 Power Devices, Powermanger IEC61850 Adaptor, and Powermanager PQ Advisor extension modules.
  • SQL Enterprise Edition Server, SQL Server Standard or SQL Server Express is installed and available.
  • A named instance is defined on the SQL Server.
  • The Windows user configured in the System Account and in the Power Quality Database Service Account must be valid and assigned all required rights. See Log on as a Service Right in System Settings Procedures.
  • The SQL Server Browser is set to automatic. See Enable the SQL Server Browser.
  • All required Windows system users are available.
