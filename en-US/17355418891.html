Working with APOGEE P2 Events

Do the following procedures as needed:

Create an Event

Once you have defined zones, you can create event definitions for the activities that will place the demands on the zones.

Creating an event definition includes defining the name and description of the event, after which you create an event schedule and specify the zones for the event.

NOTE:
To conserve memory, the system purges event schedules and replacement days that are 31 days or older.

  1. System Manager is in Engineering mode.
  1. In System Browser, select Application View.
  2. Select Applications > Schedules > APOGEE Events.
  3. The Event Editor displays in the Apogee EQS tab.
  4. Click Save .
  5. In the Save dialog box, enter a name and description.
  6. Click OK.
  7. The event is available under APOGEE Events.
    NOTE: Because the saved item is sent to the field panel which then communicates the save back to the system, there may be a delay from when you click OK and the item displays in System Browser.
  8. Create a schedule for the event.

Create an Event from an Existing Event

In order to save configuration time, you can use an existing event as the basis for creating a new one.

  1. System Manager is in Engineering mode.
  1. In System Browser, select Application View.
  2. Select Applications > Schedules > APOGEE Events > [event to be used as a basis].
  3. In the Apogee EQS tab, the Event Editor displays the selected event details.
  4. Click Save as .
  5. In the Save Object As dialog box, enter a name and description.
  6. Click OK.
  7. The new event is available under APOGEE Events.
  8. Make any adjustments to the new event as needed.
  9. Click Save .

Create an Event Schedule

 

NOTE:
To conserve memory, the system purges event schedules and replacement days that are 31 days or older.

  1. System Manager is in Engineering mode.
  1. In System Browser, select Application View.
  2. Select …
  3. From the Zone Editor or Event Editor, open the Schedules expander.
  4. Enter values into the fields in the Schedules expander.
  5. Click Save .
  6. After defining a zone or event schedule, you can do the following:
    • For zones:
      Define a Command Table
      Optimize a Zone
      Copy a Zone, Event, or Replacement Day Schedule
    • For events:
      Add Zones to an Event
      Copy a Zone, Event, or Replacement Day Schedule

Add Zones to an Event

You can drag and drop as many existing zones—which do not need to be on the same devices—as needed from System Browser to an event.

  1. System Manager is in Engineering mode.
  2. In the Apogee EQS tab, you have an existing event displayed in the Event Editor.
  1. In System Browser, select Application View.
  2. Select …
  3. In the Event Editor, open the Involved Zones expander.
  4. In System Browser, select Applications > Schedules > APOGEE Zones and drag and drop the zone over the Involved Zones expander.
  5. The zone information displays.
  6. From the Involved Zones expander, click the Mode drop-down arrow and select the mode to command the zone to during the event's scheduled period or by SSTO. Selections are associated with the state text table.
  7. Click Save .
  1. The event changes are saved.

Modify a Zone or Event

  1. System Manager is in Engineering mode.
  1. In System Browser, select Application View.
  2. Do one of the following:
    • To modify a zone: In System Browser, navigate to Applications > Schedules > APOGEE Zones > [zone you want to modify].
    • To modify an event: In System Browser, navigate to Applications > Schedules > APOGEE Events > [event you want to modify].
  3. The Apogee EQS tab displays.
  4. From the Zone Editor or Event Editor, make the necessary changes to the zone or event.
  5. Click Save .
  1. The changes are saved.

Delete a Zone from an Event

  1. System Manager is in Engineering mode.
  1. In System Browser, select Application View.
  2. Select Applications > Schedules > APOGEE Events > [the event from which you want to remove zones].
  3. In the Apogee EQS tab, the selected event details display.
  4. From the Event Editor, open the Involved Zones expander.
  5. From the Involved Zones expander, click the X associated with the zone entry that you want to remove from the event.
  6. The zone is removed from the event.
  7. Click Save .
  1. The changes are saved.

Copy a Zone, Event, or Replacement Day Schedule

Once you create zone, event, or replacement day schedules, you can copy them to reduce unnecessary repetition when you enter data. For example, copying is useful when a building has the same control requirements among floors.

NOTE:
When you copy a zone schedule over to another zone, any overrides the zone may have are not copied.

  1. System Manager is in Engineering mode.
  2. You have the zone or event to which you want to copy an item displaying in the Apogee EQS tab.
  1. In System Browser, select Application View.
  2. From the Zone Editor or Event Editor in the Apogee EQS tab, open the Schedules expander.
  3. Do one of the following to copy a schedule to the active item:
    • To copy a zone schedule: Navigate to Applications > Schedules > APOGEE Zones and drag-and-drop the zone over the Copy To field in the Schedules expander.
    • To copy an event schedule: Navigate to Applications > Schedules > APOGEE Events and drag-and-drop the event over the Copy To field in the Schedules expander.
    • To copy a replacement day schedule: Navigate to Applications > Schedules > APOGEE Replacement Days and drag-and-drop the replacement day over the Copy To field in the Schedules expander.
      NOTE: Day shift schedules cannot be copied.
  4. Click Copy.
  5. The schedule displays in the Timeline for the current item.
  6. Click Saved .
  1. The copied schedule is saved.

Delete a Zone or Event

  1. System Manager is in Engineering mode.
  1. In System Browser, select Application View.
  2. Do one of the following:
    • To delete a zone: Select Applications > Schedules > APOGEE Zones > [the zone you want to delete].
    • To delete an event: Select Applications > Schedules > APOGEE Events > [the event you want to delete].
  3. In the Apogee EQS tab, the Zone Editor or Event Editor displays the selected zone or event details.
  4. Click Delete .
  5. Click Yes.
  1. The zone or event is deleted.
