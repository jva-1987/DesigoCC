Adding the BACnet Driver to the Windows Firewall

NOTE: This step is optional if driver was previously add.

You must add the BACnet driver to your firewall. This allows a network device to initiate communication of alarms and COVs with a computer within your network's firewall.

  1. Select Control Panel > System and Security Panel > Windows Firewall.
  2. In the Control Panel Home pane on the left, click Allow a program or feature through Windows Firewall.
  3. The Allow programs to Communicate through Windows Firewall pane displays.
  4. Click Change settings.
  5. Click Yes when you are prompted to allow the Windows Firewall to make changes to this computer.
  6. Click Allow another program.
  7. The Add a Program dialog box displays.
  8. Click Browse.
  9. The Browse pane displays.
  10. Select [Installation Drive]: > [Installation Folder] > GMSMainProject > bin, > WCCOAGmsBACnet.exe, and then click Open.
  11. The pane closes and the GMS BACnet Driver is now listed in the Add a Program dialog box.
  12. From the Programs list, select GMS BACnet Driver and then click Add.
  13. The Add a Program dialog box closes, and the driver is now checked and listed in the Allowed programs and features list.
  14. Click OK and close out of Control Panel.
