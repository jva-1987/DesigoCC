Advanced Reporting Troubleshooting

This section provides solutions to the problems you are most likely to encounter when in Installed Client Advanced Reporting configuration settings are not configured properly. As a result, Flex Client is unable to execute the advanced report in Flex Client and the output is not generated at the default location [Installation Drive C]:\[Installation Folder]\[Project Name]\ FlexReports.

#

Problem/Error Message

Cause

Possible Solution

1

Invalid report settings

Check main url configuration

Main Url is not set.

Set the Main Url in Installed Client > Advanced Reporting> Extended Operation

2

Failed to reach reporting server

Check Apache Tomcat

Case1: Apache Tomcat Server service is stopped.

Case2: Incorrect Main Url is set.

Case 1: Go to Windows > Search bar, type Services, and restart the Apache Tomcat services.

Case 2: Set the correct Main Url in Installed Client > Advanced Reporting > Extended Operation.

3

Invalid report settings

Check report settings

In Installed Client, Configuration Page - Advanced Reporting, Template Synchronization setting not executed.

In Installed Client, check if the Template Synchronization setting is executed on Configuration Page - Advanced Reporting.

4

If the Media Group and Media values are not displayed in the parameter information section for Managed Meters.

Cache is not generated for Managed Meters.

Execute the Job Create Cache setting for the full period.
Before executing this setting, check if all the below settings are executed:
- Home Webservice is set.
- Template Synchronization
-Data Caching
- Caching Settings
- Layout Settings
- Additional Energy Report Settings (for Cost, Emissions, Budget and Performance) Energy Report Settings
- Energy Report Settings

For more information on all these configuration settings, see Installed Client Help of Advanced Reporting.
