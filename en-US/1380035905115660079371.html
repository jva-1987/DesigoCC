Alternate Method

The alternate method for configuring the field panel editors is to load or upgrade the User Interface using File Transfer Protocol (FTP). There are many FTP tools available that can be used for transferring files between your computer and the field panel.

NOTE:
Telnet must be enabled in order to use FTP. Once the upgrade is complete, you may disable Telnet on the field panel. For information on enabling Telnet, see the APOGEE BACnet ALN Field Panel User's Manual (125-3020).

To load or upgrade the APOGEE Field Panel Viewers and Editors’ files using FTP (alternate method; HMI method is recommended):

  1. Use FTP to copy the UIUpgrade folder and its contents from Standard Apps/Beacon, the Desigo CC installation disk, or your computer to the root of Drive A on the field panel.
  2. Do one of the following:
    • Use the HMI Uiupgrade function (System/Hardware/Ethernet/Webserver/Uiupgrade).
    • Use FTP to transfer the UIupgrade.txt file from Standard Apps/Beacon, the Desigo CC installation disk, or your computer to the root of the Drive A on the field panel.
  • The User Interface and support files will be installed from the field panel’s A:UIUpgrade folder to the field panel’s internal flash drive (IFD) and to the field panel’s Drive A.
  • Files stored in the IFD are preserved when a field panel restarts.
  • After the upgrade is complete, the field panel’s A:\UIupgrade folder is automatically removed.
