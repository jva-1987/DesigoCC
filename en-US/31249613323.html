Migrating NCC

Scenario

You want to import into Desigo CC all supported NCC icon symbols, graphic files, configuration files, and database files.

NOTE: This function is not available on Flex clients and Windows app clients (web-based stations).

For troubleshooting information, refer to Handling Problems with NCC Graphic Map Import

1 – Export NCC Graphic Maps from the CSGM Tool

  1. Run the MigrateToGms.bat batch file (provided with other scripts in a ZIP file named GmsMigrationFiles), which extracts the required data from the NCC database and creates the GmsMigrate directory with subfolders for all the extracted data.
  2. Generate XML files for MXL panels from the CSGM tool (by selecting the option Export Configuration to XML File) and add all the generated XML files to the PanelXmls subfolder inside the GmsMigrate folder.

Multiple Panels

If multiple panels are present in the configuration, make sure the NCC export package contains one database (.xml) file for each panel. If this is not the case, then you first need to manually duplicate and rename the XML file to match each panel. Proceed as follows:

  1. In the SqlExports folder, check the exact name of the imported panels in the NCC_nodes.csv file.
  2. In the PanelXmls folder, make multiple copies of the XML file, so that there is one for each of the imported panels.
  3. Rename each copy of the XML file to match the name of a target panel.

Example:

  • Name of the imported panels: MXL_1, MXL_2, MXL_3.
  • Name of the XML file (in the PanelXmls folder): project.xml.
  • Names to assign to the copies of the XML file (in the PanelXmls folder): MXL_1.xml, MXL_2.xml, MXL_3.xml.

NOTE: Copy the XML file as it is. During the import procedure, only the data required by each panel will be imported.

For detailed information about the export procedure from NCC, see Appendix L in FireFinder Network Command Center Graphics - Operation, Installation, and Maintenance Manual (P/N 315-049679-11).

 

2 – Import the NCC Graphic Maps XML into the Management Station

  1. The NCC Conversion Tools extension module is installed in the project.
  2. System Manager is in Engineering mode.
  3. The fire system panels are imported.
  4. The XML export files from NCC are available locally or over the network.
  5. To speed configuration, make sure the Desigo CC Transaction Mode is set to Simple or the Automatic Switch of Transaction Mode is set to True.
    The automatic switch setting is recommended. Without it, to re-enable the logs, you need to set the Transaction Mode to Logging at the end of the configuration procedure.
  1. In System Browser, select Management View.
  2. Select System Settings > Conversion Tools > NCC Graphics Importer.
  3. Click the NCC Graphics Importer tab.
  4. Click Import and select the folder containing the NCC exported files.
  5. The available graphic maps are listed.
  6. (Optional) Deselect the graphic maps not to import.
  7. In the Select symbols style drop-down list, select a graphic style to apply to the symbols (for example, you can choose various 2D and 3D styles).
  8. Click Save .
  9. At the end of the import procedure, a message displays the results of the import and provides access to a detail log.
  10. The imported graphic maps are available in Applications > Graphics in Application View.

NOTE 1: In case of a distributed multi-servers system, the import can only create new objects (graphics) on the local system.

NOTE 2: It is possible to delete and create again the NCC Graphics Importer node in System Browser.
