Configure the Retention Period for the PowerQuality Data

You can configure the retention periods for various categories of PowerQuality data.

  1. You have added IEC 61850 and PowerQuality extension modules to your project.
  2. The PowerQuality database is created and linked to the project.
  3. System manager is in Engineering mode.
  4. In System Browser, Management View is selected.
  1. Select Project > Management System > Servers > Power Quality Database > Retention Period.
  2. The Extended Operation tab displays.
  3. Click Enable on the any of PowerQuality data categories to define the retention period.

  4. By default, the retention period is enabled when V9.0 or later is installed. When upgrading from older versions to V9.0 or the latest version, the retention period for PowerQuality data must be enabled if you want to retain the data with configured values from the older version or the default values
    During an upgrade, the retention period synchronization starts after 5 minutes.

  5. (Optional) Enter the retention period values in the field and click Set.
  1. The retention period is defined for the PowerQuality data.
