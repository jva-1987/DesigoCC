System Browser

This section provides step-by-step instructions for System Browser. For background information, see the reference section.

Select Views

  1.  is not selected.
  • From the Views list box, select the view you want to display.
  1. The selected view displays.

Using Multi-Select

  1.  is not selected.
  1. In System Browser, select the desired view.
  2. Do one of the following:
    • To select a number of non-adjacent objects:
      a. Select the first object.
      b. Press CTRL.
      c. Select all other desired objects.
      d. Release CTRL.
    • To select a range of adjacent objects:
      a. Select the beginning of the range of objects.
      b. Press SHIFT.
      c. Select the end of the range of objects.
      d. Release SHIFT.
  1. The objects display.

Filter

Prerequisite:  is selected, and you want to filter by one or more of the following categories:

by Preset filters

  1. In the Preset filters box, select a Recent filter or a Saved filter.
  2. Select OK.

by Discipline

  1. In the Discipline box, select the arrow.
  2. Do one of the following:
    • Select the disciplines or sub-disciplines you want to filter by.
    • In the Search box, enter the disciplines you want to filter by.
  3. Select OK.
  4. Select the objects you want to display.

by Type

  1. In the Type box, select the arrow.
  2. Do one of the following:
    • Select the types or sub-types you want to filter by.
    • In the Search box, enter the type you want to filter by.
  3. Select OK.
  4. Select the objects you want to display.

by State

  1. In the State box, select the arrow.
  2. Select the state or sub-state you want to filter by.
  3. Select OK.
  4. Select the objects you want to display.

by Wildcarded String

  1. In the Search box, enter the wildcarded string.
  2. Select a search scope—Description, Name, or Alias.
  3. Select OK.

by Search within

  • To limit your search within the current selection, select the Search within check box.

Clearing Filters

  1. You want to clear an individual filter or all filters.
  • Do one of the following:
    • To remove an individual filter, select .
    • To remove all filters, select in the upper-right corner.

Display Object Properties

  1.  is not selected.
  • In System Browser, select the desired object.
  1. Property Viewer displays the object properties.

Send Objects to a Specific Pane

  1.  is not selected.
  • In System Browser, do one of the following:
    • Select the desired objects to view in the Primary pane.
    • Select the desired objects, and then select  to the right of any selected object to open the contextual menu. Select either Send to Primary or Send to Secondary.
  1. The selected objects are sent to the specified pane.

Copy an Object Name, Description, Alias, or Designation

You can copy an object name, description, alias, or designation in one of the following ways:

 

From More Options Menu

  1. Next to any object in System Browser, select , then select Copy, and then select the attribute you want to copy.
  2. Paste the selected attribute.

 

From Contextual Menu

  1. Right-click any object in System Browser.
    NOTE: Multi-selected objects are not supported.
  2. From the Contextual menu, select Copy, and then select the attribute you want to copy.
  3. Paste the selected attribute.

 

From Properties

  1. Select any object in System Browser.
  2. In Properties, select .
  3. In the popup that displays, select  and then select the attribute you want to copy.
  4. Paste the selected attribute.
