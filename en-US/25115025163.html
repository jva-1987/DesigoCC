Advanced Reporting

This section provides step-by-step instructions for the advanced reporting tasks in the Flex Client.
For background information, see the reference section.

In Flex Client, the Advanced Reporting application helps to generate advanced reports, such as Energy Reports, Pharma Reports, Power Reports, Trend Calculation reports, DMS reports, DI migration reports. The availability of any advanced reports for execution depends on the following configurations done in the Installed Client:

  • Advanced Reporting extension with all its configurations working including Main Url, Web Services URL, synchronization, execution of all configuration page settings and job create cache.
    For more information, see Installing and Configuring Advanced Reporting in Advanced Reporting.
  • Web application rules are configured to execute Energy Reports, Pharma Reports, Power Reports, and so on.
    For more information, see Configure Web Applications Rules for Nodes in Energy Reporting > Additional Energy Reporting Procedures.
  • Show and Configure rights configured to view the Reports application in the Flex Client.
    For more information, see Application Rights in User and User Group Administration > User Administration.
