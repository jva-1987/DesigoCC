Additional Management Station Scheduler Procedures

This section provides step-by-step instructions for the Management station scheduler tasks in the Flex Client. For background information, see the reference section.

Edit Management Station Scheduler Exceptions

  1. In System Browser, select Schedules.
  2. Select Management Station Schedules.
  3. Select the Management station scheduler whose exception you want to edit.
  4. Click Edit.
  5. Click Exceptions.
  6. Switch to the List view.
  7. Select the exception entry to be edited.
    For example, to convert an exception entry of type Date to Date range, select the date on which the entry is configured, click Range, and then select the end date for the date range. Select OK.
  8. Modify the required parameters.
    You can edit exception entries from the List view as well as the Calendar view.
  9. Select OK.

 

Delete Management Station Schedule Exceptions

  1. In System Browser, select Schedules.
  2. Select Management Station Schedules.
  3. Select the Management station scheduler whose exception you want to delete.
  4. Click Edit.
  5. Click Exceptions and then List view.
  6. Select the exception entry from the list and click Delete.
  1. The exception entry is deleted.

 

Delete Management Station Schedule Scenes

  1. In Application View, select Applications > Schedules > Management Station Schedules
  2. Select the Management station scheduler whose scene you want to delete.
  3. The selected scheduler displays in the Schedule tab.
  4. In the Scenes tab, select the scene to be deleted.
  5. Click  adjacent to the Name text box and select Delete scene from the menu options.
  1. The scene is deleted.

 

Create Scene Recurrence

Perform the below steps to add Recurrence time for Management Station Schedule.

  1. In the System Browser, select the Schedules > Management Station Schedules.
  2. The Schedule tab displays.
  3. Click Scenes tab and select a scene to which you want to add a recurrence time.
  4. Click  next to the Name field and select Recurrence.
  5. In the Recurrence dialog-box, do the following:
    • Select Active from the Enabled drop-down list.
    • Click the Time field and set the scene recurrence time in hours or minutes using button.
    • Click  to save the recurrence time.
  6. Click Save.
  7. The scene recurrence is created.

Copy Management Station Schedule Entries

  1. In Application View, select, Applications > Schedules > Management Station Schedules.
  2. Select the Management station scheduler whose entries you want to copy.
  3. Click Edit.
  4. The scheduler displays in the Edit mode.
  5. Click Copy.
  6. Select the day whose scheduler entry you want to copy and click Next.
  7. Select the days on which you want to repeat the scheduler entry. Click Paste.
  1. The scheduler entries are copied to the selected days.

 

Copy Management Station Schedule Exception Entries

  1. In Application View, select, Applications > Schedules > Management Station Schedules.
  2. Select the Management station scheduler whose exception entries you want to copy.
  3. Click Edit.
  4. Click Exceptions.
  5. Select the exception scheduler entry whose details you want to copy.
  6. Click Copy.
  7. Select the days on which you want to repeat the exception scheduler entry.
  8. Click Paste.
  1. The scheduler exception entries are copied to the respective days.

 

Delete Management Station Scheduler

  1. Select Applications > Schedules > Management Station Schedules > [Management Station Schedule].
  2. Select the scheduler that you want to delete.
  3. The details of the selected scheduler display in the Schedule tab.
  4. In the Scenes tab, click  next to Save and select Delete scheduler from the menu options.
  1. The scheduler is deleted.

 

Edit Existing Management Station Calendar Entries

  1. In System Browser, select Schedules.
  2. Select Management Station Calendars.
  3. Select the Management station calendar that you want to edit.
  4. The calendar displays in the Calendar view along with the configured entries. All the calendar entries configured for the selected Management station calendar also display in the List view.
  5. Perform either of the following steps:
    • To modify an existing calendar entry, select the entry in the Calendar view. The details of the entry display on the right side. Specify the new date value and click Save.
    • To add a new entry, click Add. In the <new calendar entry> dialog box, select the type of calendar entry to be added, such as Date, Date range, Weekday, Recurring. Depending on the type of calendar entry selected, the corresponding fields display in the <new calendar entry> section. Specify the required values and click Save.
    • You can also modify a calendar entry from the List view by selecting the entry and modifying the date.
  1. The calendar is saved with the updated entry.

NOTE: To delete an existing calendar entry select the entry and click Delete.

 

Delete a Management Station Calendar and Its Entries

  1. In System Browser, select Schedules.
  2. Select Management Station Calendars.
  3. Select the Management station calendar that you want to delete.
  4. The calendar displays in the Calendar view along with the configured entries.
  5. To delete the Management station calendar object, click  and select Delete calendar from the displayed options.
  6. The Management station calendar and its entries are deleted.
  7. To delete individual calendar entries, navigate to the List view and select the entry to be deleted and click Delete.
  1. The selected Management station calendar entry is deleted.
