Create a Gauge Chart

You can create the Gauge chart that displays the live value from the device for the selected source. For background information, see Gauge Chart Workspace.

  1. In the dashboard, select the Gauge chart from Create widget list.
  2. Click Next.
  3. The Create widget page opens.
  4. Click Add to select the data point.
  5. Select the device from the list and click Select.
  6. Select the Data point from the drop-down.
  7. The Gauge chart displays the live value from the device for the selected source. You can add only one data point per gauge; add a separate gauge for each additional data point.
    The Minimum and Maximum values with unit displays in the gauge for the supported data points.
  9. Click Create to add the widget to the dashboard.
  10. Click Save.
  1. The Gauge chart is created in the dashboard.

Create a Threshold Range

You can create threshold range for the values with different color code.

  1. The Gauge chart is created.
  2. In the Scale tab, the Auto scaling is disabled.
  1. In the gauge chart, select the Settings tab.
  2. Select the first threshold range description from the drop-down.
  3. Click icon.
  4. The range selector for the first threshold displays.
  5. Enter the first threshold range value.
  6. Select the second threshold range description from the drop-down.
  7. Click icon to add the next range selector field.
  8. Enter the second threshold range value.
  9. Select the third threshold range description from the drop-down.
  10. If you want to delete the threshold range, click .
  11. Click Save.
  1. The Gauge chart with threshold range displays.
