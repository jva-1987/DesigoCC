Retention Period for the Power Quality Data

The PowerQuality data stored in the database can be managed with a retention period. When the database is 90% full, any data beyond the retention period will be automatically deleted. You can set different retention periods for five types of PowerQuality data, each with its own retention period.

Enabling the retention period stores the data in the database for the defined period and deletes older data providing better control over the data stored in the database. Disabling the retention period keeps all data, which tends to fill the database storage.

When upgrading to a newer version, retention period configurations are disabled by default to prevent unintended data deletion. Critical warnings and alarms are set for database capacity, with a write block implemented when the database reaches capacity.

In the Extended Operation tab, the Retention Period section contains the Retention Span, Retention Unit and Retention to manage the retention period for the PowerQuality data.



- [Data Category] Retention Span: Specify the retention period for the PowerQuality data.
- [Data Category] Retention Unit: Specify the unit for the retention period in days and years.
- [Data Category] Retention: Enable or Disable the retention period for the PowerQuality data.

Following PowerQuality Data categories are available:

  • PQ Analysis
  • Fault File
  • IEEE 519 Report
  • PQDIF File
  • PQ Trends
