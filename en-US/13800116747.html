Searching and Replacing a File Path Property

  1. The Insight Graphics application is open.
  1. From the Tools menu, select Search/Replace UNC File Path Properties.
  2. The Search/Replace File Path Property dialog box displays.
  3. Complete the fields in the Search/Replace File Path Property dialog box.
    • Old Computer Name - UNC (Universal Naming Convention) name in the file path property of your Picture, Advanced Link, and Animation controls that you want to change or replace. Do not include a trailing backslash ("computername\") when typing the computer name; however, you can set up this field so that it references a specific directory or share. The following are acceptable formats: computername, \\computername\directory1\directory2, or \\computername
    • New Computer Name - Name that replaces the old computer name in the file path property of your Picture, Advanced Link, and Animation controls. As with the Old Computer Name field, do not include a trailing backslash ("computername\") when typing the computer name. The Old Computer Name format requirements also apply to the New Computer Name.
    • Skip Templated Graphics - Select this option if you don't want to perform a Search and Replace on file templates. This speeds the operation since graphic templates typically don't contain animations, advance links, or picture controls.
    • Case Sensitive - Distinguishes between uppercase and lowercase characters. Select this option to search for those instances in which the capitalization matches the text you typed.
  4. Click OK.
