Data Point Card Workspace

The Data point card displays the live value from the device for the selected source using a card. This widget supports only the numerical, boolean, enumerated, date, and time format values from the selected source.

1

Displays the isometric image of the added device.

2

Displays the name of the widget.

3

Displays the value for the selected data point.
If the device stops communicating to the Powermanager, then it is indicated with the RED colored icon as shown in the below image.

This is applicable only to the physical devices.

4

Settings

Contains the Widget name, and an options to enable/disable and change the orientation of the device image.

- Widget name: Displays the widget name. You can change the name if required.

- Enable image: Enabled by default, it displays the Source URL and Direction for the image if it is enabled. Disable the toggle to hide the image.

- Source URL: Displays the source URL location of the stored image.

- Direction: Allows you to change the orientation of the data point card.

Horizontal: Displays the data point card with the image in the horizontal direction, which is the default view.

Vertical: Displays the data point card with the image in the vertical direction as shown below:

5

Source

Contains common elements Data point, Delete, Edit, and Add like all the widgets.

6

Displays the device type added as a source for the widget.
