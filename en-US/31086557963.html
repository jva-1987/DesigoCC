Setting SNMPv3 Protocol

The SNMPv3 messaging protocol allows to fully encrypt transmissions, thus ensuring a secure data exchange through user authentication and message encryption.

For an SNMP network, the following configuration must exactly match the devices credentials.

 

  1. System Manager is in Engineering mode.
  2. System Browser is in Management View.
  3. The SNMP network is selected under Project > Field Networks.
  4. In the System Management tab, the General Settings expander is open.
  5. You already obtained the device credentials.
  1. In Common settings, next to Protocol version, select v3.
  2. In SNMP v3 Settings, you can now set strong authentication and data encryption.
  3. Specify the SNMP context parameters:
    a. In the Security name field, enter the exact security name set for the device.
    This setting is required and must be unique for each SNMP manager. It indicates the user or program that requires access to the device data.
    b. (Optional) In the Context name field, enter the exact name set for the device that unambiguously identifies a context.
    A context can be the name of a domain or of a specific instance of a managed entity on a device. This setting is required.
    c. (Optional) In the Context engine ID field, enter the exact value set for the device for the entity hosting the management information.
    It is the unique identifier of the SNMP context. If available, you can enter this setting for a better access to device data.
  4. Specify the security level for the data exchange (communication with the device) in one of the following ways:
    • To set the security level with no authentication and no encryption:
      - From the Security level drop down list, select No authentication and no encryption.
    • To set the security level with authentication only:
      a. From the Security level drop down list, select Authentication only.
      b.       From the Authentication protocol drop down list, select the exact message authentication code set for the device.
      c. In the Authentication key field, enter exact encrypted code set for the device to validate the user’s identity.
    • To set the security level with authentication and encryption:
      a. From the Security level drop down list, select Authentication and encryption.
      b.       From the Authentication protocol drop down list, select the exact message authentication code set for the device.
      c. In the Authentication key field, enter exact encrypted code set for the device to validate the user’s identity.
      d. From the Encryption protocol drop down list, select the exact encryption standard set for the device.
      e. In the Encryption key field, enter the exact encrypted code set for the device to encrypt messages.
  5. Click Save .
  1. Note that the save operation might be longer the first time V3 network configuration is saved.
