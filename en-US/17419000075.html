Fire WAN

This section provides some reference information about the configuration of the Wide Area Network (WAN), which can provide a connection to multiple XNETs. The WAN communication is based on HUB-4 interfaces, installed in tamper-protected enclosures with AC and battery power supply. Each HUB-4 interface can connect four XNET lines (RS-485 or modem) for Desigo Fire Safety Modular, Cerberus Pro Modular, FireFinder XLS, and MXL fire control panels, as well as NCC stations.

For a step-by-step guide to the WAN network configuration, see the workflow in Configuring a Fire WAN.
