Configure the Fire WAN Enclosure

  1. Select Project > Field Networks > [Fire WAN network].
  2. In the Object Configurator tab, click New .
  3. In the New object dialog box, enter a name and description for the new enclosure.
  4. Click OK.
  5. The newly created enclosure is automatically selected in System Browser.
  6. In the FireWAN tab, select the Enclosure Settings expander.
    NOTE: Fields with missing or invalid values are marked with a red border.
  7. In NIC-C, configure the following communication parameters:
    • Address: Select the HNET address of the NIC-C.
    • Network wiring type: Select Class B or Class X.
    • Custom message: Enter the description text of the NIC-C card.
  8. In PSC-12, configure the following power supply parameters:
    • Used: Select the check box to configure the PSC-12 power supply, or deselect it and ignore this section if the Enclosure is powered by an external supply.
    • Address: Select the HNET address of the power supply unit.
    • Tamper: If required, select the check box to enable the tamper detection.
    • Battery size (Ah): Select the battery capacity.
    • Custom message: Enter the description text of the PSC-12 unit.
    • (Optional) Relays: Configure the relay outputs in use. For relay address 1:
      - Select the Used check box.
      - Select the Usage: General output or Global alarm (Desigo CC event).
      - Enter the Custom message.
      - Repeat the steps for relays 2 to 4 as necessary.
  9. (Optional) In PSX-12, configure the additional power supply parameter:
    • Count: Select the number of additional power supply units (0, 1 or 2).
      Depending on the selection, a corresponding number of fields displays. Configure the following:
    • Address: Select the HNET address of the PSX-12 unit #1.
    • Custom message: Enter the description text of the PSX-12 unit #1.
    • Address: Select the HNET address of the PSX-12 unit #2.
    • Custom message: Enter the description text of the PSX-12 unit #2
  10. Click Save .
  11. The new enclosure objects are created in System Browser.
  12. Repeat the steps as necessary for more enclosures under the [Fire WAN network].

For background information about the enclosure configuration parameters, see the reference section.
