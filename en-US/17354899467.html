Importing the APOGEE P2 Database

There are two ways to get APOGEE P2 data into the management platform—you can import it, or you can discover it. It is recommended that you use the import method since it is faster and will preserve standard alarm priorities. Once the integration data has been imported, you can use the discovery method to maintain the system.

Import the APOGEE Database

  1. Before importing APOGEE database files, make sure they are available locally or by browsing. Also, be sure you have created a new APOGEE network for each BLN in the APOGEE Automation System.
  1. In System Browser, select Project > Field Networks.
  2. Select the network to which you will import the database.
  3. In the Primary pane, click the APOGEE Import tab.
  4. Click the Browse button.
  5. In the Select folder to import dialog box, select the parent directory you created to store the database file.
  6. Click OK.
  7. The Select panels for the BLN section displays a list of panels available for import.
  8. Click Move all items .
  9. The panels associated with this BLN display in the Items to import section.
  10. Click Import, then click Yes.
  11. The import procedure starts. When complete, the Import dialog box displays.
  12. If you want to view details of the import, click Open Log. Otherwise, click OK.
  1. APOGEE devices are now available in System Browser.

Discover All APOGEE Panels in a Network

  1. The system is in Engineering mode.
  2. The integration data has been imported, and you want to use the Discovery feature to maintain the system.
  1. In System Browser, select Management View.
  2. Select Project > Field Networks > [name of network].
  3. Click the Operation tab.
  4. For the Connection Status property, click Add Device .
  5. In the Name field, enter the name of one of the panels in the APOGEE Ethernet network.
  6. Click Send .
  7. In the Operation tab, locate the Network State property, and then click Discover .
  1. The system discovers all field panels on the network and displays them in System Browser.

Discover Objects and Points at Each APOGEE Panel

  1. The integration data has been imported, and you want to use the Discovery feature to maintain the system.
  1. In System Browser, select Management View.
  2. Select Project > Field Networks > [name of network] > [name of field panel].
  3. In the Operation tab, locate the Status property, and then click Discover .
  1. The system discovers all points and objects available in the field panel database and displays them in System Browser.
