Set Your Favorite Flex Client Homepage

You can set the Flex Client homepage that displays when you log on or to which you want to go back.
Furthermore, whenever you select the company logo in the horizontal navigation bar of the web/desktop app, the screen will refresh and your favorite Flex Client homepage is reloaded.

  1. In the horizontal navigation bar, select your initials, and then select Account.
  2. The account page displays.
  3. Select Edit.
  4. The settings are available for editing.
  6. Select the Start node field.
  7. The Browse dialog box displays.
  8. From the views drop-down list, select the appropriate view.
  9. Select the node that will correspond to your favorite homepage.
    NOTE: Alternatively, you can select  and search for objects in the System tree.
  10. Confirm your choice with Select.
  11. The Browse dialog box closes.
  12. Confirm changes with Save.
  1. In the account page, Start view and Startup node information updates accordingly. These settings will persist across user sessions.
