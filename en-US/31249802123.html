Checking Bandwidth Limits for UL/ULC Application

Scenario

Before deploying UL/ULC-compliant systems for normal use, the maximum network bandwidth of the system network must be measured, verified and recorded not to exceed the following limits of maximum total network bandwidth:

  • 50 Mbps, of which 5 Mbps for Life Safety
    NOTE: All non-Life Safety applications shall be running at maximum network traffic condition (i.e., maximum IP cameras configured for maximum bandwidth usage specified in configuration) during the aforementioned measurements.

If the limits are reached, you need to reduce the bandwidth (e.g., by reducing the resolution of cameras or by reducing the network size) to meet the required maximum limit. To measure and ascertain the maximum network bandwidth of a system, a packet analysis tool such as Wireshark or similar application must be used. Wireshark (V2.2.6 or higher) is an open source packet analysis tool that it is released under the terms of the GNU General Public License. It is used for network troubleshooting and analysis of traffic. To properly use this tool, the WinPcap (V4.1.3) application, Windows Packet Capture library, is also needed.

1 – Install Wireshark

Scenario: You want to install the Wireshark tool to measure the network bandwidth occupation.

  1. Download the Wireshark tool from: https://www.wireshark.org/download.html. Select the latest stable Windows 64-bit release.
  2. After the download, start Wireshark-win64-X.Y.Z.exe, with X.Y.Z being the latest stable Wireshark release.
  3. A User Account Control message may display, if your UAC settings are set to Default or Always Notify, asking you if you want to allow this installation program to make changes to the computer. Click Yes.
  4. A standard Install Shield dialog box displays. Click Next.
  5. The license agreement displays. Click I Agree.
  6. The Choose components dialog box displays. Leave the default options checked and click Next.
  7. The Select Additional Tasks dialog box displays. Leave the default options checked and click Next.
  8. The Select Install Location dialog box displays. Once completed, select Next.
  9. In the Install WinPcap dialog box, select Install to install/update the WinPcap application to the latest version, then click Next.
  10. In the Install USBPcap dialog box, leave the Install check box unchecked, as this library is not required for the purpose of measuring the network bandwidth (you can, however, install USBPcap for other purposes).
  11. Click Install.
  12. The Installer dialog box shows the progress of the install.
  13. The WinPcap License Agreement dialog box displays. Select I Agree to accept the license.
  14. The installer asks if you want to automatically start the WinPcap driver at boot time. Leave the check box checked and select Install.
  15. Once completed, select Finish and reboot the PC.

3 – Determine Maximum Network Bandwidth with Wireshark

Scenario: Using the Wireshark tool, you want to measure the network bandwidth occupation of your Desigo CC.

  1. Start Wireshark, and select the network you want to analyze.
  2. Allow Wireshark to run for at least 15 minutes.
  3. Make sure all non-Life Safety applications are running at maximum network traffic condition (i.e., maximum IP cameras configured for maximum bandwidth usage specified in configuration).
  4. Initiate events on several of the panels in the network, using the management station to acknowledge, silence and reset the panels.
  5. From the Statistics > Capture File Properties dialog box, take the Average bytes/s. In our example (see image below) this is 298.
  6. From the Statistics > Packet Lengths dialog box, select the Max val value from the largest row. In our example, the largest row is the 640-1279 row with an average value of 773.
  7. From the IO Graphs dialog box, select the peak value for Packets/1 sec. In our example, this is 15.5.
  8. Multiply these numbers: (298 * 773 * 15.5) = 3570487 Bytes / sec.
  9. Divide this answer by 1024: (3570487 / 1024) = 3486.8 KB / sec.
  10. Divide again by 1024: (3486.8 * 1024) = 3.41 MB / sec.
  11. Check the result against the maximum bandwidth allowed in UL/ULC application.
