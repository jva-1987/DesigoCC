Troubleshooting of Reports

This section provides solutions to the problems you are most likely to encounter when in the standard client, report configuration settings are not configured properly. As a result, Flex Client is unable to execute the report in Flex Client and the output is not generated at the default location [Installation Drive C]:\[Installation Folder]\[Project Name]\ [FlexReports].

#

Problem/Error Message

Cause

Possible Solution

1

Invalid report settings

Check main URL configuration

Main Url is not set.

Set the Main URL in Standard Client > Application View > Engineering mode > Powermanager node > Advanced Reporting > Extended Operation tab > Main Url.

2

Failed to reach reporting server

Check Apache Tomcat

Case1: Apache Tomcat Server service is stopped.

Case2: Incorrect Main Url is set.

Case 1: Go to Windows > Search bar, type Services, and restart the Apache Tomcat services.

Case 2: Set the correct Main URL in Standard Client > Application View > Engineering mode > Powermanager node > Advanced Reporting > Extended Operation tab > Main Url.

3

Invalid report settings

Check report settings

In Standard Client, Configuration Page - Advanced Reporting, Template Synchronization setting not executed.

In Standard Client, check if the Template Synchronization setting is executed on Configuration Page - Advanced Reporting.

For more information on all these configuration settings, see Standard Client Help of Advanced Reporting.
