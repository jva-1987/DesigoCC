Removing Mass Notification Categories from Events Rights

You want to prevent fire operators from seeing or treating mass notification events.

See also Removing Mass Notification Control from Fire Operators Rights.

  1. System Manager is in Engineering mode.
  1. In System Browser, select Management View.
  2. Select Project > System Settings > Security.
  3. The Security tab displays.
  4. In the Groups list, select the appropriate user group. For example, Operators.
  5. In the Event Rights expander, restrict the scope by setting event rights appropriately:
    • To disable the events completely, clear the MNS1, MNS2, and MNST check boxes.
    • To restrict event control more specifically, expand the desired category and clear the check boxes for the commands to disable:
      - Acknowledge
      - Reset
      - Silence/Unsilence
      - Close
  6. Click Save .
