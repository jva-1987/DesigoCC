About Database Backup and Restore for Field Panel Editors

Select a topic to continue:

APOGEE Field Panels Revision 3.2.4

The information in this section applies to APOGEE Field Panels Revision 3.2.4 that are on a network with Desigo CC and with or without Insight software

When Insight software is available, it should be set as the field panel’s Main Backup Disk using CT. The field panel’s dbFile setting can be AutoRestore/AutoSave Enabled as an additional optional backup/restore source. The Desigo CC Backup/Restore feature can be Enabled as an additional optional backup/restore source.

When Insight software is not available, the field panel’s dbFile setting should be AutoRestore/AutoSave Enabled. The Desigo CC Backup/Restore feature can be Enabled as an additional optional backup/restore source.

APOGEE Field Panels at Revisions Earlier than 3.2.4

The information in this section applies to APOGEE field panels at revisions earlier than 3.2.4 and on a network with Desigo CC.

You are discouraged from using APOGEE field panels at revisions earlier than 3.2.4 because the Database Restore features for native BACnet services are deficient. Use these revisions only if the APOGEE field panels cannot be upgraded to Revision 3.2.4.

If Integration Drivers are required, it is recommended that you do not use Integration Drivers with rev string xxD 2.0 or later.

Network with Insight Software

When Insight software is available with Desigo CC, it must be set as the field panel’s Main Backup Disk using CT. The field panel’s dbFile setting can be AutoRestore/AutoSave Enabled, as an additional optional backup/restore source.

The Desigo CC Backup/Restore feature, which uses native BACnet services, should be Disabled.

Network without Insight Software

When Insight software is not available with Desigo CC, the panel’s dbFile setting must be AutoRestore/AutoSave Disabled.

The Desigo CC Backup/Restore feature, which uses native BACnet services, must be Enabled.
