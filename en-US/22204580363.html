APOGEE Attribute Duplicator

For background information, see the reference section.

Complete the following procedures as needed:

Copy Point Attributes

  1. In System Browser, select an Apogee point whose attributes (properties) you want to copy.
  2. Select the Apogee Attribute Duplicator tab.
  3. From System Browser, drag points to the Destination Points expander for points you want to copy the properties to.
  4. In the Source Point Attributes expander, select the properties you want to copy.
  5. Click Copy .
    The properties are copied, and the Copy Summary dialog box displays.
    NOTE: Not all points have the same properties. Consequently, some properties cannot be copied to the destination point(s). In that case, the log displays a “copy not possible” message for each affected property.
  6. (Optional) To view the Attribute Duplicator Copy Log, click Open Log.
