Data Migration

This section provides step-by-step information about the Data Migration extension module. For more information on data migration, see the section.

Prerequisites

You are upgrading a legacy PXC (first or second generation) on your network to a recent PXC variant (PXC4/5/7). As part of that migration, you need to migrate points, trends, and other application data from your old PXC device (“device instance”) to your new device. Once you have an export file in the correct format from ABT, use this guide to migrate points and data from old to new.

Data eligible for migration includes:

  • Configuration instance information (for example, todo texts and management station alarms)
  • Management station schedules and calendars
  • Reports (standard, advanced reporting, Power BI, Trend calculations)
  • Trends (data and views)
  • Operator tasks
  • Reactions and macros
  • Logs (data and views)
  • Managed Meter
  • Graphics

Prerequisites

  • You are logged in to Desigo CC with a user that has access to all objects on the PXC device that you want to migrate. Validation is disabled for all objects that will be migrated.
  • You have a migration file for the source (the legacy device you will migrate from) and target device (the device you will migrate to). This device is a .csv file that is generated within ABT DMU Tool (Desigo Modenization Utility) . It contains object and point mappings IDs that allow Desigo to identify the equivalent on your new device.
  • You have the application rights within your user group to perform a migration
