FS92 Fire Network Operating Troubleshooting

This section contains troubleshooting information for FS92 Cerberus Pro fire control panels.

Handle Event Problems in Operating Mode

Problem

Situation

Do the following...

Cannot silence events from Cerberus DMS stations. In the Event List, the silence command icon is missing.
You cannot silence events from the panel PMI either.

The silence inhibit has been configured on the panel and is currently active. The silence command is only allowed after a predefined delay.

  • Wait for the delay configured in the fire panel tool.

All control commands have no effects.

Network connection is down: all object properties show #COM state and object symbols in graphics display a yellow grid.

  • Get the network connection re-established.

Cannot erase the Client UI Missing event.

The Client UI Supervision trouble does not automatically disappear due to incompatibility between Cerberus DMS and FS20 panels with firmware 3.0 and 3.1

  • Disconnect the management station so that the Client UI Missing event is replaced by Connection Trouble.
  • Reconnect the management station.
