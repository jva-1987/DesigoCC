Work on a Kiosk Flex Station

If you are working on the closed mode station, you will find the Flex desktop app already launched.

  • The Flex desktop app starts up automatically with Windows, and cannot be minimized, resized, or closed. You also cannot access any other applications.
  • The key combination CTRL+ALT+DEL, F5 and F11 are the only keyboard keys allowed.
  • If you try to download Desigo CC files (for example, a report, a document, and so on), a message informs you that the operation has been cancelled due to restrictions in effect on the current computer. You can nevertheless save the files on desktop or in the kioskuser folder.
