Reading XNET Detector Parameters

Scenario

On XLS/MXL fire panels, you want to read the values of fire detectors parameters (Analog, Sensitivity, Threshold, and Temperature). You can do that using manual request commands addressed to the line modules (DLC line module on XLS, ALD line module on MXL).

NOTE: The XNET network includes a 4-level hierarchical structure. In System Browser, you will find:
Project > Field Network > XNET > [panels]> [modules] >[devices (detectors)]> [components (sensors)].

  1. In System Browser, select Management View.
  2. In the XNET network, select the fire panel and make sure to have its ownership.
  3. In the fire panel, select the line module.
  4. In the Extended Operation tab, click one of the commands:
    • In Analog: Get Analog
    • In Sensitivity: Get Sensitivity
    • In Threshold: Get Threshold
    • In Temperature: Get Temperature (not available in Global FSI Fire WAN)
  5. The Get … in progress message displays while the request is being processed. In a few seconds, the values are acquired and the Get … successful message displays.
  6. In System Browser, select one of the detectors under the line module.
  7. In the Extended Operation tab, read the parameter value that you have requested. See Analog, Sensitivity, Threshold, or Temperature.

NOTE: In Sensitivity, you can also set the detector sensitivity:
- Click Set Sensitivity
- In the drop/down list, select one of the sensitivity settings from HIGH4 to LOW2 (XLS) or from HIGH3 to LOW3 (MXL).
- Click Send
