Copy the Dashboards or Energy Management Tab Configuration

You can copy the Dashboards configuration from the system, area, or device to another device of the same or different type. You can also copy the configuration of the Energy management tab from one device to another of the same type.

  1. The configured Dashboard or Energy management tab is present.
  1. Go to Dashboards or the Energy management tab that you want to copy the configuration.
  2. To copy the dashboard configuration including the source, select Actions > Apply dashboard Config > With source.
    To copy the configuration without source, select Actions > Apply dashboard Config > Without source.
  3. To copy the configuration of the Energy management tab, select Actions > Apply dashboard Config.
  4. The Apply dashboard configuration page displays.
  5. Select the destination system, area, or device to apply the copied configuration.
  6. When copying the dashboard configuration, if you select an area as the destination, the configuration is applied to all devices of the same or different type under the area.
    For example, the configuration of a PAC3200 device, with or without the source, from one area can be copied to another device(s) of the same or different type, which are available under the same area or a different area.
  7. When copying the configuration of the Energy management tab, if you select an area as the destination, the configuration is applied only if the destination contains the same device type as the source device for the area.
    For example, the configuration of a PAC3200 device, including source from one area, can be copied only to the same device type, PAC3200, which is available under the same area or a different area.
  8. Click Apply.
  1. If you have copied the dashboard configuration, a new dashboard is created on the destination device(s) with or without the source.
  2. If you have copied the configuration of the Energy management tab, the Energy management tab is created on the destination device(s) including the source.
