Integrating APOGEE P2 Systems

Scenario

You want to integrate APOGEE P2 software into Desigo CC. Once you integrate the P2 systems, you can then migrate APOGEE Insight Software. For migration step-by-step topics, see Migrating APOGEE Insight Software. For migration reference material, see Migrating APOGEE Insight Software.

Prerequisites

  • You have installed the Desigo CC management platform
  • You have a project configured
  • You have access to the Desigo CC Export Utility in Insight or the CT Commissioner
