Creating and Managing Groups in Mobile Flex

This section provides step-by-step instructions on how to create, update, and remove group from the mobile Flex web app.

  1. Tap  and select System.
  2. Rotate your mobile screen to view the left side bar.
  3. In the left side bar, tap  and navigate to Notification > Groups.
  5. Tap Create and enter Name and Description of the group.
  6. To add recipients to the group, tap  and select Add recipient from the menu options.
  7. The Add recipient dialog box displays with the list of recipients.
  8. Select the checkbox corresponding to the recipient you want to add to the group and tap Create.
  9. The selected recipients are added to the group.
  10. (Optional) To remove a recipient or sub-group from the selected group, select the specific recipient or group and tap Remove.
  11. (Optional) To edit the group, tap  next to the group tile and select Edit from the menu options.
  12. (Optional) To delete the group, tap  next to the group tile and select Delete from the menu options.
