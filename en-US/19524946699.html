Notification Center

Function

Description

Details

Buzzer

Cannot edit sound settings.

In the Notification style settings, the feature Play sound for unprocessed events is switched on permanently. The operator can never disable the possibility to play a sound when a new event occurs.

Toast messages in Notification Center

Enable notifications for new events.

In the Notification style settings, the operator can switch on or off the feature Show in Notification Center, which allows showing toast messages for new events in the Notification Center.

Event List

Function

Description

Details

Event filters

Enable automatic removal of applied filters on new events.

Any applied filter criteria are automatically cleared when a new event occurs.

Event grouping

Disable grouping together events that occur when the same event source repeatedly generates the same alarm condition.

Events belonging to the same source and category display as individual events in Event List.

Colored rows

Indicate the event row color.

The event row color matches the event category color.

Columns

Indicate Event List default columns.

  • Discipline/category (event icon)
  • Event cause
  • Source
  • State
  • Date/time
  • Timer
  • Belongs to

The operator can resize, move, or hide only some of the columns, and restore default columns layout.

Event icon, Source and State are the only columns that the operator cannot resize, move, or hide.

The operator can show or hide additional columns but cannot resize the Commands column.

Sorting criteria

Indicate default event sorting in Event List.

  • State: Unprocessed (to be acknowledged) events grouped on top, then Ready to be reset events, then events that are Waiting for condition
  • Category: most severe on top, for example, Life Safety before Fault
  • IN before OUT: events relating to the start of the alarm condition, then events relating to the end of the alarm condition
  • Date/time: oldest event on top

With this sorting, all the ‘to be acknowledged’ events will be grouped at the top. Within the ‘to be acknowledged’ group, events will be grouped by category, IN before OUT. Finally, within a group of ‘to be acknowledged’ events belonging to the same category and IN before OUT, the oldest ones will display on top.

Disable sorting

Disable the possibility to change event sorting.

The operator cannot change default event sorting.

Disable multiple selection

Disable the possibility to select multiple events in Event List.

The operator can only handle one event at a time.

Disable event commands on active event filter

Disable the possibility to send event-handling commands when a filter is applied to Event List.

The operator can see but not send event-handling commands.

Direction

Visual indication of OUT events.
