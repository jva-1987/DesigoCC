Execution and Parameter Information Workspace

1

System Browser

- Displays the list of objects in the selected view (Application View, Management View, Logical, Physical, and UserView).
- Reports configured in the standard client are displayed on the System Browser.

- When you select the System Browser node, the Reports tab is displayed.

- To view the Reports tab in Primary pane or in Secondary pane and generate report from these panes:
Select the System Browser on which the reports are available, and then select  on the right of the selected report to open the contextual menu. Select either Send to primary or Send to secondary.

2

Displays the report name which is selected for the generation of reports. Allows you to access the reports that are fetched from the standard client and to generate reports in PDF and Excel or in both format.

Displays the report title on the left side and  icon the on the right side to maximize and minimize the window.

3

Reports

Displays the default rule defined for the report in the field.

4

Generate

Generates the advanced report output in three formats:

- PDF format: PDF report along with timestamp is generated successfully and its preview is displayed in the preview area.

- Excel format: The Excel report along with the timestamp is generated successfully but its preview is not displayed in the preview area. To view the report, select the corresponding report in the History area and download the report locally from the preview area.

- Both formats: The generated report is displayed in the preview area in PDF format. The history group entry can be expanded by showing two sub-entries, one for PDF and one for Excel.

When the report is generated, click  to Download, Preview, and Delete the report from the generated reports list.

- When you delete the reports, the report that is generated in the History area and the default location ([Installation Drive C]:\[Installation Folder]\[Project Name]\ [FlexReports]) gets deleted.

- If the number of files in the [FlexReports] folder exceeds the default storage space limit of 500 MB or as per the configuration, then all the older reports get auto-deleted from the folder.

5

Duration

Select the duration from the following for the report to be generated:
- Today: Generates a report for the current day, measuring data from 12:00 AM to the current local time on the same day.

- Yesterday: Generates a report for the previous day, measuring data from 12:00 AM of the previous day to 12:00 AM of current day.

- This Week: Generates a report for the current week, measuring data from 12:00 AM on Monday of the current week to the current local time (considering Monday to Sunday as a week).

- Last Week: Generates a report for the last week, measuring data from 12:00 AM on Monday of the previous week to 12:00 AM on Monday of the current week (considering Monday to Sunday as a week).

- This Month: Generates a report for the current month, measuring data from 12:00 AM on the first day of the current month to the current local time.

- Last month: Generates a report for the previous month, measuring data from 12:00 AM on the first day of the previous month to 12:00 AM on the first day of the current month.

- This Year: Generates a report for the current year, measuring data from 12:00 AM on the first day of the current year to the current local time.

- Last Year: Generates a report for the previous year, measuring data from 12:00 AM on the first day of the previous year to 12:00 AM on the first day of the current year.

- Custom: Generates a report for the user-defined duration. You can specify the range using From Date Time and To Date Time. If Compare option is selected, you can also define Compare From Date Time and Compare To Date Time.

- Relative: You can specify the relative durations for the report by setting the option to Last or Current. For more information on Relative durations, see Report Workspace under Operating Reference in the Installed Client help file.

For example, if the current data and time on your computer is 26/06/2025 11:40 AM and you specify any of the following:
- Today: The data for the period 12:00 AM to 11:40 AM is retrieved.
- Yesterday: The data for the period June 25, 2025 12:00 AM to June 26, 2025 12:00 AM is retrieved.
- This Week: The data for the period June 23, 2025 12:00 AM to June 26, 2025 11:40 AM is retrieved.
- Last Week: The data for the period June 16, 2025 12:00 AM to June 23, 2025 12:00 AM is retrieved.
- This Month: The data for the period June 01, 2025 12:00 AM to June 26, 2025 11:40 AM is retrieved.
- Last Month: The data for the period May 01, 2025 12:00 AM to June 01, 2025 12:00 AM is retrieved.
- This Year: The data for the period January 01, 2025 12:00 AM to June 26, 2025 11:40 AM is retrieved.
- Last Year: The data for the period January 01, 2024 12:00 AM to January 01, 2025 12:00 AM is retrieved.

Interval Type

Specify the interval type for the selected duration to generate the report.
For the interval types Sec, Min, Hour, and Day, the report generates with values measured every second, minute, hour and day accordingly.
Applicable to Standard, Load Duration, Load Variance, Absolute Energy, and Cost Center reports.

Interval Length

Specify the interval length for the selected interval type.
For example, if the Interval Type = Min and the Interval Length = 15 for the duration = Today, the report generates with values measured for every 15 minutes in a day.
Applicable to Standard, Load Duration, Load Variance, Absolute Energy, and Cost Center reports.

From Date Time

For the Custom duration, specify the From Date Time value to define the start range of the report generation. For example, if the From Date Time = May 16, 2025 00:00 hours, the data is measured from this duration.

To Date Time

For the Custom duration, specify the To Date Time value to define the end range of the report generation. This range can also be defined using future dates.
For example, if the To Date Time = May 17, 2025 00:00 hours, the data is measured till this duration.

Additional Interval(+1)

Enable this option to measure an additional interval of data in addition to the data measured for the defined duration and intervals. For example, if the Duration = Yesterday, Interval Type = Hour, Interval Length = 1, and the Additional Interval (+1) is enabled, the data is measured from the local system time of 00:00 hours of the past day to 00:00 hours of the current day with an additional hour data for the current day (01:00 hours). Applicable to Standard report.

Relative Duration Type

Select the relative duration type as Last or Current from the drop-down list, as required to retrieve the data accordingly.
Enable the Compare option to compare the data from two different relative durations. For example, if Duration = Relative, Relative Duration Type = Last, Relative Duration Length (1 to 999) = 1, Relative Duration Unit = Day with Compare option enabled, the report is generated with data for the previous day compared to the day before yesterday. In detail, if the Next Schedule date is 25/06/2025, the report is generated for 23rd and 24/06/2025 with comparison.
For more information on Relative duration, see Scheduling Report Configuration Expander under Report Workspace.

Relative Duration Length (1 to 999)

Specify the relative duration length in numbers (range =1 to 999) for the selected relative duration type.

Relative Duration Unit

Select the relative duration unit from the following for the selected relative duration length:
- Min
- Hour
- Day
- Week
- Month
- Year

Run

Click Run to create report for the selected values.
