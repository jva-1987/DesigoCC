Which Devices Appear in Device View

By default, Device View displays a set of predefined device types, such as fire panels, management stations, intrusion systems, and comfort or additional integrations. You can add additional devices by customizing the libraries. This must be done on the installed client in Engineering mode.

More specifically, Device View will show:

  • All the same devices that would appear in the Node Map on the installed client.
  • Any additional devices configured to appear only in Device View (but not in the Node Map).

For more information, in the installed client help search for "Customizing the Node Map".

Device View System Limits

An excessive number of devices or activity may slow the loading of the Device View page. For a loading time of less than 2 seconds, the system limits are:

Number of devices

  • 200 Fire Panels (with ownership)

System load

  • 5 COVs per second
  • 1 alarm per second
