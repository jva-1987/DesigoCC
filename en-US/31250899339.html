NCC-2F Card for XNET

The NCC-2F card is a PCI-compliant network card providing the supervised RS-485 network connectivity to XNET. The NCC-2F operates in both Class B (DCLB) and Class X (DCLC) modes, and can also be used for NRC-based ring networks.

NOTE: NCC-2F card is not compatible with OS above Windows 10 or Windows Server 2019.

Hardware Installation

The card comes pre-installed in new computers or you can install it in any available PCI 5V available slot following the Installation Instructions (P/N 315-049430-2) provided with the hardware.

When Desigo CC connects to a NRC-based XNET network, the card requires additional interface hardware to be installed in one of the network nodes. The interface requires a separate CC-2 or CC-5 card cage with NRC and NIC-C modules.

Configuration

The NCC-2F is automatically assigned to a standard COM port by Windows when the drivers are installed. The installation process usually takes the next available COM port. There are no jumpers involved and no manual configuration is required.

Electrical Connections

The XNET connections are made on the terminal block on the front of the NCC-2F card. Refer to Installation Instructions (P/N 315-049430-2) for detailed wiring information.

Software Installation

The NCC 2F card requires a device driver whose files are provided with the hardware. The installation procedure is described in the Installation Instructions (P/N 315-049430-2).
