Importing APOGEE Information Text

  1. The prerequisites in APOGEE Information Text Importer Overview have been met.
  2. System Manager is in Engineering mode.
  1. In System Browser, select Management View.
  2. Select Project > System Settings > Conversion Tools > APOGEE Information Text Importer.
  3. From the Information Text Import tab, click Database Import .
  4. The Select APOGEE Information Text dialog box displays.
  5. In the Look in field, search for the folder that contains the APOGEE database you want to import.
  6. Click OK.
  7. In the Information Text Import tab, a list of all available panels displays.
  8. Select the check box next to the panels you want to import, and click Start.
  9. Click Yes.
  10. The Import Summary dialog box displays the status of the import.
  11. (Optional) For more details about the import, click Open Log or view the Detailed Log.
  12. Click OK.
