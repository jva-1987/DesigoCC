Event List Columns

In Flex client web/desktop app on large monitors, after you increase the width of the Event List area, Event List changes to table view and column headers become available on top of it.

  • The visible headers and their order may vary depending on column customization. In addition, note that resizing the browser window may prevent the column headers and some details from being displayed. If you reduce the browser window size, make sure to have a sufficient view of the required information.
  • On top right of event details, use  to customize the columns. For instructions, see Show, Hide, or Rearrange Columns in Event List.
  • You can also rearrange event sorting directly from the column headers. For instructions, see Changing the Sorting of Events.

 

Column Header

Description

Discipline/category

Event icon
NOTE: You cannot move, resize, or remove the event icon column.

Event cause

Descriptive text of the event cause.

State

Includes the following:

  • Event source state
  • If an operating procedure was configured for a specific event, the icon  indicates the availability of assisted treatment to handle that event. For instructions, see Handling an Event with Assisted Treatment.
  • Number of recurring events, if any (except for UL/ULC profiles, where events are listed individually). For more details, see Handling Recurrences of an Event.
    NOTE: Depending on your profile, you may not be able to move, hide, or resize the State column.

Date/time

Event date and time

Timer

Indicates that a countdown timer is active for that unprocessed event. When the countdown ends, the event will be escalated.
NOTE: Depending on your profile, the Timer column might not be available, or might be available, but you cannot resize or hide it.

Source

Event source. Hover over the column content to view the full source information in a tooltip.

NOTE: Depending on your profile, you may not be able to move, hide, or resize the Source column.

Belongs to

Parent of the object property that issued the event.
Whether the name or description displays, depends on the current display mode.

Informational text

Text configured for the off-normal and normal conditions of the event source.
It can be technical information, instructions for operators, or intervention forces.

Path

The entire System Browser path of the object that issued the event.
Whether the name or description displays, depends on the current display mode.

Hover over the column content to view the full path information in a tooltip.

Commands

Available command for handling the event.
NOTE: You cannot resize the Commands column.

You can directly select the button to send the corresponding command.
If no suggested action is available in the Commands column, you can use  to view the list of commands in a popup; text in light gray indicates that those commands are unavailable because they were already issued or they cannot yet be issued.

NOTE: Depending on your profile, you may not be able to send event-handling commands when Event List is filtered.

Proposed action

Describes the next action the operator must take for handling the event.

State icon

Proposed action text



Acknowledge event



  • Wait for condition
  • Finish assisted treatment



Wait for condition



One of the following:

  • Ready to be reset

System name

Indicates the name of the individual system where a specific event occurred.

Event message

Text that consists of one of the following:

  • For driver alarms, the most recent message that has come from the field panel at any alarm transitions.
  • For workstation alarms, blank or the event cause.

In process by

Indicates details of the event processing as follows:

  • For anonymous Flex client:
    Web client\[full name of the logged-on user]
  • For identified Flex client: [web client name]\[full name of the logged-on user]

If the computer or device/user data was not specified in the configuration, [localhost]+[user’s short name] displays instead.

Furthermore, for recurrences of the same event, after you select the most recent recurrence of that event in Event List:

  • This column indicates [local client name]\[full name of the logged-on user].
    The same happens if, under Events in the event details, you also select the individual recurrence that corresponds to the most recent recurrence of that event.
  • This column is cleared if, under Events in the event details, you select any other recurrences older than the most recent recurrence.

Alias

Indicates a customer-assigned name used to identify the technical equipment within the building/facility.
