Assign Event Category to GCNET Device Status Points

If the imported XNET network includes field devices configured to produce a status message, you must assign the status event category to the status message so as to display an event in Event List.

  1. System Manager is in Engineering mode.
  1. In System Browser, select Management View.
  2. Select the device containing at least one component configured as status point in the imported XNET network tree.
  3. Select the XNET tab, and open the Status Events Display Settings expander.
  4. From the drop-down list, select the Status event category.
  5. (Optional) Select is Self-Restoring to indicate that no acknowledge or reset is required.
  6. Repeat the steps above for all device status points.
