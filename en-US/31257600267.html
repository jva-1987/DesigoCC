Settings

1

Widget name

Displays the widget name. You can change the name if required.

2

Override dashboard settings

Override the dashboard settings for the widget and define the new settings. If the dashboard is set to override, then the options to change the Period and Default interval are enabled in the Settings, which are already set while creating the dashboard.

Enabling the Override dashboard settings, displays the Selected date range and Interval options in the widget that is saved in the dashboard.

3

Compare

Enable the compare toggle button to compare the data with the reference data. Enabling the Compare button displays the Compare*, Selected date range, Reference date range, Style, and Match the days options.
The compare toggle is available in the widget added to the dashboard page to enable or disable the comparison and view the data.

4

Compare*

The Compare* field contains the following options:

- Dashboard to custom: Compares the selected date range (date range defined in the dashboard) value to the reference date range value and displays the consumption values for the selected data point. For this setting, the reference value can be modified. For example, if Compare* = Dashboard to custom, the Selected date range will be disabled with value 03/14/25 - 03/16/25 and the Reference date range will be 03/11/25 - 03/13/25 which is the same number of days as the Selected date range. The dates for the Reference date range are considered from the past days of the Selected date range start date.

- Today to yesterday: Compares the values up to the current local system time from 00:00 hours of the yesterday and displays the consumption values for the selected data point.
For example, if Compare* = Today to yesterday, the Selected date range will be 03/14/25 - 03/14/25 and the Reference date range will be 03/13/25 - 03/13/25.

- This week to last week: Compares the past week values to the current week values up to today and displays the consumption values for the selected data point.
For example, if Compare* = This week to last week, the Selected date range will be 03/09/25 - 03/14/25 and the Reference date range will be 03/02/25 - 03/08/25.

- This month to last month: Compares the values from past month to the current month up to today and displays the consumption values for the selected data point.
For example, if Compare* = This month to last month, the Selected date range will be 03/01/25 - 03/15/25 (consider up to current date) and the Reference date range will be 02/01/25 - 02/28/25.

- This quarter to last quarter: Compares the values from the past quarter to the current quarter up to today and displays the consumption values for the selected data point.
For example, if Compare* = This quarter to last quarter, the Selected date range will be 01/01/25 - 03/15/25 (consider up to current date) and the Reference date range will be 01/10/24 - 12/31/24.

- This year to last year: Compares the values from the past whole year to the current year up to today and displays the consumption values for the selected data point. When this option is selected in the Compare field, the Selected date range and Reference date range fields are disabled and cannot be modified.
For example, if Compare* = This year to last year, the Selected date range will be 01/01/25 - 03/15/25 (consider up to current date) and the Reference date range will be 01/01/24 - 12/01/24.

- Custom: Compares the values for the selected custom range and displays the consumption values for the selected data point. Allows you to select any date range for both charts.

5

Select the color for both selected and reference date range of the consumption chart.

6

Selected date range

Displays the date range to compare with the reference date range. Values will be calculated up to the selected date range based on the reference range.

7

Reference date range

Displays the date range to compare with the selected date range. Serves as the reference point to restrict the values calculation.

8

Default interval

Select the interval for the data points based on the selected period. The available intervals are 15 min, Hourly, Daily, ISO weekly, Work week, and Monthly.

- 15 min: Displays the chart for every 15 minutes within the defined date range.

- Hourly: Displays the chart for every 1 hour within the defined date range.

- Daily: Displays the chart for every 24 hours within the defined date range.

- ISO Weekly: Displays the chart for ISO weeks within the defined date range.

- Work week: Displays the chart for the work weeks within the defined date range.

- Monthly: Displays the chart for every month within the defined date range.

9

Match the days

Matches the days for the selected and reference date range values and displays the consumption values.
For example, if Compare* = This week to last week, the Selected date range will be 03/09/25 - 03/14/25 (Monday - Friday) and the Reference date range will be 03/02/25 - 03/08/25 (Monday - Saturday). Selecting Match the days, displays only the common days (Monday - Friday) from both weeks.
