Linking Web Service Application, Flex Web Application, Power Quality Web Application, and Power Quality Database to the Project

 You have created a Web Service, Flex Client, and Power Quality web applications.
 You have created a Power Quality database.

Linking Web Service Application and Flex Web Application to the Project

  1. Open SMC and navigate to your project.
  2. Open Power Monitoring tab.
  3. Select Web Service Application from WSI Web App drop-down.
  4. Select Flex Client Application from Flex Web App drop-down.
  5. Click Save .
  1. Web Service application and flex web app are linked to project.

 

Linking Power Quality Web Application and Power Quality Database to the project

  1. Open SMC and select created project.
  2. Navigate to PowerQuality tab and PowerQuality Details expander.
  3. Select Linked PowerQuality Web App and Linked PowerQuality DB.
    For Remote PQDB, the Encrypted check box is selected by default when you save and reload the PowerQuality tab.
  4. Click Save .
  1. Power Quality analytics web application and Power Quality database linked to the project.
