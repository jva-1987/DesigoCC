Connect with Web Interface

  1. Web Interface is only supported together with the Desigo Room Automation subsystem.
  1. In System Browser, select Logical View.
  2. Select Logical > [network name] > [building] or [floor] .
  3. Room Overview displays all room Rooms.
  4. Select the room.
  5. In the context menu, select Related Items.
  6. Select Device.
  7. Select the Data Configuration View.
  8. Enter the log-in data for the web interface.
  9. Select Logon.
  1. The web interface displays.
