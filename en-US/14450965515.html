Treating FS20 Fire and Carbon Monoxide (CO) Detection Alarms

Handling an alarm from Desigo CC includes multiple steps. The following procedure presents a typical scenario. You can suspend/resume this procedure at any step.

  1. (Optional) Select the event (one at the time).
    NOTE: The next expected command (Acknowledge, Silence, or Reset) is directly available for each event in Event List without any selection.
  2. Click Acknowledge .
  3. This informs the local panels that the event treatment is started on the management station.
  4. Click Silence to stop the local horns and silence the alarming devices.
  5. Check the field conditions using the available alarm verification tools in System Manager such as dynamic graphics and video images.
  6. Depending on the specific situation, start the required counter-measures to address the actual alarm situation in the building.
  7. Ensure that the alarm condition has terminated.
  8. Click Reset to reset the alarm.
  9. Click the event button.
  1. The event is cleared from Event List.
