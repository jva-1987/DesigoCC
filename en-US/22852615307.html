Manually Configure the Comark Driver

  1. When working on a FEP station, the driver folder must be available in System Browser. You can create it using New .
  2. You know which serial port is used to connect the card (check hardware model specifications.
  1. In System Browser, depending on where the card is installed, select one of the following:
    • Project > Management System > Servers > Main Server > Drivers
    • Project > Management System > FEPs > [FEP] > [drivers folder]
  2. In the Object Configurator tab, click New and select New Comark Driver.
    NOTE: You can only create one Comark driver on a station.
  3. In the New Object dialog box, enter a name and description.
  4. Click OK.
  1. The newly created Comark node is automatically selected in System Browser.
  1. In the System Management tab, open the General Settings expander.
  2. (Optional) In the Vendor and Type field, enter a textual comment of your choice about the installed monitor card. By default, this field just indicates Comark.
  3. In the Communication Port field, select the serial port connected to the card.
  4. Click Save.
  5. In the Properties expander, configure the relay output.
    The general procedure is the following:
    a. Select the Relay Active property.
    b. Drag a point from any of the System Browser views onto Data PointName.
    c. Enter the Property Name and Activation value.
    d. Click Save.
    e. Repeat the steps for all the data points to set.
    NOTE: The configuration of specific applications of the relay output is provided in the next sections.
  6. Modify the default setting of one or more of the following properties:
    For each of the properties, select it, modify the value, and click Save.
    • Fan Alarm (mandatory)
    • Set Alarm Timeout
    • Set High Limit In
    • Set Low Limit In
    • Set Message Interval
    • Sound Audible (mandatory)
    • Temperature Alarm
  7. In the Operation tab, select the Manager Status property.
  8. Click Start to activate the driver.
