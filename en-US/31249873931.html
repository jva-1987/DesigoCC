Migrating and Upgrading XNET Panels

This section contains engineering procedures for upgrading Desigo CC projects with XNET fire control panels, and migrating the configuration of XNET fire control panels.

Upgrade Desigo CC from Previous Versions

When you upgrade Desigo CC from V3 or V4 to V5, follow the standard Desigo CC upgrade procedure.

Then, in the Desigo CC project, re-import the XNET network to apply the latest library modifications.

 

Migrate the Configuration of MXL Panels to XLS Panels

If an MXL panel is replaced by an XLS panel in the field, you can update the project by re-importing an updated configuration file and updating the graphic maps. All previous configurations will be saved, except for system views, which need to be re-configured manually in Views.

  1. The panel address assigned to the XLS panel is the same as the one assigned to the MXL panel.
  1. Create an XLS node, and populate it with proper hardware to match the MXL properties.
  2. Export the configuration file of the XLS panel from the Zeus tool.
  3. Import the configuration file of the XLS panel into the existing XNET network, the same XNET network where the MXL panel was configured.
  4. The MXL panel configuration is replaced by the XLS panel configuration.
  5. Set System Manager to Engineering mode.
  6. In System Browser, select Application View.
  7. Select Applications > Graphics > [graphic map].
  8. In the Graphic Editor, click File > Update graphics.
  1. The graphic map is updated.
