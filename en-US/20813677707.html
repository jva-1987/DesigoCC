Discovering Devices

Complete the following procedures in order:

Checking for BACnet Devices on the Network

  1. In the Desktop Search field, enter BACnet Object Browser, and then click the associated App.
  2. Verify that the devices you want the system to discover appear in the BACnet Object Browser’s left pane.
    NOTE: If you do not see your devices in the BACnet Object Browser, they will not appear in Desigo CC. In this case, use field panel documentation to troubleshoot your BACnet configuration or your physical network setup, or both.

Configuring Discovery Settings

  1. System Manager is in Engineering mode.
  2. A BACnet driver has been added, a BACnet network has been added, and a BACnet driver has been assigned to the BACnet network.
  3. The BACnet network is selected in System Browser.
  4. The Discovery tab is selected.
  1. Click the Discovery Settings expander.
  2. In the General Setting section, specify the Scan timeout in seconds if you want to change the default setting. This setting determines the amount of time a network scan runs before it stops.
  3. In the Auto-discovery Setting section, check the Enable auto-discovery for devices check box if you want to automatically scan for new devices on the network.
  4. In the Filter Setting section, specify any combination of the following three settings:
    • To enable the discovery of all the devices on one network, select the Use network filter option. Then enter the network number in the Network number filter field.
    • To enable the discovery of all the devices within a range, select the Use instance Filter option. Then enter your range of numbers in the Beginning instance and Ending instance fields.
    • To enable the discovery of all the devices on the network from one vendor, select the Use vendor filter option. Then enter the vendor ID number in the Vendor ID field.
  5. Click Save .

(Optional) Running Auto Discovery

  1. You want to automatically discover devices only.
  2. System Manager is in Engineering mode.
  3. A BACnet driver has been added, a BACnet network has been added, and a BACnet driver has been assigned to the BACnet network.
  4. The BACnet network is selected in System Browser.
  5. The Discovery tab is selected.
  6. Discovery filters have been set.
  1. Click the Discovery Settings expander.
  2. Check Enable auto-discovery for devices.
  3. Click Save.
  4. As devices are discovered, they display in the Discovery Status section.
  5. Start monitoring the discovery progress in the Discovery Status section, keeping in mind that devices are only discovered if they are on the network. If you do not see activity in the Discovery Status section or in the BACnet network in System Browser, you must troubleshoot the problem.
  6. To automatically stop discovering panels, uncheck Enable auto-discovery for devices.

Running Manual Discovery

  1. System Manager is in Engineering mode.
  2. A BACnet driver has been added, a BACnet network has been added, and a BACnet driver has been assigned to the BACnet network.
  3. The BACnet network is selected in System Browser.
  4. The Discovery tab is selected.
  5. Discovery filters have been set.
  1. Click the Device Discovery expander.
  2. Click Scan.
  3. As devices are discovered, they display in the Network Scan section.
  4. To stop the scan, you can do one of the following:
    • Click Cancel.
    • Wait for the scan to timeout based on the setting specified in the Discovery Settings section.
  5. (Optional) Do the following:
    • If you want to discover only a device, with no objects attached:
      a. Check Import Selection for the device.
      b. Select the Create Device Only check box.
      c. Click Save .
    • If you want to use a library other than the default:
      a. Click the Library drop-down menu.
      b. Select the library that applies to this device.
    • If you want to limit the number of objects discovered for third-party BACnet devices:
      a. Check Import Selection for the device.
      b. Click Objects.
      c. Click Yes.
      d. Select the objects you want to include in the import.
      e. Click Save .
      f. Click Back.
      g. Repeat this process for each device you want to limit.
  6. Check Import Selection for the device you want to discover.
  7. Click Save .
  8. In the Discovery Status section, start monitoring the discovery progress. Discovery may take a few seconds or several minutes depending on the size of the database. If there is no activity in the Discovery Status section or in the BACnet network in System Browser, you must troubleshoot the problem.

NOTE: If a TEC application function cannot be found in one of the existing libraries during Discovery, Desigo CC automatically creates and assigns a function for the TEC. However, the function will not have a template graphic associated with it, so a default graphic will not be created. You will need to assign or create that after Discovery if desired.

(Optional) Enabling Automatic Object Discovery

  1. System Manager is in Engineering mode.
  2. A BACnet driver has been added, a BACnet network has been added, and a BACnet driver has been assigned to the BACnet network.
  3. The BACnet network is selected in System Browser.
  4. The Discovery tab is selected.
  5. The Device Discovery expander is open.
  6. Devices have not been previously limited during discovery—that is, only some of the objects in the devices have been selected for discovery. If devices have been previously limited, normally you would not enable automatic object discovery. Doing so will cause the remaining device objects to be discovered once the device database is revised.
  1. In the Discovery Status section, you can specify that devices auto-discover objects when they are added to the device.
  2. Select the Auto Discovery check box.
  3. Click Save .

Rediscovering All Objects in a Device

  1. The system is in Engineering mode.
  2. The device has already been discovered.
  1. In System Browser, select Management View.
  2. Select Projects > Field Networks > [BACnet network] > Hardware > [Device].
  3. Click the Extended Operations tab.
  4. Locate the Firmware Revision property, and then click Rediscover.
  5. Monitor the Discovery Progress property until it indicates Success.
  1. System Browser refreshes the device list.
