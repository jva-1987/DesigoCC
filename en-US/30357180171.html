Importing CSV File

  1. In System Browser, select Application View > Powermanager > Area.
  2. Select the Device created.
  3. Navigate to Extended Operations tab > Import file.
  5. File path should be entered manually in Import file section in .CSV format.
    NOTE: A sample file named MMD_Sample.csv is located in the folder [Local Drive]\GMSMainProject\Data\Powermanager.
  6. Navigate to the current project Data folder and open MMD_Sample.csv to view the following sample file format.
  7. You can use this sample file as reference to create your own .CSV file with actual data. For detailed explanation of .CSV file format, see Manual Measuring Device.
  8. Click Import.
    The button response is Import Successful.

- The message Import Successful appears by default when the Import button is clicked. It does not confirm that the file was actually imported.

- Check the Status field for the actual import progress or result.

- The Status field displays validation messages and other messages for Manual Measuring Device in extended operation, according to the operating system language.

Depending on the amount of data it takes time to show the status message for the following Import scenarios:

Scenario 1: Importing a Valid .CSV File.

  • Import file path: Valid.
  • If you click Import, the Status field displays In Progress.
  • Once the import process is completed, the Status field updates from In Progress to Import Successful.

Scenario 2: Importing an Invalid File Path or Incorrect Format of .CSV File.

  • Import file path: Empty.
    If you click Import, the Status field displays Enter the file path to import data.
  • Import file path: Invalid or Non-existent file or Incorrect format.
    If you click import, the Status field displays File does not exist or File format is incorrect.

Scenario 3: Incorrect Data Format of .CSV File.

  • If any inconsistencies occurs in the data of .CSV file, the Status field displays
    Import failed. Please check the path [Local Drive]\Siemens\SENTRON\Powermanager\[Current Project]\Log\MMD.log
  • To fix the issue, open the MMD.log file, review the error details, correct the data in the .CSV file, and then try importing again.

- Manual Measuring Device can be configured and viewed in energy reports.

- Sankey report is not supported in Manual Measuring Device.
