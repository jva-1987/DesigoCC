Flash Cache

Perform these steps if you are creating a new BACnet project or you are integrating an APOGEE Insight system.

FPWeb UI and APOGEE Editors are Adobe Flash-based applications that can “cache” field panel information.

  1. You have one of the FPWeb UI or APOGEE Editors displayed in a Desigo CC Secondary pane.
  1. Right-click and select Settings.
  2. Select the folder icon, clear the Never Ask Again check box, and move the slider all the way to the right, toward unlimited.
  3. Click Close.
