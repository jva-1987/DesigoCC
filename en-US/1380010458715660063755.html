Discovering Unassigned Applications

  1. You have imported FLN applications and have a custom or unknown application among them. The system designated the application as unassigned, with no graphic templates attached.
  2. System Manager is in Engineering mode.
  1. In System Browser, select the device with the unassigned application(s).
  2. In the Operations tab, click Discover.
  1. The system attempts to discover and import the application from the device and places the application number and description in the following locations:
  • System Settings > Libraries > Project > Common > Functions
  • System Settings > Libraries > Project > Common > Object Models
    NOTE: The discovered application does not import any graphics or custom symbols located in the libraries. Instead, it uses generic symbols. To discover an application, the FLN application and the host device must be online and not failed.
