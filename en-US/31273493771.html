Line Area Chart Workspace

The Line area chart displays a line chart with area data points of minimum and maximum value. The minimum and maximum data points for the area are represented with a gradient color, and the line chart serves as a boundary for the area. The Line area chart supports only numerical values from the selected source.

For the following device types, the data points of power with avgerage2, minimum, and maximum values are archived by default from Desigo CC V9.0 or higher when a device is newly created.
- PAC2200
- PAC2200CLP
- PAC3120
- PAC3200T
- PAC3220
- PAC4200
If Desigo CC is upgraded from earlier versions to V9.0 or higher, the data points of power with avgerage2, minimum, and maximum values for the same device types listed above must be archived to view the line area chart.
For other devices, the data points are not archived by default and displays a Trend chart when a device is newly created. You can archive the data points to view the line area chart as required.

Settings

Contains the Widget name, Override dashboard settings, and Period.

-Widget name: Displays the widget name. You can change the name if required.

- Override dashboard settings: To override the dashboard settings, enable the option toggle. This will display the option to change the Date range and Interval in the widget saved in the dashboard.

- Period: Specify the period for the chart to fetch the values.

7

Source

Contains common elements Data point, Delete, Edit, and Add like all the widgets and the additional following list of elements:

- Min. data point: Select/ Displays the minimum data point for the selected main data point. While selecting data point, most appropriate minimum value should be chosen.

- Max. data point: Select the maximum data point for the selected main data point. While selecting data point, most appropriate maximum value should be chosen.

- Data point style: Allows you to select color for the line chart. This behaves as a boundary for the area chart based on the minimum and maximum data point.

- Min. and Max. data point style : Allows you to select color gradients for the minimum and maximum area of the area chart.
