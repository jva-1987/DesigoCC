Viewing Tags in Graphics

In System Browser, in the Application view, select the Graphics tab .

Graphical tags are a way of inserting text that is linked to a variable. Instead of writing the literal text in a graphic, the user invokes a text string by inserting a tag name. While tags are set up and modified only within the management station, their value is displayed in graphics on the flex client. For a viewer of the flex client, a tag will appear to be an ordinary text string.
