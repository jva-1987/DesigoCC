APOGEE TEC Overview

APOGEE TEC is a system application that lists the subpoints for a selected P1 or BACnet FLN application. The Subpoints workspace displays in the Primary Pane when System Manager is in Engineering mode and an APOGEE P1 TEC or BACnet FLN application is the primary selection.

APOGEE TEC Workspace

NOTE:
You can sort the information in the various columns by selecting the column headings.

Item

Description

1

APOGEE TEC toolbar
Includes the following controls:
Save: Saves all changes made and sends values to the panel.
Release: Releases the initial value of the selected subpoint. To remove an override, select the subpoint with the override, and then click
Filter: Allows you to display only the subpoints that have overridden initial values. If desired, click to toggle between viewing only subpoints with overridden values and all subpoints.

2

Status Indicator
If a subpoint has changed since the last save, an asterisk (*) displays.
If there is an error or fault associated with a subpoint—for example, a value is out of range—an exclamation point (!) displays, along with a short description in the last column, until the next action.

3

Override
If the initial value for a subpoint has been overridden, OVRD displays.

4

Subpoint
Displays the default subpoint number.

NOTE: Column displays only when an APOGEE P2 TEC application is selected in System Browser. Does not display when BACnet TEC applications are selected.

5

Description
Displays a brief descriptor used for the point.

6

Initial Value
Displays the factory default value (such as a temperature setting) or overridden value of the subpoint. You can override the value by selecting the value and typing a new number, and then clicking to save the settings.

When you override an initial value, OVRD displays in the Override column.

NOTE: BACnet initial point values are not defined in the panel, therefore, this column initially displays as blank. Once the BACnet device has a Function assigned to it, the column will populate.

7

Units
Displays the engineering units of measure for the subpoint.

8

Status
Displays one of five statuses: Alarm, Failed, Out of Service, Alarm/Out of Service, Alarm/Failed.

9

Type
Displays the subpoint type.

10

Status Description
If there is an error or fault associated with a subpoint—for example, a value is out of range—a short description displays until the next action.
