Grouped List Card Workspace

The Grouped list card displays a table with several data points in multiple groups. Each group contains a list of data points added for the group. The Grouped list card widget supports only the numerical, boolean, enumerated, date, and time format values from the selected source.

1

Displays the name of the widget.

2

Displays the group name for the created groups. Click on the group name to view the group and its data points list.

3

Displays the data points in a list for the selected group.

4

Settings

Displays the Widget name and Default value view.

- Widget name: Displays the widget name. You can change the name if required.

- Default value view: Displays the created groups for the widget with an option to set the default group view in the dashboard.

5

Source

Contains common elements Data point, Delete, Edit, and Add like all the widgets and the additional following list of elements:

- Add group: Allows you to create groups for the group list card.

- [Group]: Displays the group name with indication for number of added data points.

- The  icon next to  Add in the group allows you to change the group name using Edit group and delete the group using Delete group.

- Edit group: Allows you to change the group name.

- Save: To save the changes.

- Cancel: To discard the changes.

- Delete group: Allows you to delete the group.
