Change the Browser Language to View Date and Time Format

Perform the following steps to change the browser language to view date and time format according to the selected language:

  1. Open the Chrome browser.
  2. Navigate to Settings > Languages.
  3. Select the required language from the list. If the required language is not available, perform the following:
    • Click Add languages.
    • Select the required language and click Add.

  7. Click  next to the required language and select Display Chrome in this language.
  8. Click Relaunch.
  10. The Flex client displays the date and time format as per the selected browser language.

  11. If the selected browser language is not supported, the date and time format displays as per the user language configured in the Desigo CC Installed client.
