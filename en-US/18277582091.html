Running the Network Wizard for APOGEE P2 Ethernet

Complete the following procedures:

1 – Select the APOGEE P2 Ethernet Subsystem

  1. Select Project > Field Networks.
  2. Click the Network Wizard tab.
  3. The Subsystem selection section displays.
  4. From the Available subsystems drop-down list, select Apogee P2 (Ethernet Network).
  5. Click Next page .

 

2 – Add Network Information

  1. Enter the network name and description.
  2. (Optional) To change the language selection, click the flag icon in the Network description field, select the desired language, enter the desired text, and then click OK.
  3. Enter the BLN system name.
  4. In the Discovery/Import Mapping section, do the following:
    • From the Name drop-down list, select the desired option.
    • From the Description drop-down list, select the desired option.
  5. Click Next page .

 

3 – Select a Workstation and Driver

  1. From the Station Selection drop-down list, select the workstation your subsystem will be connected to.
  2. From the Driver selection drop-down list, do one of the following:
    • If you select a new driver, click Next page . The wizard displays Step 4 of 6. Go to the Enter Driver Information topic.
    • If an Apogee driver already exists, it is selected by default. Click Next page . The wizard displays Step 5 of 6. Go to the Import APOGEE P2 Ethernet Devices topic.

 

4 – Enter Driver Information

  1. (Optional) In the Driver description field, change the descriptive text. To switch languages, click the flag icon, select the desired language, enter the desired text, and then click OK.
  2. Click Next page .

 

5 – Import APOGEE P2 Ethernet Devices

  1. Verify that Discover them from the network is selected.
  2. Click Next page .

 

6 – Review Summary Information

  1. Review the network information for accuracy. If you need to modify any of it, click Previous page until you arrive at the location where you need to modify information, and then resume your Network Wizard steps until you are satisfied with the configuration.
  2. Click Run Configuration .
  3. Click Yes.
