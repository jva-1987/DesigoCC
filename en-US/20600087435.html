Recipients

This section provides reference and background information for handling recipients in the Flex Client Notification. For related procedures, see the step-by-step section.

Recipients User Workspace

Item

Name

Description

1

Notification 

Displays the list of following Notification objects:

  • Recipients
  • Groups
  • Templates

2

Recipients (workspace)

Displays general information workspace for the recipient.

3

Recipients (column)

Displays the list of recipients in the recipient column with their state.

4

State

(Applicable only for Reno Plus users)

Displays the recipient state in front of the recipient name. Following is the list of all the recipient states:

  • Active: When the user is active, the recipient state column does not show any value.
  • Do not disturb: The state restricts the user to receive any notifications for a specific period of time.
  • Blocked: Blocked user is present in the system but does not receive any notification.
  • Temporarily Blocked: User does not receive any notification for the specific period of time. This setting can be managed from Installed client only.

5

Search

Search for a particular recipient or recipients either from the name or state.

6

Add

Adds a new recipient to the system.

7

Recipient details setting tabs

Allows you to add, edit, block, or delete the recipient information using different tabs.

8

Do not disturb

(Applicable only for Reno Plus users)

Sets the recipient state to Do not disturb mode from the time options available from the Do not disturb drop-down. You can customize the date and time using Customize option. See Set Recipient State in Creating and Managing Recipients.

Recipient Settings

Item

Name

Description

1

Actions

Provides the following options:

  • Block account
  • Delete account

2

Block account

(Applicable only for Reno Plus users)

When the recipient account is blocked, it exists in the list but does not receive any notification. See Block Recipient in Creating and Managing Recipients.

3

Delete account

The recipient is permanently removed from the Flex Client. See Delete Recipient in Creating and Managing Recipients.
