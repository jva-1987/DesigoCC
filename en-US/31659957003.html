Link a New PowerQuality Database to the Existing Project

You can link a new Power Quality database to the existing project with all the created devices. The existing database can be archived for future reference, or it can be cleaned up accordingly.

  1. A new Power Quality database is created.
  1. In SMC, select Projects > [project] > PowerQuality tab.
  2. Select the new database for the existing project from the Linked PowerQuality DB drop-down list.
  3. Click Save . Confirm with Yes.
  1. A new Power Quality database is linked to the existing project with all the created devices, and the Power Quality data starts entering into the new database.

When restoring a Power Quality database to the project, disable the Retention Period before linking to the project to avoid data loss if the data is older than the defined retention period.
