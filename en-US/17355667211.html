Working with the APOGEE P2 AEM Network

Do the following tasks as needed:

Remove an APOGEE P2 AEM from the Network

You can remove an APOGEE P2 AEM from your Desigo CC BLN. This ends the connection between your AEM network and the AEM device.

  1. System Manager is in Engineering mode.
  2. Your network has associated APOGEE P2 AEMs.
  1. In System Browser, select Management View.
  2. Select Projects > Field Networks > [APOGEE P2 AEM network].
  3. The properties for the APOGEE P2 AEM display in the Operation or Extended Operation tab.
  4. From the Has AEM property, click Remove AEM.
  5. A success message displays.

Reset APOGEE P2 AEMs on a Network

You can reset your APOGEE P2 AEMs from your Desigo CC BLN. This action will disconnect and reconnect all the APOGEE P2 AEMs associated with your APOGEE P2 network.

  1. System Manager is in Engineering mode.
  2. Your network has associated APOGEE P2 AEMs.
  1. In System Browser, select Management View.
  2. Select Projects > Field Networks > [APOGEE P2 AEM network].
  3. The properties for the APOGEE P2 AEM display in the Operation or Extended Operation tab.
  4. From the Has AEM property, click Reset AEMs.
  5. A success message displays.

Disconnect an APOGEE P2 AEM from the Network

You can disconnect the APOGEE P2 AEM network from the Desigo CC management platform. This means that all the panels on that network will be disconnected.

  1. System Manager is in Engineering mode.
  2. Your network has associated APOGEE P2 AEMs.
  1. In System Browser, select Management View.
  2. Select Projects > Field Networks > [APOGEE P2 AEM network].
  3. The properties for the APOGEE P2 AEM display in the Operation or Extended Operation tab.
  4. Click on the Extended Operation tab.
  5. From the Connection Status property, click Disconnect.
  1. A success message displays.

Synchonize the APOGEE P2 AEM BLN Time

From the Desigo CC AEM network, you can perform a time synchronization of all the panels on the network with the current time of the Desigo CC management platform. When you perform this task, the current Desigo CC management platform's time is sent to all the field panels on that network and the panels' time is adjusted to the management station's time.

From Desigo CC you can perform a manual time synchronization at the field panel.

  1. System Manager is in Engineering mode.
  2. Your network has associated APOGEE P2 AEMs.
  1. In System Browser, select Management View.
  2. Select Projects > Field Networks > [APOGEE P2 AEM network].
  3. The properties for the APOGEE P2 AEM display in the Operation or Extended Operation tab.
  4. Click on the Extended Operation tab.
  5. From the Connection Status property, click Time Sync.
  6. A success message displays.

Update an APOGEE P2 AEM Network

You can perform a manual update on all the field panels in an APOGEE P2 AEM network.

  1. In System Browser, select Management View.
  2. Select Projects > Field Networks > [APOGEE P2 AEM Network].
  3. From the Operations tab, in the Status properties, click Discover.
  1. All your APOGEE P2 AEM panels on that network are updated to reflect any changes made.
