Point Creation

When you add or create a point with the APOGEE Point Editor, you must specify the data point type and other information which describes the characteristics of the data point, such as the name, description, address, and alarm characteristics. When you create a data point, you define the characteristics of the data point and then save it in the field panel.

Device and Network Validation

Validation helps protect against inadvertent changes that may affect the system. This means that user action might be required for viewing, changing, or commanding validated objects and devices on an APOGEE network. The action required, depends on the validation profile of the device or the network.

For more information, see the Validation reference documentation.
