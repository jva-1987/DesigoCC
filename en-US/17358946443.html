APOGEE P2 AEM Overview

The APOGEE Ethernet Microserver (AEM) allows your remote APOGEE P2 AEM Building Level Network (BLN) to connect directly to an APOGEE P2 Ethernet network and its connected devices at all times. The BLN can consist of a single remote field panel or a maximum of 99 field panels if all are running APOGEE firmware.

The documentation in the APOGEE P2 Help file guides you through the process of setting up your APGOEE P2 AEM network and your existing P2 AEM devices in Desigo CC , and then importing the field panel objects associated with those devices. Additionally, the APOGEE P2 Help file provides the tasks and steps to work with your APOGEE P2 AEM network and devices.

APOGEE P2 AEM Network Limitations

Desigo CC supports a maximum of 128 APOGEE P2 AEM networks.

APOGEE P2 AEM\VAEM Requirements

You must use an AEM to connect an Apogee P2 RS-485 network to Desigo CC .

Desigo CC supports the APOGEE P2 AEM network and requires either a:

  • Physical AEM device, or a
  • Virtual AEM device in the PXC field panel. (Recommended, performance will be considerably faster.)
  • An AEM can be connected to only one management station at a time.
  • If a network of APOGEE P2 RS-485 controllers is connected to both Insight and Desigo CC through AEMs, then two AEMs are required.
  • If a network of APOGEE P2 RS-485 controllers is connected to Insight through a TI-II and to Desigo CC through and APOGEE P2 AEM, then one APOGEE P2 AEM is required.

APOGEE P2 AEM Function in the Management Station

The APOGEE P2 AEM performs the following functions in Desigo CC :

  • The flash memory in the APOGEE P2 AEM stores an IP address or Device Name that allows the APOGEE P2 AEM to communicate with other AEM Ethernet network devices using the TCP/IP protocol.
  • An APOGEE P2 AEM BLN uses an Ethernet network to communicate with Desigo CC .
  • When an APOGEE P2 AEM BLN is defined, it is linked to a specific field panel. Even though Desigo CC can communicate with every field panel on the Ethernet network, all communication for the AEM BLN is routed through the field panel where it is defined. An AEM BLN cannot be connected to more than one Desigo CC management station on the same MLN.

When you define an APOGEE P2 AEM you define the fixed or reserved IP address of the APOGEE P2 AEMs. One APOGEE P2 AEM is used for each remote BLN.

New APOGEE P2 V-AEM Devices

If a new APOGEE P2 AEM must be added to an APOGEE P2 AEM network in Desigo CC , there are three available options:

  1. Use an external AEM2100 - (Not recommended)
  2. Configure a Virtual AEM in an existing PXC controller
  3. Install a new PXC controller configured as a Virtual AEM

Options 2 and 3 are preferable to an external AEM, as a VAEM has a faster processing speed.

Refer to Field Panel documentation for more information about purchasing, installing, enabling, and configuring AEMs and PXC controllers. Supported hardware, firmware, and licenses are required for use of Virtual AEMs.

APOGEE P2 AEM Device Backups

APOGEE P2 AEM devices are backed up by the Desigo CC management station every 24 hours. The backup files are stored in your project folder in the following location: [Your project]\Data\Device\Backup folder.

You can perform a manual backup of your device(s), from the Status property of the Operations\Extended Operationtab, in Desigo CC .
