Create a Consumption Chart

You can create the Consumption chart widget that displays the live and historical consumption values for a specified period using bar chart. For background information, see Consumption Chart Workspace.

  1. In the dashboard, select the Consumption chart from the Create Widget list.
  2. Click Next.
  3. The Create widget page opens.
  4. Click Add to select the data point.
  5. Select the device from the list and click Select.
    You can also select System and Area instead of device to get the data points list.
    Similarly, when you create Dashboard > [Widgets] from System or Area node, than the sources can be selected from System or Area or Device node only if the configuration is enabled in the standard client.
  6. Select the Data point from the drop-down.
    In the Installed Client, data points must be archived to view their values in the Flex Client Consumption chart.
  7. The Consumption chart is created and displays the historical consumption values for a specified period in a bar chart.
  9. Click Create to add the widget to the dashboard.
  10. Click Save.
  1. The widget is created in the dashboard with the default time interval defined in the dashboard.

Create a Comparison Consumption chart

You can create a comparison in the consumption chart for different date ranges with different color codes.

  1. The consumption chart is created.
  1. In the consumption chart, select the Settings tab.
  2. Enable the Override dashboard settings.
  3. Enable the Compare toggle button.
  4. The Compare*, Selected date range with Style, Reference date range with Style, and Match the days options displays for configuration.
  5. Select the Compare* value from the drop-down. Based on the selected value for Compare* , the Selected date range and Reference date range values are auto-populated, and the Default interval will vary.
    For example, if Compare* = Today to yesterday, the Selected date range will be 03/14/25 - 03/14/25 and the Reference date range will be 30/13/25 - 03/13/25.

  6. Consider the time range from 00:00 to 00:00 hours of both days and use the MM/DD/YY format for dates in all examples.

  7. Select the Default interval from the drop down.
  8. The Comparison Consumption chart displays for the selected and reference date range.
  9. If you want to match the selected data range and reference date range based on the Compare* value, enable Match the days check box.
    For example, if Compare* = This month to last month, the Selected date range will be 03/01/25 - 03/14/25 and the Reference date range will be 02/01/25 - 02/28/25.
  10. Click Save.
  1. The comparison consumption chart is created.
