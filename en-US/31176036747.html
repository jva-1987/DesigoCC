OAP Protocol Alarm Type

The alarm type name is defined by the AlarmTypeFileName.csv file located in the ..:\Program Files (x86)\Siemens\SORIS OAP Adapter\Config folder.

AlarmTypeFileName.csv is a file used to configure and map security events or alarms in a system.

Below is the default configuration and an explanation of each entry. If you need to customize it, edit the file manually.

AlarmTypeFileName.csv is structured in a table with three columns:

1. RawText: key used in the system.

2. Value: A numeric value associated with each identifier.

3. MessageText: The readable text describing the corresponding event.

 

Explanation of values in the default configuration:

- monitorReceiver (0) → “Monitor Receiver”: Monitor Receiver.

- test (1) → “Alarm”: Alarm system test.

- noNewLocation (2) → “No new location”: There is no new location available.

- pushButton1 (3) → “Hostage taking”: Button signaling a hostage taking.

- pushButton2 (4) → “Push button2”: A second button, usable for example for another type of emergency.

- manDown (5) → “Man down”: Someone has fallen or is in danger.

- pullCord (6) → “Pull cord”: Emergency system activated by pulling a cord.

- auxiliary (7) → “Auxiliary”: Secondary or auxiliary event.

- external (8) → “External”: Event related to an external input.

- emergencyPhoneCall (9) → “Emergency phone call”: An emergency call.

- verification (128) → “Verification”: A verification operation in the system.

 

OAP Alarm Description Texts

To manage alarms with the ability to change texts, including the language, a CSV file called AlarmDescriptionFileName.csv can be used. The file is located in ...:\Program Files (x86)\Siemens\SORIS OAP Adapter\Config folder.

The CSV file includes three columns:

  • Device: The device number (Device ID)
  • FixMessage: A text that must be the same for each device.
  • Description: The alarm description text, which can be dynamic and customized as needed.

For example:
Device, FixMessage, Description
1000, Alarm from:, Room 33
2000, Alarm from:, Room 44

In Event List, the Description appears in the Message Text column.
