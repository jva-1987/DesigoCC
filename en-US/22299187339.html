Monitor Control Procedures

On Flex client you can also select any monitor or monitor group to connect or disconnect it from video streams.
NOTE: The results of these actions will not be visible directly on the Flex client, but rather on any installed client that uses the affected monitor or monitor group. For background information, see Monitor Control Reference.

 

Prerequisites

  • The top navigation bar is set to System.
  • The left sidebar is set to Hierarchies .
  • System Browser is in Application View.

 

Connect a camera to a monitor

  1. In System Browser, do one of the following:
    • Select Applications > Video > Monitors > [folder] > [monitor].
    • Select Applications > Video > Monitor Groups > [folder] > [monitor group].
  2. In the Video Viewer, locate the monitor where you want to connect the camera.
  3. On the monitor tile, select  and then select Connect a camera.
  4. In the Select a video object dialog box, select Cameras > [folder] > [camera] and choose Select.
  1. The monitor tile indicates that the camera is connected.

To disconnect the camera, see Disconnect a camera from a monitor.

 

Connect a camera group to a monitor group

  1. In System Browser, select Applications > Video > Monitor Groups > [folder] > [monitor group].
  2. In the Video Viewer, locate the first monitor to use for the camera group.
    NOTE: The cameras in the group will populate the monitors sequentially from this first monitor onward.
  3. On the monitor tile, select and then select Connect a camera group.
  4. In the Select a video object dialog box, select Camera Groups > [folder] > [camera group] and choose Select.
  1. The monitor tiles indicate that the cameras of the group are connected.

To disconnect the camera group, you must individually disconnect each monitor from its camera. See Disconnect a camera from a monitor.

 

Connect a sequence to a monitor group

  1. In System Browser, select Applications > Video > Monitor Groups > [folder] > [monitor group].
  2. In the Video Viewer, locate the monitor where you want to connect the sequence.
    NOTE: If the sequence occupies only one monitor, it will cycle on this monitor. If the sequence occupies multiple monitors, it will also use subsequent monitors in the group, as needed.
  3. On the monitor tile, select  and then select Connect a sequence.
  4. In the Select a video object dialog box, select Sequences > [folder] > [sequence] and choose Select.
  1. The  symbol indicates the monitors occupied by the sequence.

To stop showing the sequence, see Stop a sequence from a monitor group.

 

Disconnect a camera from a monitor

  1. The monitor currently has an associated camera (tile tag does not indicate nothing to show).
  1. In the Video Viewer, locate the monitor that you want to disconnect.
  2. On the monitor tile, select and then select Disconnect Stream.
  1. The monitor tile label changes to Nothing to show, indicating that no camera is connected.

 

Stop a sequence on a monitor group.

  1. A monitor group is currently connected to a sequence.
  1. In System Browser, select Applications > Video > Monitor Groups > [folder] > [monitor group].
  2. In the Video Viewer, the  symbol denotes the monitors occupied by a sequence.
  3. On any one of the monitors occupied by the sequence, select  and then select Stop sequence.
  1. The sequence is disconnected from this monitor group, and the corresponding  symbols are removed from the monitors.

NOTE: The above method will only disconnect the sequence from the selected monitor group. If the sequence was connected to multiple monitor groups, it will continue showing on the others. If you want to disconnect a sequence from all the monitor groups, you can do so as follows:

Disconnect a sequence from all monitor groups

  1. In System Browser select Applications > Video > Sequences > [folder] > [sequence].
  2. In the Properties, set Advanced mode .
  3. Next to the Sequence Session property, select  and then select Stop All.
  1. The sequence is disconnected from all monitor groups to which it was connected.
